# 0.6.11 Windows 本地构建

本版接通 CAgent 可选能力包市场与自研远程桌面本机链路。安装、工具授权、服务监听和调用方观看/控制分别配置；更新不会自动安装能力包或开启端口。

2026-10-17 已完成本机 CShell/CAgent 更新并打开两个窗口，安装后核对能力包未自动安装、桌面服务未监听。安装包已做 SHA256 核验，未代码签名，未上传 GitHub。

## 使用

在 CAgent 隐藏菜单的应用市场安装能力工具包，再保存需要的权限。系统应用包复用真实系统包管理器和安装计划，仍检查系统应用安装权限。智能体只列出当前已注册工具，具有副作用的能力调用遵循已保存的审核策略；全放行不会扩大工具授权。

CShell 的 cagent 扩展应用市场也能管理本机能力包。安装自研远程桌面并授权后，配置真实监听地址及 TCP/UDP 端口；本机观看、键鼠控制和指定远端指纹分别授权。保存监听配置会关闭已有桌面连接。不会自动修改防火墙。远端只显示自身权限，不能修改这些配置。

已连接 Agent 的桌面入口提供观看、选择键鼠控制、画质参数和断开。票据及加密密钥保留主进程，渲染器只接收画面。失焦释放输入；停止、撤权与连接断开释放会话。配置目标帧率不代表设备已达到该帧率。

## 验证与边界

- 能力包真实文件摘要、平台/版本检查、权限交集、撤权、卸载排空及智能体审核测试。
- 桌面控制/媒体协议、授权隔离、单用票据、模拟输入释放、延迟 ACK、反馈计算测试。
- 真实 Windows DXGI/MF 硬件采集、加密本机传输、WebCodecs 解码。测试不注入真实键鼠，不持久化桌面像素。
- 实际 Electron IPC/preload 链路连续观察 16.179 秒，接收并解码 187 帧，零解码失败、零自动断开，最后 2.5 秒仍有 32 帧更新。解码耗时 P50 约 1.2 毫秒、P95 约 2.4 毫秒；整体约 12 帧/秒，仍需采集编码性能优化，不能宣称已达到流畅远控目标。证据为 `test-results/cagent-desktop-electron-ipc.json`。
- 生产构建和本机安装证据分别写入 `test-results/cagent-market-build.json` 与 `test-results/cagent-market-install.json`，以实际文件为准。
