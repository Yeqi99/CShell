# 0.8.7 更新流程与智能体输入修复

状态：开发验证中，尚未发布。正式版本仍是 0.8.6，不移动或覆盖现有标签附件。

- 智能体统一 Enter 发送、Shift+Enter 换行，IME、重复按键和运行中任务保持保护。
- 更新使用香港源，立即更新连续完成下载、摘要校验和安装，不导航到 GitHub。
- Windows 退出前保留会话确认与记录刷新；取消退出撤销待安装动作。安装到原目录并重新打开。
- Android 按开源/Pro 包身份选渠道，校验摘要、包身份、版本与签名；下载后进入系统安装，安装权限设置返回后继续。系统确认不可绕过。
- Linux AppImage 原位替换并保留备份，非 AppImage 运行方式不可冒充可原位更新。macOS 校验 DMG 内的应用身份和版本再复制替换，需当前用户对安装目录有写权限。
- CAgent Windows 安装支持主动更新后重开；Unix 私有运行包验证版本、平台、架构、归档路径和类型后替换并重启。系统 Node 启动及程序内嵌数据目录拒绝自动替换，避免破坏环境或身份。
- 0.8.2 固定 GitHub API 和旧附件规则，无法由香港服务端修复其已安装代码，需要从官网下载覆盖升级一次，保留配置。

验证记录：更新选择、摘要和取消下载；AppImage 替换/取消/回滚；实际 React 单击下载到安装、校验失败不安装；Windows 原生 CAgent 编译。Linux 实际包替换、Android 编译和安装器验证继续进行。未声称所有平台已实机验收。
