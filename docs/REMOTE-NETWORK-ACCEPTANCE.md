| 验证项 | 实际结果 |
| --- | --- |
| 首次采样 | `sampling`，无历史基准时速率为空，不伪造为 0 |
| 第二次采样 | `ready`；检测到 `lo`、`eth0` |
| eth0 接收/发送 | 354.19 / 2237.44 B/s，按字节计数差除以远端间隔计算 |
| lo 接收/发送 | 0 / 0 B/s，来源为两次真实计数没有变化 |
