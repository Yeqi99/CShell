# 终端稳定性与历史回看验收

2026-10-30，0.8.16 候选版本。此记录不代表正式发布或所有远端场景已通过。

## 已确认的问题与修复

- 自动识别 Nano 后，辅助工具栏原先直接加入纵向布局。在实际 xterm 测试中，终端从 23 行变为 21 行，向远端发送 resize，导致全屏编辑器重新绘制。现在识别只在原有快捷键栏提供 Nano / Vim 工具入口；用户主动展开才调整终端尺寸。内置文本编辑器入口随工具展开。
- xterm 6 的历史滚动条默认自动隐藏，隐藏时不响应指针。有历史时现在保持滚动条可见、可拖动；回看时提供“返回最新输出”，后续输出不会把阅读位置拉回末尾。
- 快捷键栏保持单行，窄窗口横向滚动，避免历史状态或工具入口出现时再次挤压终端。只有终端外观字段变化才重新设置字体，隐藏标签不主动执行尺寸适配。

## 验证方式

运行 `pnpm exec tsx scripts/terminal-stability-smoke.ts`。该测试加载真实 TerminalPane、项目样式和 xterm，在隔离的 Chromium 页面实际写入 ANSI 输出并操作滚轮与滚动条，不使用用户配置或连接凭据。

已在 Windows 上对开源与 Pro 两树通过：

- 300 次回车覆盖式下载进度输出不引发 PTY resize。
- 1,200 行日志可以滚轮回看、拖动滚动条；持续输出保留阅读位置，返回末尾按钮有效。
- 空闲后历史滚动条仍可见。
- Nano 自动识别及连续重绘不改变终端尺寸；主动展开工具确实调整尺寸。
- 360、520、800 像素容器连续重绘稳定；隐藏标签修改字体不发送 PTY resize。
- 既有 `terminal-parsed-race-smoke.ts` 解析与 React 提交竞态回归仍通过，TypeScript 检查通过。

两树 Windows checks 与 Windows release 构建均执行稳定性测试，发布时需查看对应 CI 结果。

## 平台审查与限制

新增 DOM 操作均位于 effect、xterm 回调或用户事件内，没有增加模块加载时访问 window / document；现有终端是 Electron 客户端组件，不宣称新增服务端渲染支持。滚动条样式严格限定当前终端且只使用锁定版本 xterm 6 的结构，未覆盖全局滚动条；color-mix 由当前 Electron Chromium 支持，并有颜色变量缺省值。

本次未在 macOS、Linux 实机执行终端交互测试，也未取得用户持续抖动时的截图或原目标操作序列。普通回车进度输出在修复前也未复现持续 resize，因此不能将所有进度条闪烁都归结为工具栏或宣布全部解决。远端程序自身清屏、网络延迟、多窗口同时控制同一 PTY 等场景仍需按实际反馈复现。
