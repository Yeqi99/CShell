# CAgent 后续能力验收（2026-11-01）

## 已实现

- 版本化微信能力包提供原生设置入口，通过 managedWechat 接口完成服务配置、进程绑定和精确版本核验。微信安装、操作授权、账号和收发范围分别处理。
- 通用自动化 list 返回已安装、已配置并授权的真实事件 source/type/payloadSchema；智能体可按来源与字段条件创建事件规则，不必猜测微信回调结构。远端控制端可以管理属于自己的规则，不能注入伪造微信事件。
- 目标规则可更新 memory、prompt、everyMs（1000ms 至30天）。修复工具清单支持 update 但执行校验拒绝 update 的问题。记忆按历史数据处理，不授予新权限；每小时60次总执行限额继续生效。
- CAgent 系统应用目录已无 Codex/Claude Code 入口；保留旧用户数据及兼容后端。
