### 微信单条授权发送后的回调复验（2026-11-01）
- 用户明确授权后，隔离工具服务先确认 native listener ready，仅向本人的文件传输助手发送 `CAgent-check-20261101` 一次。操作返回 completed，持久化单次发送标记防止重试；没有向其他联系人发送、没有自动回复。
- 120 秒窗口内未收到匹配的 `message.received`，自动化任务执行数为 0。原生适配挂接 receive 入口，方向字段可以标识 outgoing，但不能据此保证本机发送一定进入接收路径。本次不能标记回调到任务执行验收通过。
- 窗口内原绑定微信进程退出，随后出现新微信进程；助手未关闭或重启微信。Application Error/WER 最近一小时没有对应微信崩溃记录，无法断言退出原因。停止工具时暴露死目标的无效 RPC 被当成 retained 无限等待的缺陷。
- 确认原目标进程不存在后，仅回收本轮测试子进程；测试父服务退出，隔离 Node 回调监听关闭，隔离配置订阅/webhook及发送接收范围禁用。没有操作当前新微信进程。
- 私有工具源码已增加原进程句柄 `GetExitCodeProcess` 检测：明确退出才直接结束清理；仍活动或无法确认时保留安全等待，不凭数字 PID 猜测。三个无副作用测试覆盖已退出/仍活动 RPC 失败/状态未知，均通过。源码修补尚未重新构建发布，不能将旧市场二进制视为已修复。
