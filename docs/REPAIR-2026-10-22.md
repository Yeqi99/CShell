# 2026-10-22 修复与更新验证

本轮修复覆盖 CShell 0.8.2、CShell Pro 0.8.3 与 Windows cagent 0.8.3。

## 行为

- 文件列表跳过无法读取的子项；失败时保留当前所选目录，允许继续切换或重试。
- 浏览器专用连接保持心跳，读写请求不再被长轮询串行阻塞；浅色桌面输入框使用正确颜色。
- 远程控制提供填满、等比、原始比例与缩放、拖动画面；拖动模式不向远端发送键鼠。默认编码配置降低到 30 fps / 5 Mbps。没有宣称所有网络环境延迟已经降低。
- 智能体支持从已有对话切换模型并建立新会话，保留原任务绑定；显示层平滑流式文本，停止时显示所有已接收内容。
- 常用操作使用统一错误卡片，包含简明说明、可用时的重试，以及可复制的折叠诊断信息。cagent 连接配置增加字段说明并避免空密码覆盖已有密码。
- 新建连接采用宽松默认，已有明确关闭权限保留。

## 香港更新源

- 开源目录：https://shell.canp.ai/downloads/opensource/releases.json
- Pro 目录：https://shell.canp.ai/downloads/pro/releases.json
- 两套目录分别提供 Windows 客户端、Windows cagent 安装程序和 Android APK；旧平台版本保留。
- 客户端获取目录与安装包不会跳转 GitHub。每个新文件在香港服务器校验 SHA256 后才加入目录。
- CShell 自动检查并下载，安装需要用户执行；Windows cagent 自动下载，实际退出时安装，可关闭。安装前再次校验文件摘要并保留原安装根目录。
- Linux/macOS cagent 尚未实现自动安装，本轮未发布这些平台的新包。Windows 安装包未做 Authenticode 签名；Android APK 已做签名和版本核验。

## 模型服务

香港模型网关已部署：合并上游不接受的多个 system 消息，移除上游语法编译器不接受的工具 schema 提示，实际工具执行仍保留完整参数校验。网关逐段转发 SSE，并区分参数错误、限流与上游服务错误。

使用实际客户端生成的合成初始请求验证两个免费模型均成功完成，首个流事件分别约 0.4 秒和 6.31 秒。该验证不读取真实会话或登录凭据。
