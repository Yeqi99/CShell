# 远端文件重新读取期间保护新草稿

## 复现

打开文本或 Python 文件，点击重新读取。在远端响应返回前继续输入，旧实现直接用返回内容替换 CodeMirror 文档，新输入丢失。原有放弃草稿确认只针对点击时的内容，不能视为同意放弃等待期间的修改。

## 修复

请求开始时记录当前编辑器及不可变文档对象。远端返回后若文档已改变，保留草稿、原保存内容及冲突检测版本，不应用远端响应；原位提示重新读取未应用。实时同步沿用错误暂停规则，避免接着自动上传新草稿。用户可以手动保存（仍使用原 revision 检测冲突），或再次明确重新读取。

`scripts/text-reload-race-smoke.ts` 渲染真实 React PythonEditor 和 CodeMirror，通过延迟 IPC 响应控制读取顺序，不读取用户文件。
