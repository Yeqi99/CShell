# 0.7.5 移动端与模型响应修复

安卓文件页提供手机与远端切换。手机目录由系统文件选择器授权，保留目录授权；远端操作绑定选中的 SSH 或 CAgent，不回退到手机。支持目录浏览、文本预览和文件传输。预览限制为 64 KiB，传输分块进行；CAgent 下载核对文件版本，上传不覆盖已有文件。系统撤销目录授权后需重新选择。

原生窗口应用状态栏、显示缺口和键盘边距，修复本地品牌图片资源加载。Windows 工作台的新建连接改为快捷连接标题旁的小图标入口，保留键盘名称和悬浮提示。

安卓 CAgent 的设备连接与屏幕投影分别管理。系统停止录屏不再同时停止设备状态查询；锁屏时不宣称可操控。系统撤销投影后需要重新授权，厂商省电仍可能中断网络。具体范围见 [Android CAgent](ANDROID-CAGENT.md)。

## 模型诊断

本机历史包含一次 beam-free 返回 JSON 截断、旧版本空 tool_calls 兼容错误，以及权限和网络失败。不能把这些都归为模型能力不足。本次使用已配置账号对 beam-free 与 longcat-2.5-preview-free 分别进行最小文本和结构化工具返回验证，均成功；未执行返回的工具，也未发送历史对话。历史截断没有复现，尚不能确定其上游原因。

响应解析现在区分无效 JSON、流式 JSON 和结构错误，提供可读错误码，不回显原始响应。未完成的工具调用不会执行。此改动不代表上游服务不再返回截断数据。

## 验证边界

前端布局与文件入口使用浏览器模拟桥检查；安卓原生代码、仪器测试编译和 lint 已通过。真实手机的系统目录选择器、锁屏、厂商后台策略及重新授权仍需实机验收，不能以编译代替。Android 被控端的手机文件管理和终端尚未实现；手机文件页和手机作为控制端的远端文件功能不等同于这两项能力。
