# CShell / CAgent 1.0.0 发布说明

状态：候选验收中。下载入口与更新清单完成核验之前，不代表已向用户发布。

本轮重点是账号同步、同账号连接和会员 MCP 长连接，以及围绕真实连接的文件、智能体和日常界面体验。

## 账号与连接

- 同步连接、分组、模型与扩展配置、偏好；保留本机身份与加密上下文。手动配置的连接地址不再被同账号中继地址替换。
- 同账号设备统一进入连接列表，保留用户移动的分组；中继连接复核会员、设备身份和操作授权。
- 同步容量、中继与 MCP 用量可配置和扩容；账号页显示已用、预留及剩余。管理员可配置成本费率并查看审计，不自动降低已有用户权益。
- MCP 提供可撤销的会员长连接客户端，支持真实会话恢复与任务查询；重连不重放状态未知的写操作。

## 操作与工具

- MCP/CLI 补齐连接与凭据管理、主机身份核验、预检、会话和任务恢复、完整命令结果、权限诊断、应用偏好和更新工具。
- 更新工具执行检查、下载、校验、安装；遵守版本频道、目标身份与更新授权。重启安装须显式确认，不接受任意下载地址或安装路径。
- CAgent、SSH/SFTP、FTP 文件互传使用真实 Provider 能力；支持时优先机器直传，开始写入后不因失败自动重放。临时文件校验后发布，不覆盖已有目标。
- Android 提供已授权目录文件访问、应用入口和手机远控；画面保持原始比例并跟随横竖屏，输入坐标随画面映射。系统录屏、无障碍和目录授权仍由 Android 管理。
- 微信市场展示一个“微信工具”，自动按精确版本选择能力包，优先使用香港下载源并核对摘要。0.1.3 支持微信 4.1.15.56 / 4.2.0.12 已验证的文本和消息订阅范围。
- 增加快捷反馈、诊断脱敏预览与后台处理；同一提交重试不重复创建反馈。

## 界面

- 设置按分类组织，保留草稿；全局权限操作集中呈现。
- 单机器与全部 Ping 使用图标；自动检测菜单限制在窗口内。
- 手机远控窗口默认保持竖屏比例；断开、权限不足和空目录等状态分别说明。
- 语言、标签和桌面入口在最终安装包中检查；不同 Provider 的文件和终端不通过虚假占位状态冒充可用。

## 已知边界

- 本轮的 Windows/Linux 应用网络出口不是所有进程的系统 VPN。系统 TUN/WFP 执行层未开放；Android VPN 的 UDP/QUIC 也不在当前支持范围。
- 微信 4.1.15.50 仍隔离，未知版本不宣称兼容；通讯录、历史、媒体、朋友圈和财务能力不在 0.1.3 两包的已验证范围。
- canp.site 的真实受限 DNS 与 HTTPS 续签闭环尚待专用令牌及生产验收，不以 mock 或接口存在宣称一句话建站已完成。
- macOS 签名/公证与各平台实机限制，按最终资产验收清单逐项披露；编译成功不等于实机通过。
- 本轮最终手机实机、长时间负载和跨月计量场景尚未全部完成。已验证范围与方法记录在 release-evidence；不沿用旧测试包的实机结果冒充最终包。

发布附件、源码提交、SHA-256、更新清单及本机升级结果将在实际发布验收后补充。
