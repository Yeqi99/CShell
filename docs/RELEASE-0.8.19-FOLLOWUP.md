# 0.8.19 收口跟踪

用户于 2026-11-02 要求本轮问题统一修复验证后发布 0.8.19。此文件记录验收范围，不表示已经发布。

## 必须完成

- 机器分享入口必须从连接列表可发现并到达实际管理页面；支持指定邮箱、批量机器、有效期、限次分享码、兑换和撤销。借用者不可获得连接密码，过期与撤销由服务端执行。已有“账号与云同步”中的机器借用表单不等于入口体验验收通过。
- Android 不能只完成本人账号发现：借用连接需实现独立委派认证、服务端验证、到期和撤销收敛，不把本人账号密码传给借用者；没有实现验证前不得展示为可用借用能力。
- 对 2026-11-01 的 19 项及附加需求重新按源码、实际 UI 入口和验证证据核对；区分已实现、不可发现、未验证与缺失。历史文档中的旧勾选和“完成”不能替代本轮审计，真实限制保留。
- Android CAgent 启用后，以当前账号登记稳定设备身份并建立受控端中继；登录、退出、服务停止、网络切换及凭据冲突不串号、不覆盖其他设备数据。
- 电脑设置提供“自动发现账号设备”。启用后，同账号且已具备有效加密连接凭据的设备进入统一左侧列表；身份不匹配或凭据尚未同步时不伪装为可连接。
- 首次发现放入默认分组，显示紧凑账号设备标记；用户改名、拖动分组、排序和收藏不被后台刷新覆盖。离线设备保留并显示离线，网络检查失败与确定离线区分。
- 自动发现偏好按本机账号隔离，保持现有 0.8.18 严格云数据结构兼容。
- Ping 全部入口改为图标按钮，保留键盘名称和悬停说明；右键自动检测菜单在窗口边界内定位，打开时不被工具提示遮挡。覆盖窄侧栏、小窗口和缩放布局。
- 同步普通版与 Pro 的适用代码，回归既有账号配置、分组及设备认证；完成实际包验证再发布，不移动 0.8.18 标签或覆盖旧附件。
- 更新官方文档、官网、各平台香港下载及更新清单，校验实际客户端使用的无查询参数 URL、下载长度及 SHA256；用户自行升级，不强制重启当前应用。

## 限制必须如实保留

Android 系统录屏授权和无障碍控制授权不能由账号会员或云发现代替；设备上线不等于屏幕已共享。没有真实设备验证的项目不能记录为通过。已发布 0.8.18 的更新渠道验收与本轮新增能力验收分别记录。

2026-11-02 已完成两个公开更新目录与 28 个新二进制附件的 Worker 范围下载校验，实际 CAgent 更新器完整下载并验证通过，没有执行安装。香港存储清理后可用约 15.10 GiB、使用率 88%；后续发布遵守 HK-RELEASE-STORAGE.md 的容量和保留规则。
