# AI 基座与智能体

顶栏机器人图标打开可折叠侧栏。先在“基座与权限”添加名称、API URL、模型 ID 和可选 API Key。当前协议为 OpenAI 兼容 Chat Completions（支持 function tools 与 SSE 流式响应）；不声称兼容任意供应商的专有协议。HTTPS 地址和本机回环 HTTP 可用，重定向禁止，修改地址必须重新输入 Key，避免把旧密钥发给新服务。

可添加多个基座，在对话中选择模型，并为连接凭证解析独立设置基座。所有会话共用全局权限，不按工作台、终端、文件或 Python 等界面位置划分授权。已有会话固定使用创建时的基座、位置和服务器，切换工作区不会改变目标；需要更换时新建会话。历史、密钥和权限保存在操作系统加密的 `ai.enc`，不进入外观方案、导入导出或 Git 仓库。清空 Key 字段并保存可移除原 Key。没有配置基座不会发送请求；用户发送后，消息和明确授权读取的工具结果发送至所选供应商。

## 权限

在同一界面勾选 CShell 自身能力、机器范围与默认操作，默认全部关闭。每台机器可覆盖默认操作；覆盖列表为空表示禁止该机器的全部操作。覆盖不会扩大机器访问范围。旧版按位置授权不自动合并为全局授权，需要重新勾选机器操作。授权分组包含以后加入该分组的已保存机器；临时连接需保存后授权。后端核对真实 SSH 会话的主机、端口、用户名及当前分组，权限不由模型或前端宣称决定。

| 能力         | 工具                      | 范围                                             |
| ------------ | ------------------------- | ------------------------------------------------ |
| 查询 CShell | `list_machines`, `list_sessions` | 已保存连接目标和分组、当前活动会话；不返回密码、密钥或终端内容 |
| 读取资源指标 | `read_metrics`            | 当前服务器的 Linux `/proc` 和磁盘计数            |
| 读取远端文件 | `list_files`, `read_file` | 目录和最多 64 KiB UTF-8 文件；可能包含敏感数据   |
| 执行命令     | `execute_command`         | 独立 SSH exec 通道，具有登录用户的全部服务器权限 |

CShell 查询工具无需绑定机器，也可在远程连接断开后使用。机器工具仍绑定会话创建时的真实连接。只把已授权工具提供给模型；即使模型伪造调用，执行前仍会校验。每项审核结束后再次检查权限和连接状态。不能操控本机文件或借用其他连接。工具输出视为不可信材料，不能扩展权限。

## 审核等级

- **全提示**：读取与执行工具都需要逐项批准，显示目标和完整参数。
- **限制执行**：普通操作直接运行，危险命令、解释器、网络下载、权限修改、服务/包管理及 shell 组合语法进入审核。
- **全放行**：在已授权机器与能力内执行，无额外提示。它不授予未勾选的能力或机器。

风险名单是审核辅助，**不是 shell 沙箱**。别名、自定义可执行文件和程序副作用无法仅凭命令字符串穷尽判断；不信任的任务应使用全提示、只读能力和低权限 SSH 账户。命令执行能力本身就是服务器控制权限。

运行期间不能切换审核等级。停止会取消模型请求、待审核项和正在运行的 exec 通道，不能撤销已完成的远端修改。每轮最多 16 次模型调用，单次 API 90 秒、命令 60 秒超时。服务器断开后保留对话并报错，不自动切换服务器或重连执行。重启保留历史，但不恢复待执行操作。

## 连接信息提取

连接表单仍可完整手动填写；“从文本智能填写”是可选入口，默认使用“模型基座 → 连接凭证解析模型”指定的基座；选择自动时使用第一个已配置基座。提取面板可临时选择其他基座，不改变保存的默认值。点击“提取并填写”才向该基座发送粘贴文本，不写入聊天历史。请求不提供 Tool，输出严格校验 SSH 字段、端口及长度，不允许额外命令或连接执行。认证失败、模糊信息、多个地址或不支持的协议保留表单供手动填写，不静默改用其他服务。当前仅支持已实现的 SSH 表单适配。
