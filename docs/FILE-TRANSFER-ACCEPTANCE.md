# 文件大小与传输反馈验收（2026-10-30）

## 修复范围

- SSH/SFTP 与本地文件列表原先使用中文紧凑数字格式（如“1.4亿 B”），统一为 B / KiB / MiB / GiB。FTP、CAgent 使用同一格式化函数。
- SSH/SFTP 数据流、跨服务器复制及 FTP Provider 的真实字节回调进入统一进度计量器。队列等待不计入传输计时；显示明确标为“平均”的吞吐率，结束、取消和失败后清除速率。
- SSH 工具侧栏新传输自动展开队列，显示已传/总量、百分比和平均速度。目录逐项发现总量时只显示已传字节；文件提交/重命名完成之前不显示完成状态或 100%。
- CAgent 下载原先只有“正在传输”，后台写入每个真实分块后发送进度事件；剪贴板上传以远端确认的 offset 累计。批量总量未知时不伪造百分比。结束事件不受 100ms 节流影响，保留最后实际字节数。
- CAgent 浏览器文件选择上传在每次远端分块确认后更新真实计数与平均速率，并核对远端返回位置。取消、错误和目标切换不保留进行中的假速率。

## 验证

Core 与 Pro TypeScript 检查通过；15 项相关测试通过：

- 5 项新增进度测试：二进制单位、未知总量、排队/失败状态；真实 Node 流和 SFTP 写入模拟的多次增量；FTP 队列 Provider 计数；CAgent 事件节流与取消/完成最终字节。
- 6 项现有 FTP/FTPS 测试使用本机实际控制/数据 Socket，覆盖传输、TLS、取消、断连和授权边界；3 项传输取消测试、1 项 CAgent 分块文件协议测试通过。
- Edge 组件验证使用模拟 IPC 事件，显示 `16 MiB / 64 MiB · 25% · 平均 4 MiB/s`，完成时显示 `64 MiB / 64 MiB · 100%`；320/600px 下进度内容没有溢出。截图保存在本地 `.local/transfer-progress-600.png`。

这不是用户远端大文件端到端实测。未更改真实用户配置、凭据或授权；本任务未安装或发布。安装后的大文件上传/下载、剪贴板批量传输及断连恢复体验仍须在真实目标验收，不能用组件模拟替代。
