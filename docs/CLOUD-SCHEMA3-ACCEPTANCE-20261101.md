## 恢复边界

外部插件记录携带清单摘要；已验证本机包按精确身份恢复启用选择，安全片段可直接恢复。CAgent 仅对宿主信任目录中的精确版本、摘要自动恢复包；其他来源展示待处理。配置仅通过宿主适配器声明的非敏感字段验证器导入。密钥、权限授予、运行进程与本机路径不通过此配置协议迁移。

账号外观修改及切换串行化；机器网络规则先暂存期望值，其他云字段提交或回滚完成后才重建实际连接。明确卸载与禁用会更新云端期望，避免重启后复活。
