# CShell / cagent 0.6.30 — Windows x64

## 本次更新

- 远程桌面：修复初始化后没有首帧的黑屏，自动切换兼容采集；恢复通知不再残留为错误。
- 支持填满工作区、全屏与还原，保持同一连接；画面等比例适配，连接中可调整画质。
- cagent 连接统一进入机器工作区，包含终端、文件、桌面、应用市场、智能体及设置权限；修正边距、窄窗口布局和主题一致性。
- cagent 提供独立 Windows 安装程序、桌面图标、后台托盘、连接信息复制、映射端口配置及应用内更新。
- 智能体新增 ai_event_list、ai_event_save、ai_event_set_enabled、ai_event_remove，支持查看、创建、修改、启停及删除事件订阅。请在智能体访问权限中开启“管理事件订阅与触发任务”。
- 订阅工具复用现有来源、处理会话授权和预算控制；订阅不会自动扩大微信权限。事件唤醒的任务不能修改订阅规则。

## 下载范围

本次附件仅发布已构建验证的 Windows x64 CShell 与 cagent。其他系统的历史版本仍在对应旧版本页面，本次不声明其已升级。Windows 附件未进行商业代码签名；SHA256SUMS.txt 可核对下载完整性。

## 验证与边界

生产构建、事件订阅工具及事件调度专项测试通过。桌面实机测试包含采集、解码、画质调整和公网兼容采集恢复；全屏及工作区模式切换保持连接。并不保证所有锁屏、RDP 会话切换及网络环境都已完成验收。
