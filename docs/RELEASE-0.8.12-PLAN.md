# 0.8.12 候选范围与发布门槛

当前正式版仍 0.8.11。本文件是下一版收口清单，不是已发布声明；不移动旧标签。

三个独立问题域：

1. Android 输入可靠性：手势队列串行化、失败丢弃依赖输入、指针松开保留真实按住的修饰键、光标未确认时停止依赖按键。两版 API 29/35 的光标修复验收成功；Pro 连续 8 组三次点击在运行 40442330793 成功。早期 Pro API 29 偶发少一次点击（121976781855）根因仍未知，不能声称已解决或抹除记录。保留触摸诊断，不重放不确定操作。
2. 文件传输取消：跨机器复制绑定两端，取消后元数据返回也不创建目录；网络 closed 事件取消关联任务。两版各 20 项文件相关测试、10 项生命周期测试和类型检查通过，见 TRANSFER-CANCELLATION-FOLLOWUP.md。
3. 智能体草稿：失败后恢复保存能清除对应警告，不掩盖其他会话失败，忽略过期结果；恢复失败单独保留。Core `67f03b7`、Pro `b8cc8ca`，真实 React hook 浏览器回归、两项加密存储测试和两版类型检查通过，见 AI-DRAFT-RECOVERY-FOLLOWUP.md。

官网首页、按架构下载选择器与文档阅读器改版已分批上线并核验，不把网页改动拆成客户端发布数量。

剩余门槛：

- 核对两版源码差异和版本文件，确认 Pro 已有未提交 icon.png/style.css 不被误打包；仍需给当前冻结提交完整构建与必要回归。
- 新版本构建所有实际提供的平台和架构，验证产物、签名条件、安装与更新渠道；不能复用旧 SHA 的绿灯作为新版本证明。
- 失败检查保留原记录。Windows 安装包签名、macOS 公证及真机限制如实说明。
- 冻结新标签并发布，更新香港镜像、官网版本/日志、更新清单；附件摘要及实际可下载状态逐项核验。
- 本机升级前检查进程与活动会话；之前 CAgent 旧运行时尚未完成切换验证，不能只以安装退出码替代运行验收。保留身份、凭据、OpenCode 配置及其他应用。
- 账号草稿错误提示验证不等于整机磁盘故障验收；Android 模拟器不等于真机。官网个性化目标还需审视独立场景和开发者页，不因首页完成便关闭长期目标。
