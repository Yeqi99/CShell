# 账号同步范围与兼容性

更新：2026-11-01。这里描述代码当前实际字段，不把本地持久化等同于云同步。

| 内容 | CShell 账号同步 | CAgent |
| --- | --- | --- |
| 连接、分组、排序、收藏、连接凭据、已核验主机身份 | 加密同步 | 保存不消费的数据；账号设备另外由云设备目录发现 |
| 外观、字号、默认连接方式、Ping周期、命名方案、监控布局 | preferences/presets/monitorViews 同步 | 保留原字段，不把桌面设置误当设备权限 |
| 字体与背景文件 | 摘要校验，每项不超过8MiB | 保留密文中的原数据 |
| 内置插件启用选择、扩展命令、Docker socket选项 | extensions 同步；外部包不自动下载安装 | 保留选择；只执行本平台已安装能力 |
| 模型基座、Key、文本助手默认模型、用户记忆、AI访问策略 | ai 加密同步 | 使用共享基座与记忆；本机执行/设备授权不因导入变更 |
| OpenCode独立账号、模型引用、Tavily配置 | 各自密文字段同步 | OpenCode通过官方运行时使用；未消费字段保留 |
| 浏览器数据、HTTP工作区、CAgent设备记录、机器桌面外观 | 独立字段同步 | 保留未消费字段 |
| 模型网络出口选择 | 新增 networkRoute 同步 | 保留CShell设置；CAgent自己的账号出口使用网络规则服务 |
| 账号设备发现、会员、借用、来源→出口规则 | 由服务端独立存储和鉴权 | 从服务端刷新，不复制机器密码 |
| MCP监听地址、访问令牌、API客户端授权、设备私钥、本机路径授权 | 不同步 | 各设备独立持有 |
| 智能体聊天全文/草稿、事件与本地定时任务、运行中会话、匿名统计同意 | 当前只本地保存，不同步 | 本机保存；账号切换隔离 |
| 外部扩展二进制、已装软件、系统环境变量、终端进程 | 不随配置同步 | 需在明确目标机器另行安装或设置 |

## 旧版本与新增字段

先部署云服务再发布客户端。旧数据保持schema 1。新快照含扩展启用字段时，成功写入和新账号注册会原子建立schema 2门禁。旧客户端继续访问会收到升级提示，不能覆盖新版数据；不会把版本不兼容当成密码错误。

CAgent 对不消费的顶层字段保留原值。桌面解析当前已知格式；未知结构会拒绝整次导入而不是静默剥除后上传。不能据此声称任意未来字段已向后兼容。每次新增字段必须扩展schema与迁移测试；Android还需用真实账号跨端往返验证。

## 导入与恢复

开源版、未登录工作区和账号工作区分离。导入需用户选定来源与冲突处理；凭据通过原上下文解密、目标上下文重新加密。旧模型被移除时清除CAgent缓存密钥，不扩大权限。代理出口暂不可用时仍保存所选出口，之后请求失败会明确提示，不擅自切为直连。

## 秒级目标与系统代理控制面（2026-11-01）
- CShell 目标支持 1 秒至 7 天检查间隔，旧分钟配置保持兼容。智能体可通过 update_goal 保存目标记忆并调整间隔，不重放工具操作；每轮记忆作为不可信历史笔记注入。未绑定目标可在授权范围内选机器，已绑定目标继续锁定真实身份。保存编辑保留检查历史。
- Windows 系统代理启用前固定原有系统代理到独立控制请求会话，账号租约/中继请求不会递归经过自身出口。系统代理仅覆盖遵守系统 HTTP/HTTPS 代理的应用，不是 TUN；忽略代理的软件和 UDP 不在接管范围内。
- 验证：ai-work 10 个测试；system-proxy 2 个模拟注册表测试；local-http-proxy 实际 HTTP 转发测试；TypeScript 编译。未修改用户当前系统代理，尚未实机验收系统范围切换。
