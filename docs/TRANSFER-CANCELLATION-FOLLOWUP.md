# 文件传输取消：0.8.11 后续

确定性测试在修改前复现两个问题：跨机器复制取消源会话后仍打开 SFTP；目录元数据返回前取消，仍创建目标目录并报告完成。

修复为跨机器任务同时保存源、目标会话关联（界面仍归属目标），取消任一端均终止排队任务。获取源通道后和目录元数据返回后重新检查取消状态；上传、下载与跨机器复制在创建目录前均检查。已经发生的远端操作不宣称回滚，也不自动重试或重放。

新增测试覆盖源／目标取消、排队任务不打开 SFTP、等待元数据时取消不创建目标目录，以及本地下载目录不产生。修改前两个测试失败，修复后通过。Core 的传输取消、SFTP 生命周期、核心真实 SSH 与 FTP/FTPS 回归合计 20 项通过，TypeScript 检查通过。Pro `76699a8` 同步后同样 20 项测试和 TypeScript 检查通过；Core 修复为 `18e90a1`。

尚未发布，不单独为了这一项提高版本号。此项与 Android 输入可靠性属于不同问题域，可作为下一版独立修复。

## 远端意外断开

主进程此前只在手动断开 IPC 中调用取消传输；远端 closed 事件仅注销连接，遗漏待执行任务。现在所有 closed 事件先取消关联传输，再注销连接，并在 MCP 消费事件前完成清理。Core `92180ff`、Pro `a40abec`。两版各 10 项连接生命周期与取消测试通过，包含真实 SSH 网络断开、认证/超时/取消及 SFTP 写入失败；两版 TypeScript 检查通过。测试覆盖连接事件与取消机制，未将其声称为完整 Electron 窗口端到端验收。
