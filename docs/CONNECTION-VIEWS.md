# 连接的打开方式与文件工作区

本页对应 0.8.9 的实现与验证；构建发布状态以发行记录为准。

## 双击连接时打开什么

- 默认使用原生连接方式：SSH 打开终端，RDP 打开远程桌面。CAgent 仍进入机器工作区。
- 偏好设置中的「默认打开方式」可以改为可视化。左侧连接右键中的「默认以可视化打开」仅覆盖该台 SSH / RDP 机器；它不会连接机器、修改凭据或增加权限。
- 即使默认使用原生模式，连接右键仍可单次打开可视化桌面。可视化与原生 SSH 共用现有会话，切换不重建 PTY。
- SFTP、FTP、FTPS 始终打开文件工作区；HTTP 始终打开请求工作区，不受机器桌面默认值影响。
- Pro 会同步全局设置和每台机器的覆盖值。全局概览、命令和可视化工作台是另一项设置，不改变连接协议。

旧版本没有记录可视化默认值是否由用户主动选择。本次把没有明确选择标记的旧可视化默认迁移为原生；需要时可在设置中重新选择可视化。此后会保留明确选择，已有原生选择和单台机器覆盖不变。

## 侧边栏文字

在侧边栏空白处右键，展开「外观设置」，微调分组、服务器、地址字号和行间距，也可恢复默认。默认界面字号为 14 px，分组 14 px，服务器与地址 12 px；已有自定义数值保留。侧边栏与终端最低可设为 8 px，界面最低 9 px。字体、背景、命名方案等仍在偏好设置的外观分类中。

## 可视化中的 SSH 终端

终端右上角「文件与机器信息」默认收起。展开后显示当前 SSH 会话的文件区与监控；窄面板改为上下排列并可滚动。收起不会丢掉终端历史、文件路径或编辑草稿，也不会继续后台采集监控。未连接、断开或采集失败时不展示虚构数据。断开后停止文件操作和自动保存。

## 独立文件连接

SFTP 使用 SSH 身份验证，但连接过程中不创建终端或请求 Shell。文件区保留文本编辑和冲突检测；不会因为打开 `.py` 文件而探测或执行 Python 环境。保存已有文件需要服务器声明支持 OpenSSH 原子重命名；不支持时在写入前拒绝，保留原文件与编辑草稿，可下载后编辑并另存为新文件，不自动降级为直接覆盖。

FTP / FTPS 提供路径导航、Ctrl / Shift 多选、普通文件上传下载、拖入上传、建单个目录、重命名、删除文件或空目录。删除先确认；不展示未支持的文本编辑、跨连接复制、递归目录传输。目录下载需进入目录后选择文件。FTPS 使用显式 TLS 与证书校验，失败不降级为 FTP。

底部传输队列只显示当前真实会话，包含实际字节进度、错误和取消入口。断开后文件操作停用，旧页和未保存编辑保留；「重新连接」创建新的文件会话，不把旧编辑草稿悄悄绑定到新会话。

## 验证

- `tests/connection-view.test.ts` 覆盖迁移、明确选择、字号下限、每台机器覆盖存储与文件协议排除；Pro `tests/cloud-store.test.ts` 覆盖云还原。
- `scripts/connection-view-smoke.ts` 使用真实 React / ToolsPanel 组件与隔离接口，检查折叠菜单、屏内定位、400 / 900 px 布局、保留终端宿主和路径草稿、断开状态。
- `scripts/file-connection-workspace-smoke.ts` 使用真实 React / FilePanel / CodeMirror 与隔离接口，检查 320 / 400 / 700 px 布局、FTP 操作与确认、传输队列，以及 SFTP 无环境探测、离线停自动保存并保留草稿。
- 上述界面 fixture 不接触用户连接，不代表公网服务器实测。真实协议测试、发行包端到端验收另见发行记录。
- `tests/text-files-atomic.test.ts` 使用真实 SFTP 协议，覆盖未声明原子替换时零写入、真实 VERSION 声明后的保存与并发冲突。测试服务器实际实现所声明的扩展，不修改客户端能力缓存。
- `scripts/file-connection-package-smoke.ts` 可通过 `APP_PATH` / `APP_ARGS` 指定真实 Electron 构建；`SFTP_ATOMIC=false` 验证不支持原子替换的服务器。已在本机 core 0.8.9 源码构建跑通支持/不支持两轮，覆盖新建、保存、读取、建目录、工作台三模式、零 Shell 请求与重连保留旧草稿；尚不等同于所有发行附件验收。
- `scripts/ftp-connection-package-smoke.ts` 使用真实 Electron 与回环 FTP 控制 / 数据 Socket，覆盖新建连接、目录浏览、上传、改名、下载字节一致、建目录与确认删除空目录；空闲断线正确停用操作，重连获得新会话，旧页路径草稿保留。FTPS 已检查新建入口与证书策略说明；TLS 传输与证书拒绝另由协议测试覆盖，不通过界面测试放宽系统信任。未接触用户文件或公网目标。
