# CShell Pro 0.8.20

本次更新改善跨设备模型配置、CAgent 应用市场和中英文界面，并包含 0.8.19 的账号设备发现与机器分享。

- 修复云恢复覆盖本机明确网络出口的问题。新设备默认跟随系统代理；已有明确选择保留，指定出口不可用时不悄悄改为直连。
- CAgent 应用市场按窗口宽度排列卡片，区分能力包与系统应用；刷新保留搜索内容。
- 新建 CAgent 账号工作区与首次启动使用一致的智能体默认权限。升级保留已有明确关闭的设置，不重置配对和设备授权。
- 原生桌面入口根据目标机器实际检测结果显示；未检测到桌面时可从菜单主动重新检测。
- 补齐内置桌面应用、窗口操作、权限说明、延迟检测和自动检测菜单的中英文切换；用户自定义名称保持原文。
- 同账号设备分组置顶并初始折叠，记住账号各自的展开状态；设备标签与地址独立排布，保留离线状态和移动分组。
- 安卓远控默认完整适配，跟随手机横竖屏比例；改进有界视频队列，减少等待确认时反复丢帧。新增手机文件与应用快捷入口，按实际系统授权提供。
- 全部延迟检测使用紧凑图标，窄窗口和缩放下菜单保持在可见范围内；权限说明与焦点轮廓不再相互覆盖。
- MCP / CLI 补充连接创建与修改、加密凭据更新、首次 SSH 指纹探测与显式信任；分别授权，保存连接不会自动授予连接权限。
- 可找回当前调用方的会话和任务 ID、输出游标，并查询当前权限；应用重启后的未知操作不会自动重放。
- SSH 命令结果分别返回 stdout、stderr、真实退出码及截断标记，失败退出不再显示为成功。
- 修复普通版 CAgent 使用 Pro 更新目录的问题，并校验附件渠道和版本，避免跨渠道下载。

0.8.19 的机器分享可从左侧连接右键“分享机器…”进入；同账号设备自动发现可在账号设置启用。分享与中继仍由后端核验身份、时效和权益。

Windows 包未签名，macOS 包未签名、未公证。原生构建不等于所有实体设备均已验证；Android 录屏、无障碍及短信电话仍受系统许可约束。指定联想设备中继及运营商短信、电话的实机覆盖限制保留。

发行状态以最终验收记录和更新目录为准。本说明的准备不表示附件已经公开或更新目录已经切换。
