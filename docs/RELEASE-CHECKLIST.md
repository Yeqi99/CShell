Windows 私有文件权限新增真实 ACL 回归，修复中文路径传给 PowerShell 的编码问题，并区分启动、应用权限与超时失败；仍保持当前用户独占权限和 15 秒超时，失败不继续启动。上一轮 CI 的权限错误缺少底层诊断，不能认定根因已经证实。最终本机并行全量测试出现 6 项失败、1 项取消，其中三个 ACL 设置明确超时；同一代码逐组执行 112 项全部通过，云端最终平台检查通过。保留并行失败记录，高负载下启动和计时可靠性仍需继续跟进。

Android 35 曾在进入 TLS 之前因模拟器网络未就绪失败；最终测试固定官方支持的独立模拟器网络模式，并在测试进程内确认 TCP 可达，未放宽 TLS 或重试协议断言。API 29 / 35 最终均通过。

Android 签名公钥指纹记录在 scripts/android-release-identity.json，依据原持久发行签名；密钥和密码不入库。不能为了通过构建换签名导致用户无法覆盖升级。

Android Agent 身份是 0.6.0 新增能力。发布前修复 Android KeyStore 的 TLS 预哈希签名权限，保留密钥别名与身份；更早的内部 0.6.0 APK 未分发或安装到用户设备。历史正式版的 APK 签名保持一致。当前没有真实 Android 设备，模拟器通过不能替代输入法、后台恢复与真机兼容性验收。

## Windows Agent 压力样本

2026-10-14，Windows 10.0.26200、16 个逻辑核心、独立 Node 24.19.0 进程：闲置 2.717 秒样本 RSS 61.64 MiB；四个 PTY 共接收 4,644,892 个字符，用时 4.99 秒，Agent CPU 时间 1.797 秒、RSS 121.47 MiB。暂停确认后累计约 262,397 字符即暂停推送，恢复确认后继续；关闭退出码为 0。

这些数值不包括 Shell 子进程、控制端或终端渲染，不作为吞吐或持续运行保证。确认消息单在途、积累合并、关闭后不继续发送已加入自动化回归，Android 同步修复。
