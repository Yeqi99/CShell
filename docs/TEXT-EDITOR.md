# 文件编辑与多磁盘监控

2026-10-20，CShell 0.6.41。

## 当前实现范围

- SSH Linux 工作区：`df -Pk` 分别展示已挂载的本地文件系统，重复设备不重复计数；`lsblk` 展示物理磁盘容量，排除 loop 等非 disk 类型。两者不相加。命令不可用时不伪造磁盘数据。
- SSH 文件列表双击文本进入内置编辑区，不要求 Python 插件。未知扩展名也进行有界内容检测；常见二进制文件保持下载行为。当前支持 UTF-8（保留 BOM 和换行），单文件上限 1 MB。
- 保存模式按 Ctrl+S 或保存按钮写入。实时模式合并 350 ms 内的输入，每个编辑器串行上传最新内容；失败、冲突、断连时暂停，保留草稿。
- 写入采用临时文件、权限属性保留、写前版本比较、上传后再次比较和 OpenSSH 原子替换。不支持原子替换的服务器返回错误，不退化为先删除再上传。原子替换前的比较不能替代服务器端跨客户端事务锁。
- 回退保留本次编辑会话内最近最多 8 个已保存版本，合计最多约 2 MB；不持久化。恢复到编辑区时切为保存模式，用户再保存到服务器。文件页最多同时保留 6 个编辑器，切换保留草稿。
- 内置纯文本、Shell 语法模式。Python 由现有 Python 插件启用，使用选择的真实解释器/Jedi 提供补全、签名和语法诊断。探测 Conda、项目及祖先目录的 `.venv`/`venv`/`env`、常见系统、pyenv 和 virtualenv 目录；不是全盘扫描，不能声称发现所有自定义环境。
- Vim/Nano 当前全屏状态下提供内置编辑器入口，默认实时模式。单一绝对路径启动命令可预填；相对路径、复杂参数不猜测，需要填写完整路径。原 Vim/Nano 缓冲区保留，用户应先保存其未写盘内容，不能将内置编辑区当作 Vim 缓冲区同步协议。

## 验证

TypeScript 检查、构建、15 项相关测试通过。SFTP 测试覆盖一般文本、UTF-8 BOM/CRLF 保留、过期版本拒绝、原子替换、二进制及大小限制。Electron 实际窗口测试覆盖双击打开、保存模式不提前写入、切换后草稿保持、展开还原，以及实时保存失败时原文件保留并暂停同步。

## 尚未对齐

此轮未扩展本机目录、CAgent 文件协议及手机端的文本读写能力，也未实现 Windows 原生磁盘枚举。Python 功能不是完整 PyCharm IDE，不包括调试器、项目重构和所有语言服务；其他语言的语义补全贡献接口尚未实现。编码转换、跨重启回退、Vim 未保存缓冲区迁移仍未实现。
