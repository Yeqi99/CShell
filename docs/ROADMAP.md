# 路线图

## 0.1 开发预览

已实现核心 SSH/SFTP、多标签终端、本地配置、加密凭据、双语主题、文件复制/移动与 Linux 监控。界面按所有者提供的概念图调整为紧凑三栏，不沿用参考图的 Nebula 品牌/资源。

## 发布前验收

- 真实 OpenSSH Linux 主机、加密/未加密密钥和密码、认证过期、网络抖动、突然断线。
- Vim/tmux/top、CJK/组合字符/ZWJ Emoji、超长输出与多会话长时间压力测试。
- 大文件、目录树、覆盖、取消中断、磁盘满、低权限服务器、SFTP 扩展不支持、杀进程残留临时文件。
- 原生系统拖入、不同 DPI 和多屏、Windows 安装/升级/卸载、正式签名证书。
- 安全审查、发布第三方声明与供应链清单。自有代码许可证已确定为 MIT。

## 下一阶段

连接取消/自动重连策略、跳板机/代理、主机指纹管理、可编辑片段、自定义快捷键、分组重命名和批量连接；拖出到资源管理器、系统文件剪贴板、跨卷移动、冲突策略、断点续传。

## 后续平台

macOS/Linux CI 和系统密钥库验证；独立 Web 网关的授权与隔离原型；嵌入组件/SDK 版本化。Android 已加入独立移动终端源码，仍需编译、持久签名、设备验收及桌面插件/AI 的移动适配。

0.3.0 已加入多基座 AI 会话、位置/机器/分组权限及三种审核等级；接下来验证真实供应商兼容性、补充非 OpenAI 协议适配、命令审计与断线后显式恢复策略。公开 GitHub 市场与下载需要完成仓库发布和各平台实际产物验证。
