# 0.8.7 收口记录

## 本轮功能

- 智能体 Enter 发送、Shift+Enter 换行；保留 Ctrl+Enter，中文输入法选词不误发。覆盖 CShell、机器智能体与 CAgent 原生窗口。
- 桌面更新按钮自动下载、校验并进入安装重开；Windows 保留原目录，取消关闭时不残留待执行安装。macOS 挂载并验证 DMG 内应用身份后准备替换，Linux AppImage 保留旧文件备份。Android 校验身份、版本和签名后进入系统安装；首次未知来源授权后继续。
- CAgent 更新覆盖 Windows 与私有运行时的 macOS/Linux 包。不能把系统 Node 安装当成受支持的私有运行时替换。Linux DEB 仍交由系统包管理器处理。
- 微信改为独立签名 `.cshellext` 包，不在公开市场显示；主程序与 CAgent 不捆绑微信实现和 Python 运行时。界面取消“实验”名称，实际版本兼容要求与授权保留。
- 自定义扩展支持文件选择、拖入、预览、确认导入、单独启用和卸载。默认不启用，不执行命令、不授予访问权限。普通外部包仅支持声明式命令贡献；原生微信包必须验证签名与逐文件摘要。

## 验证

- 开源与 Pro TypeScript、生产构建通过。
- 两套 Windows 实际打包程序通过原生加密存储、沙箱、SSH 终端、SFTP 和自定义扩展 IPC 流程测试。
- 19 项扩展/微信授权/消息事件测试通过；真实独立签名包经过隔离安装、默认拒绝、篡改拒绝及代码包解耦检查。
- 真实 React 界面测试验证公开市场隐藏、预览无修改、确认后停用、拖入、取消、卸载。使用实际全局样式检查页面。
- 完整 Pro 测试首次 453 项：449 通过、1 跳过、1 失败、2 超时取消。TLS 与反向连接独立重跑通过。WSL 测试改为分别等待冷启动和执行结果，并兼容 ConPTY 合并输出行；实际 Ubuntu PTY 与独立命令环境重跑通过。未改用户 WSL 配置。
- 原有更新回归已覆盖 SHA-256 失败拦截、取消关闭、安装仅执行一次、AppImage 备份回滚与真实 Linux CAgent 私有运行时替换重开。
- 官网 26 页、136 个索引章节、文档检索、链接和窄屏检查通过。

## 发布边界

0.8.2 等旧客户端若写死旧更新源，仍需从官网覆盖升级一次；新版可应用内更新。不跳转 GitHub 作为普通更新路径。Android 保留系统安装确认，macOS/Linux 不绕过系统权限。

Windows 未代码签名，macOS 未公证；多平台 CI 包验证不等于所有实体设备实测。微信独立包单独提供，不作为公开市场或公共发行附件发布。签名私钥不提交。

最终 GitHub、香港镜像、更新清单和本机安装验收应在附件完整性确认后追加，不把构建成功当作发布完成。
