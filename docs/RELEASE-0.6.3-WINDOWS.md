# CShell 0.6.3 — Windows x64

微信扩展的历史和通讯录工具现在主动读取数据，无需用户提前打开聊天、翻页或切换通讯录。通讯录工具提供真实数据库分页，保留准确 ID，并明确区分数据库记录与好友关系。

需要同时更新微信工具包至 0.1.1，仍只支持已核对的 Windows 微信 4.1.15.50 精确模块。权限设置、发送黑名单和默认关闭策略保留。历史仍限本地 message_0.db；微信重启后仍需重新绑定。未增加后台常驻监听、自动账号重绑或其他平台支持。

此原生适配仍为实验功能。验证包括真实空闲读取与分页，以及 Python/桌面后端检查；不代表长期稳定性保证。
