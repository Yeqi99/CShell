# CAgent 自动更新设置持久化

## 修复范围

快速连续切换“自动更新”时，原实现共享同一个临时文件并同时重命名，可能报 ENOENT。保存前就修改运行状态，也会在磁盘写入失败时出现界面与实际更新行为不一致。

现在按照调用顺序逐次写入，成功原子替换设置文件后才更新运行状态；每次调用返回自己已保存的值。读取等待此前的保存结束。失败保留之前的状态，后续修改仍可保存。关闭后的新请求继续拒绝；不改变下载源、权限、安装授权或更新校验。

## 验证

- 真实文件系统连续 40 次交替写入：旧实现失败，新实现全部成功，最终关闭状态在重新初始化后保持。
- 使用独立临时目录制造重命名失败：旧实现错误启用内存中的自动更新，新实现保留关闭状态；移除故障后再次保存成功。
- Core / Pro 各 9 项更新相关测试通过，双方 TypeScript 检查通过。

此修复在 0.8.13 冻结后完成，不属于该版本附件。后续发行应与其他实质改进一起构建，不移动旧标签、不替换已验证的安装包。
