# CShell 0.6.6 Windows

智能体新增 `get_permission_link`：无需业务授权即可查询已支持的权限节点，并返回可点击的内部定位链接。支持微信扩展各项授权、智能体应用能力、机器默认操作与机器访问范围。微信授权拒绝消息附带对应链接。

点击链接打开当前工作区的设置，滚动、高亮并聚焦目标节点。链接只导航，不勾选、不保存、不重试被拒绝的操作；用户修改后保存才生效。已有聊天输入与设置草稿保留。

仅接受内置节点目录中的 `#cshell-permission/...` 链接，不支持任意路径、执行参数或外部协议。工具返回的是入口，不宣称目标权限已启用；插件未启用时进入插件市场，仍需用户启用。

验证：8 项相关后端测试、生产构建，以及隔离桌面中由模型调用工具→返回 Markdown→点击跳转的完整验证。检查微信最近会话与智能体微信读取节点、键盘焦点、草稿保留、保存前权限不变。微信原生工具包仍为 0.1.2。
