# 下载页重构与架构筛选 · 2026-10-27

## 行为

产品、系统、处理器依次筛选，Linux 与 macOS 可直接选择 x64 / ARM64。只存在一种架构时恢复默认并收起处理器选择，避免隐藏全部结果。Android 通用 APK 不伪装特定架构；CAgent Android 无独立包时显示已有平台说明。

选择通过 product / system / arch 查询参数保存，支持分享、刷新和历史位置恢复；未知参数回退合法默认值，不拼接未经校验的选择器。不开 JavaScript 时保留全部安装包。

## 视觉

沿用新版首页深色工具区、薄荷色选中态与开放阅读面。产品和系统选择集中在工具区；安装包由重复卡片改为信息对齐的列表，版本、架构、格式、限制、校验和下载各有固定位置。手机维持全部导航、版本信息与下载操作，不隐藏能力或平台。保持原有附件地址和摘要。
