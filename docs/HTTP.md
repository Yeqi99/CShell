# HTTP 扩展

插件市场安装 HTTP 后，新建连接出现“HTTP 请求”。这是请求工作区，不是持续在线的机器会话；共用左侧分组、收藏、编辑和双击入口。

## 使用

1. 创建工作区，在“目标与智能体工具”中保存多个基础地址。
2. 新建请求，选择目标或完整 URL，编辑方法、参数、请求头、请求体。
3. 选择本机、SSH 或支持 HTTP 的 Agent 发送；未连接的机器可点击“连接发送方”进入原连接流程，不会回退本机。
4. 发送或取消，查看状态码、耗时、大小、响应头、格式化 JSON、文本和图片。HTML 仅展示文本，不执行脚本。
5. 保存请求；切换请求、工作区和主题保留草稿。历史可载入为新请求，不自动重发。

支持 GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS，以及 JSON、文本、URL 编码表单。认证通过请求头配置，敏感头输入隐藏。工作区、请求和历史独立加密，不进入外观方案。文件上传、自动 OAuth、cURL 导入和响应脚本暂未提供。

## 发送方

- 本机直接发送 HTTP / HTTPS。
- SSH 使用独立 direct-tcpip 通道，从所选服务器访问目标；不依赖 curl、不向终端输入命令，HTTPS 验证目标证书。禁用 SSH 转发时明确失败。
- Agent 使用独立认证 TLS 通道在受控电脑发送，需要受控端显式开放 HTTP 权限并重新授权控制端。取消请求不关闭终端。
- 其他 Provider 只有实现发送接口后才作为可用发送方；RDP、WSL 目前不提供此接口。

最多同时 6 个请求、超时 1–60 秒；本机/SSH 响应保留上限 1 MiB，Agent 64 KiB，超限标记截断。请求体最多 65,536 字符，Agent 另有 128 KiB 帧限制。不自动重试或跟随重定向。界面展示工作区最近 50 条历史，全局最多 200 条；旧响应正文超过约 20 MiB 后清理并标记截断。

## 智能体

工具默认勾选，可逐项取消。加入工具列表不等于授权：需在智能体权限开启 HTTP 工具并选择允许的 HTTP 工作区；远端发送还需授权发送方机器的 HTTP 能力。

`http_list` 查询工作区、请求和发送方；`http_save_request` 保存可见请求；`http_send` 发送；`http_history` 查询结果。使用已保存 requestId 可在后端使用认证头，不必把密钥传入模型。审核展示实际发送方、方法和目标；配置变化使旧审核失效。

人工和 AI 共用历史并标明来源，响应作为非可信数据。停用扩展或取消工具会阻止新调用。独立的 HTTP 定时任务编辑器尚未提供，后台常驻和跨机器编排按路线图推进。
