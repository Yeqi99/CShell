# 0.8.17 更新与微信扩展

状态：构建准备中，尚未发布应用。0.8.16 的下载恢复独立上线，不需要等待此版本。

## 更新下载

香港源返回 522 或超时时，客户端可从官方同渠道 Release 继续查询和下载。下载仍校验版本、架构、大小与 SHA-256，不打开浏览器，不混用普通版与 Pro 安装包。CAgent 的更新请求使用系统或环境代理，配置的代理失败不回退直连；暂不支持的 PAC/WPAD 明确提示。

为恢复旧客户端，下载域名的两份目录及 0.8.16 附件由独立边缘服务提供。只接管这四条路径，网站其他服务与 DNS 源站不变。香港源站仍不可访问，不能把下载恢复描述成源站已修复。后续发布必须同步边缘目录与附件白名单。详见 [更新源恢复](UPDATE-SOURCE-RECOVERY.md) 和 services/update-edge 的验收记录。

## 微信扩展

支持精确版本 4.1.15.56、4.2.0.12 的独立工具包。源码保存在私有仓库，市场安装公开二进制；配置、授权和账号绑定仍分别完成。文本收发与事件可接入通用定时任务和事件处理，不把业务任务写死在客户端。

4.1.15.50 完成生命周期与隔离加固，但其历史崩溃隔离未解除，不在市场提供为可用版本。4.2 的数据库、媒体和财务等尚未迁移的能力不显示为已支持。具体实测范围见 [微信接入进度](CAGENT-WECHAT-ROLLOUT.md)。

原生验证超时不会强杀回调进程。结果未知的操作保留状态，不自动重试；不同微信版本与进程创建时间隔离。市场下载采用系统代理、有限大包超时及完整摘要校验。
