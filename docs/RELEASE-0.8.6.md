# 0.8.6 发行记录

状态：2026-10-24 已正式发布。开源、Pro、CAgent、香港下载源、官网与本机均更新为 0.8.6。

## 改进

1. CAgent 关闭时取消更新网络请求并释放 app-host 管道；处理启动期间关闭的竞态，避免迟到的控制服务和 UI 再次启动。这些关联修复作为一项生命周期改进。
2. OpenCode 扩展和新会话加载时刷新模型目录，保留既有会话绑定；已保存模型不再提供时要求明确选择，不静默换成其他或收费模型。
3. 使用手册按任务重组，24 篇指南、124 个可搜索章节；新增批量导入、终端、网络出口、机器信息、OpenCode 和故障排查。支持正文搜索、章节直达、移动目录和示例复制。官网采用完整机器工作台展示及分场景介绍。
4. Pro 修复旧配置导入读取 OpenCode 凭据的位置，使用扩展实际存储目录，保留账号 ID 并按目标应用上下文重新加密。开源端不会执行 Pro 账号导入。

## 验证记录

- 官网 26 页结构检查，24 篇使用手册、124 章节索引；四平台下载选择、键盘导航、内部链接、正文搜索和 390px 无横向溢出检查通过。桌面与移动端截图已人工检查并修正标题断行和手机首屏目录密度。
- 两个工作树完整测试已执行，Windows ACL 子进程在并行负载下出现超时；失败日志保留，不能记为一次全绿。Pro 相关 9 项独立串行复测通过。开源对应复测、发行包和原生窗口验收继续进行。
- 文档使用同一 HTML 源导出到两个工作树的 docs/manual，避免开源与 Pro 手册分叉。

## 不能声称完成的事项

OpenCode 实际免费模型调用仍可能被服务商拒绝。未修改官方客户端的真实测试也返回 403 FreeTierError；官方客户端集成没有交付为可用功能。没有绕过地区限制、伪造客户端标识或未经授权启用收费模型。
