# 批量导入与账号迁移

<h2 id="csv">从 iShell 等软件导入 CSV</h2>
<ol><li>从原软件导出 CSV，保留原文件备份。CShell 不直接读取其他软件的私有加密库。</li><li>新建连接 → 批量导入，选择逗号、分号或制表符，再选择 CSV。</li><li>展开「CSV 列对应关系」，将地址、端口、用户名、密码、名称、分组、协议对应到源文件列。没有对应字段时留空。</li><li>缺少用户名时可填写统一默认值。修改映射后先点击「更新预览」。</li><li>核对有效行与错误行，选择「跳过重复项」或「另存为新连接」，勾选要导入的条目后确认。</li></ol><p>文件在本机解析，不发送给智能体。预览不会连接机器；密码只显示是否存在，不在列表明文展示。不同软件的 CSV 列名和协议表达不同，以预览的识别结果为准，不能保证任意私有导出格式都兼容。</p>


<h2 id="text">一次识别多条连接文本</h2>
<p>在批量导入文本框粘贴多条 SSH / RDP 信息并点击「预览连接」。例如：</p>
<pre><code>ssh alice@dev.example.com -p 22
ssh bob@test.example.com -p 2222</code></pre><p>逐条确认地址、协议、用户名和分组，再保存。无法识别的行不会自动执行；缺少密码可在真正连接时补齐。剪贴板导入提示只创建草稿，不会覆盖已有草稿或自动连接。</p>


<h2 id="account">把开源版或未登录配置载入 Pro 账号</h2>
<ol><li>登录目标 Pro 账号，进入账号页的「本机配置」。</li><li>选择「CShell 开源版」或「Pro 未登录工作区」，查看来源及条目数量。</li><li>对于不同的同名条目，逐项选择保留「当前账号」还是「本机来源」。所有冲突处理完后才能确认。</li><li>需要同时带入外观、扩展偏好和默认模型时，勾选对应选项。</li><li>点击「载入当前账号」后自动同步，原来源文件仍保留。</li></ol><p>模型及 OpenCode 等扩展凭据需要在原应用存储上下文解密，再在目标上下文重新加密。不能通过复制加密文件来保证可用。访问授权、浏览器登录状态与应用安装状态不在这次导入范围；同账号云同步的权限恢复是另一条流程。</p>


<h2 id="guest">清除未登录缓存与切换账号</h2>
<p>账号页「本机配置」提供「清除未登录数据…」。确认界面会列出未登录工作区的连接与凭据、模型、记忆、扩展、外观和浏览器数据。确认前确保其中需要的条目已经载入。</p>
<p>清除不会删除当前账号、云端数据、开源版原配置或 CAgent 设备身份。不同账号与未登录工作区相互隔离，不会把前一个账号的数据自动混到下一个账号。</p>


<h2 id="missing">导入后仍缺模型或连接</h2>
<p>先核对来源和当前账号，再查看冲突选择。配置导入成功不代表模型服务可访问：Key 失效、模型下架、服务商地区限制都会导致调用失败。遇到 OpenCode 账号缺失时，不要反复导入覆盖当前配置，先看<a href="https://shell.canp.ai/docs/opencode.html">OpenCode 故障说明</a>并保留原数据。</p>
