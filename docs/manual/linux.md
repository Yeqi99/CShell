<h2 id="section-1">下载</h2>

<p>从 <a href="https://shell.canp.ai/downloads.html">香港下载中心</a> 选择开源版 Linux x64 或 ARM64 附件。格式以实际发行列表为准。Pro 提供 x64 / ARM64 实验版 AppImage 和 DEB，在官网下载区选择架构与格式。CI 构建和协议测试已通过；尚未完成发行版及实体设备验收。</p>



<h2 id="section-2">桌面客户端与 CAgent</h2>

<p>CShell 桌面客户端需要可用图形环境。CAgent 独立运行，可提供已授权的终端、文件、HTTP 和管理能力，不依赖 Electron 或捆绑 Chromium。</p>

<p>Linux 的机器工作区、浏览器网络出口和原生图形应用是不同能力。不要将可视化工作区理解为已支持所有 Linux 原生桌面采集。</p>



<h2 id="section-3">应用与系统依赖</h2>

<p>应用目录按目标发行版实际检测到的 APT/DNF 等包管理器提供配方。不自动添加软件源、sudo 或替换系统依赖。不同 glibc、显示服务与发行版仍需对应环境验证。</p>
