<p>CShell 是连接机器、使用终端、管理文件与运行智能体的工作台。CAgent 是安装在目标机器上的独立智能体，也为 CShell 提供机器连接能力。</p>



<h2 id="section-1">选择产品</h2>

<ul>
<li><strong>CShell 开源版</strong>：MIT 许可，从 GitHub 下载，无需 Pro 账号即可使用本地工作台。</li>
<li><strong>CShell Pro 免费版</strong>：在共享核心上增加账号和云同步。各平台安装包及验证状态可在官网下载页查看。</li>
<li><strong>Pro 会员版</strong>：同一个 Pro 客户端，通过账号权益提供更大的配置空间与会员能力。会员购买尚未开放。</li>
<li><strong>CAgent</strong>：安装在希望管理的机器上；不需要安装完整 CShell。</li>
</ul>


<h2 id="section-2">第一次连接</h2>

<ol>
<li>在<a href="https://shell.canp.ai/#download">下载页</a>选择系统和版本，安装并打开 CShell。</li>
<li>点击「新建连接」，选择实际需要的 SSH、Windows 远程桌面或 CAgent 连接方式。</li>
<li>填写目标地址和认证信息；连接 CAgent 时核对目标设备身份。</li>
<li>在左侧连接列表双击机器，进入所属工作区。文件、终端与应用始终操作这台机器。</li>
</ol>


<h2 id="section-3">使用 Pro 同步</h2>

<p>从主页账号入口注册或登录。登录后连接、模型及支持的设置自动同步，不需要每次手动上传。运行中的终端会话属于当前设备，不会跨设备迁移。详见<a href="https://shell.canp.ai/docs/cloud.html">账号与同步</a>。</p>
