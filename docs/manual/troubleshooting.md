<h2 id="sync">登录状态与本机工作区不一致，已停止云同步</h2>
<p>这是隔离保护，不能通过删除工作区标识或复制其他账号数据来绕过。先记录当前版本与登录邮箱，正常退出并重新打开相同版本的 Pro，核对账号页。仍异常时保留本机数据再反馈；不要立即清除未登录缓存或重复导入。</p>
<p>连接、模型、权限分别检查。权限云恢复不意味着远端 CAgent 的本地授权也被覆盖。遇到策略冲突应明确选择，不自动取更大的权限集合。</p>


<h2 id="browser">这台机器的浏览器已在另一工作区打开</h2>
<p>先查找该机器已有的工作区或浏览器窗口，关闭重复窗口后重试；确认客户端版本。手机访问过并不应永久占用桌面端的本地浏览器。若没有任何活动窗口仍报占用，正常退出当前 CShell 再打开并记录复现步骤。</p>
<p>不要删除浏览器整个数据目录来释放占用，这会丢失 Cookie 和登录状态。断网时网页请求失败应先恢复所选机器连接，不改成本机直连来掩盖故障。</p>


<h2 id="permissions">智能体说没有权限，或 Unknown permission node</h2>
<p>先查看展开的工具调用和实际目标。在访问权限中检查应用能力、机器范围和单机覆盖，再检查目标 CAgent 自身授权。「全放行」只改变审核方式，不扩大能力范围。</p>
<p>Unknown permission node 表示工具参数中的权限名称不被识别，不等于所有权限都关闭。模型可能生成了不存在的名称。保留工具名称与错误并更新客户端，不手工编造权限节点。简单任务可改为明确的只读请求，例如“查询这台机器 CPU 型号，不修改系统”。</p>


<h2 id="connection">桌面能打开，机器却无法连接</h2>
<p>离线桌面保留入口和上下文，不代表网络已连通。点击右下角连接状态重试，检查地址、端口、凭据和设备身份。SSH 能连接不代表 RDP 或 CAgent 已安装可用；只有 RDP 登录信息时，也不保证存在可执行远程安装的管理通道。</p>


<h2 id="model">Key 正确但模型无法回复</h2>
<p>分别检查目录、认证、推理错误。401 常涉及认证，403 可能是权限或地区，429 涉及限流或额度，超时可能是出口网络。不要只凭一次连接测试判断生成一定可用。OpenCode 详见<a href="https://shell.canp.ai/docs/opencode.html#403">免费模型限制</a>。</p>


<h2 id="update">升级后版本没变或找不到下载</h2>
<p>核对正在运行的是开源版还是 Pro，以及实际安装目录。两者可以并存，不应交叉安装或用一个渠道覆盖另一个。官网下载选择正确系统和架构；下载完成后核对摘要，再执行对应安装器。Android 必须经过系统安装确认。</p>
<p>不要修改旧发行标签来冒充新版本。macOS 签名公证和 Linux 实机验证状态见<a href="https://shell.canp.ai/docs/releases.html">版本说明</a>。</p>


<h2 id="feedback">怎样反馈才容易复现</h2>
<p>按“版本 / 系统 → 入口 → 操作 → 预期 → 实际”描述，附不含秘密的截图与错误时间。注明是在本机、SSH、CAgent 还是 WSL；浏览器与模型问题注明出口。日志不要包含 Key、密码、私钥或 Cookie。</p>
