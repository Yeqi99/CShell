<h2 id="open">打开正确环境的终端</h2>
<p>双击左侧机器，在桌面打开「终端」。只有 SSH 信息的机器也可先打开桌面，连接成功后再使用终端和文件。本机 Windows 可选 CMD / PowerShell；WSL 从已启用扩展选择真实安装的发行版。连接断开时，保留的输出是历史，不代表命令仍可执行。</p>
<p>切换工作区保留终端与滚动历史；关闭终端和切换标签不同，关闭前确认前台任务是否仍在运行。极简视图和独立小窗复用会话，可从还原入口回到工作台。</p>


<h2 id="keys">Ctrl+C 复制、Ctrl+V 粘贴，同时保留 Linux 按键</h2>
<p>默认剪贴板模式下，选中文字后按 Ctrl+C 复制，Ctrl+V 粘贴；未选择文字的 Ctrl+C 不发送中断。Ctrl+Shift+C / Ctrl+Shift+V 仍可用于复制粘贴。</p>
<ol><li>需要停止运行中的命令时，展开终端快捷键栏，点击「中断 · Ctrl+C」。</li><li>栏中也有挂起 Ctrl+Z、结束输入 Ctrl+D、原生 Ctrl+V 和 Esc，操作只发送给当前有效终端。</li><li>需要完全遵循 Shell / Vim 按键时勾选「原生按键」；要长期采用原生行为，在终端偏好中关闭剪贴板快捷键。</li></ol><p>粘贴多行命令可能由远端 Shell 按换行处理。先检查文本再粘贴，尤其不要把解释性文字或密码粘入正在运行的程序。</p>


<h2 id="appearance">字号、配色、链接与命令候选</h2>
<p>在外观设置调整终端字体、字号和明暗配色，和界面字体分开设置。终端也支持 Ctrl+Shift+= 放大、Ctrl+Shift+- 缩小、Ctrl+Shift+0 还原。</p>
<p>终端保留远端 ANSI 颜色，并提供受支持内容的视觉强调。程序本身的全屏绘制与颜色仍由程序决定，不会把所有输出重新解释成语法代码。链接打开前应确认地址。</p>
<p>启用 Shell 联想扩展后，候选仅补全输入，不自动回车。密码输入和全屏程序不应出现普通 Shell 候选。Vim / Nano 操作面板依赖有效编辑器状态，不能仅凭日志里出现编辑器名称就执行操作。</p>


<h2 id="files">上传、下载与编辑文件</h2>
<ol><li>在目标机器桌面打开「文件」，核对当前目录与机器名称。</li><li>选择文件后使用带悬浮说明的上传、下载、复制、粘贴等工具。目标目录必须在当前账号可访问的范围内。</li><li>遇到同名文件先处理覆盖冲突；查看所属操作的进度与错误，不把开始传输视为完成。</li><li>编辑内容保存前核对目标路径。断开、权限不足或文件变化时，先保留草稿再处理错误。</li></ol><p>CShell Pro 云同步保存配置，不会把远端文件作为网盘上传。删除、安装和传输的目标都是当前机器；把文件拖回原目录不应产生一次新的移动。</p>


<h2 id="troubleshoot">终端不响应或显示异常</h2>
<ul><li>有历史输出但无法输入：检查连接状态和是否处于仅观察模式。</li><li>Ctrl+C 没有停命令：检查剪贴板模式，使用快捷键栏的中断按钮。</li><li>中文错位：选择支持中文的等宽字体，检查字号和远端编码。</li><li>安装日志提到 Vim 却未打开工具条：这是正常的，工具条只应服务实际编辑器。</li><li>文件操作被拒绝：检查目标路径和远端权限，不以切换界面绕过授权。</li></ul>
