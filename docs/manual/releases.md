SFTP：</strong>桌面端新增独立文件连接，支持浏览、上传、下载、重命名、建目录与传输队列；文件连接不启动 Shell。FTP 不提供未实现的递归传输或文本编辑。<a href="https://shell.canp.ai/docs/connections.html#default-connection-view">设置打开方式</a>。</li><li><strong>工作台与 CLI：</strong>概览、命令台、可视化三种视图共用能力目录，支持独立命令台标签、草稿、契约查询和真实调用。命令台不是 CMD 或 PowerShell。<a href="https://shell.canp.ai/docs/plugin-authoring.html#process-tools">制作工具扩展</a>。</li><li><strong>模型选择：</strong>OpenCode 账号下动态列出模型，不必逐个填入基座；失效状态同步到设置，已有会话保持原选择。接入官方运行时不等于服务端允许所有模型。<a href="https://shell.canp.ai/docs/opencode.html">查看接入与实际拒绝状态</a>。</li><li><strong>界面与兼容：</strong>侧栏字号收进右键折叠设置，默认字号更紧凑；窄面板分类不再竖排挤压。硬件与市场按机器实际能力读取，RDP-only 安装入口改为 Windows 安装指南。支持新协议的 CAgent 功能，并保留不消费的云配置字段；不把桌面能力标成手机已实现。</p><h2 id="release-087">0.8.8 · 应用内更新与智能体输入</h2><p>开源版与 Pro 使用香港源，在应用内连续下载、校验并安装。各平台的系统确认仍保留；CAgent 也提供原位更新。智能体统一 Enter 发送、Shift+Enter 换行，兼容中文输入法和已有会话。</p><h2 id="section-1">0.8.5 · 升级与退出</h2><p>开源版与 Pro 同步修复三项问题：智能体任务运行时退出会提示，取消退出保留任务；CAgent 的 Windows 文件版本与发行版本一致；静默升级刷新已有快捷方式的图标，不重建已删除入口，也不修改其他安装的快捷方式。</p><h2 id="section-2">0.8.4 · 统一机器工作区</h2><p>开源版与 Pro <h2 id="section-3">Pro 账号与网络</h2><p>登录后自动同步账号配置；开源版和未登录数据先预览，再由你选择载入。新增权限配置恢复、未登录缓存清理、共享基座与习惯记忆。同账号 CAgent 自动发现，会员可使用免公网 IP 连接和应用机器出口。受控端权限仍由目标机器授权。</p>
<h2 id="section-4">浏览器与终端修复</h2><p>同一机器的多个工作区复用本机浏览器标签，失效占用自动释放；手机和电脑的本地浏览器互不占用。断线不回退本机网络，浏览器可重试；终端断线历史和独立小窗会话保留。</p>
<h2 id="section-5">0.8.8 正式包的平台验证</h2><p>Windows x64 已完成实际安装包启动、SSH、终端与文件流程验证；Android 提供签名 APK，并完成 Android 29/35 模拟器原生测试。macOS 与 Linux 提供已构建的 ARM64 / x64 包；实体设备和不同发行版仍需验证。macOS 未做 Apple 公证，Windows 安装器未做发行者代码签名。</p>

<h2 id="one-click-update">一键更新</h2><p>CShell 0.8.8 起，在「设置 → 关于与更新」点击<strong>立即更新</strong>，应用会下载当前产品和架构对应的安装包、校验后继续安装。全过程使用香港更新源，不需要打开 GitHub。自动下载完成时，点击「安装并重新打开」即可。</p><ul><li><strong>Windows：</strong>保存当前任务后安装到原目录并重新打开。有运行中会话时会先确认；取消退出也会取消本次安装。</li><li><strong>Android：</strong>下载后直接进入系统安装确认。首次需要允许 CShell 安装应用，返回后继续安装；不会绕过系统确认。签名或包身份不一致时停止，不要求卸载或清空数据。</li><li><strong>macOS：</strong>验证 DMG 内的应用身份与版本，在有写权限的原应用目录替换并保留备份。仍受系统安全检查与未公证限制。</li><li><strong>Linux：</strong>AppImage 可原位更新并保留旧程序。DEB 安装仍通过系统包管理器处理，不能把非 AppImage 安装方式当作可直接替换。</li><li><strong>CAgent：</strong>原生窗口或「设置与权限 → 应用更新」提供检查与更新。Windows 使用安装程序；Linux/macOS 独立私有运行包原位更新并用原数据目录重新启动。程序内嵌数据目录、系统 Node 启动或不可写目录会停止自动替换，防止损坏数据与环境。</li></ul><h2 id="legacy-update">0.8.2 等旧版本怎么升级？</h2><p>旧客户端若仍显示「打开 GitHub 下载页」或找不到安装包，其更新源和匹配规则已写在旧程序内，服务器不能直接改掉。请从<a href="/downloads.html">香港下载中心</a>下载对应产品，覆盖安装一次；不要卸载或删除配置。之后使用应用内更新。开源版与 Pro 必须选择各自渠道，不能互相覆盖。</p><h2 id="install-flow">安装、升级与保留数据</h2><ol><li>在下载页选择开源版、Pro 或 CAgent，再选系统和处理器架构。会员与免费 Pro 使用同一客户端。</li><li>开源版、Pro 和 CAgent 均可使用香港下载源，无需跳转 GitHub。核对包名、版本和 SHA-256 摘要。</li><li>升级前处理正在运行的任务，按对应安装程序执行。保留原安装路径与数据，不用另一版本覆盖当前渠道。</li><li>重新打开后核对关于页版本、账号、连接与模型。没有更新不等于安装失败，也可能是当前已为该渠道最新版。</li></ol><p>Windows 包未签名，macOS 包未签名 / 公证；macOS 与 Linux 仍有实机验证限制。Android 需要系统安装确认，不能声称所有设备已静默升级。</p><h2 id="remove">卸载与重装</h2><p>卸载客户端程序与删除用户数据是两件事。若希望重装后保留连接和身份，先确认安装器的数据选项并备份；不要手工删除 CAgent 身份目录或跨设备复制私钥来“恢复”。</p><p>清除 Pro 未登录缓存使用账号页专用入口，不把卸载程序作为清理云账号的方法。云端数据、远端文件和服务器上已安装的软件不会因卸载本机客户端自动消失。</p>
