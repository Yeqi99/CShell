# 连接、终端与文件

<h2 id="section-1">连接列表</h2>
<p>SSH、SFTP、FTP / FTPS、RDP 和 CAgent 连接共用左侧列表，可命名、分组、收藏和编辑。双击连接；修改配置或删除记录从菜单进入。删除分组保留连接。首次身份提示用于确认目标，不能因为名称相同就忽略指纹变化。</p>
<h2 id="section-2">终端</h2>
<p>终端绑定真实连接。切换工作区保留正在运行的会话、滚动历史与草稿。Windows 本机可使用 CMD、PowerShell；WSL 从扩展中进入真实检测到的发行版。远程 CAgent 使用目标系统支持的终端。</p>
<p>命令联想只补全输入，不自动执行。默认便捷按键模式中，选中文本后 Ctrl+C 复制，Ctrl+V 粘贴；没有选区时 Ctrl+C 不发送中断。需要停止命令时，展开终端快捷键栏点击「中断」，或切换为原生按键模式。Ctrl+Shift+C/V 仍可复制粘贴，设置中可持久化选择按键模式。密码提示、全屏编辑器与断开状态不应继续显示普通 Shell 候选。</p>
<h2 id="section-3">文件和编辑</h2>
<p>从机器的「文件」进入上传、下载和目录浏览。SSH 文本编辑器与 Python 扩展按目标实际能力开放。保存发生冲突时先核对远端内容，不直接覆盖。Android 本机文件通过系统目录选择器授权，不等同于整个手机文件系统访问。</p>
<h2 id="section-4">断开与恢复</h2>
<p>连接失败时检查地址、认证与目标服务状态。未连接时监控不代表实时值；浏览器的远端网络断开后不会自动改用本机网络。关闭会话前先保存编辑内容。</p>
<p>协议和平台细节：<a href="https://github.com/Yeqi99/CShell/blob/main/docs/CONNECTION-PROVIDERS.md">连接 Provider</a>。</p><h2 id="section-5">批量导入与统一桌面</h2><p>新建连接中的批量导入支持 CSV 文件与多条明确连接文本。CSV 可选择分隔符并映射主机、端口、用户名、密码、分组等列；先预览、处理重复项，再确认保存，不自动连接。第三方导出需具有可识别字段，不能直接读取专有加密备份。</p><p>默认双击 SSH 进入原生终端，RDP 进入远程桌面，CAgent 进入机器工作区。也可在连接右键菜单打开可视化桌面，或勾选「默认以可视化打开」记住该台机器的选择。可视化桌面离线仍可打开，右下角显示真实连接状态并提供重试。</p><h2 id="section-6">终端快捷键与配色</h2><p>默认 Ctrl+C 复制选区，Ctrl+V 粘贴。没有选区时 Ctrl+C 不发送中断。展开终端“快捷键”栏可发送中断、挂起、结束输入与原生按键；设置中可切回原生快捷键。提示符和链接提供辅助配色，保留程序原有 ANSI 颜色，不改变原始输出或复制内容。</p><h2 id="section-7">延迟测试</h2><p>连接诊断可测试本机到目标，或由有执行权限的机器 A 测试目标 B。显示源、目标、TCP 握手采样结果及失败数；远端执行失败不会改为本机测量。</p><h2 id="file-protocols">FTP、FTPS 和 SFTP 文件连接</h2><div class="table-scroll"><table><thead><tr><th>协议</th><th>默认端口</th><th>认证与用途</th></tr></thead><tbody><tr><td>SFTP</td><td>22</td><td>SSH 密码或密钥；只建立文件通道，不要求 Shell</td></tr><tr><td>FTPS</td><td>21</td><td>FTP 显式 TLS；校验证书与主机名，不降级为明文</td></tr><tr><td>FTP</td><td>21</td><td>账号密码；传输不加密，适用于明确需要明文协议的服务</td></tr></tbody></table></div><ol><li>点击「新建连接」，选择文件协议，填写真实地址、端口和认证信息。</li><li>SFTP 首次连接核对 SSH 指纹；FTPS 使用有效证书。协议选择以目标实际服务为准。</li><li>连接后直接进入「文件」，通过路径栏浏览，上传、下载、建目录、重命名或删除。</li><li>在底部队列查看当前会话的真实字节进度、失败原因或取消。断线后先确认目标状态再重新连接，操作不会自动重放。</li></ol><p>FTP / FTPS 当前支持普通文件传输和空目录删除；不提供文本编辑、跨连接复制或递归目录传输。SFTP 可编辑文本；服务器不支持安全原子替换时，保存已有文件会说明原因，不直接覆盖原文件。</p><p>CSV 与明确的 SFTP / FTP / FTPS 连接字符串也可批量导入。预览隐藏密码，确认后加密保存；导入不会自动连接。路径、查询参数等不作为服务器连接地址导入。</p><h2 id="visual-ssh-tools">可视化 SSH 中的文件与信息</h2><p>打开可视化桌面的终端，点击右上角「文件与机器信息」展开原 SSH 文件区和监控，默认收起。终端仍使用同一 SSH PTY，切换视图保留历史。收起或断开后停止后台监控；文件路径和编辑草稿保留，断开后停止自动保存。</p><section><h2 id="default-connection-view">默认打开方式与侧边栏</h2><p>在设置 → 工作区中选择「原始连接方式」或「可视化桌面」。默认使用原始连接方式：SSH 进入终端，RDP 打开远程桌面。连接右键菜单的「默认以可视化打开」单独覆盖该台机器；全局修改不会重建已运行的会话。CAgent、HTTP 和文件协议各自保持对应工作区。</p><p>旧版未记录可视化默认值是否由用户主动选择。升级时，没有明确选择标记的旧可视化默认会迁移为原生；需要时可重新选择可视化，此后的明确选择会保留。Pro 同步全局偏好和单台连接覆盖值。</p><p>侧边栏空白处右键，展开「外观设置」，微调分组、服务器、地址字号和间距。默认分组 14 px、服务器与地址 12 px，界面 14 px；已有自定义字号保留。侧栏与终端最低 8 px，界面最低 9 px。</p></section>
