<h2 id="section-1">注册与登录</h2>
<p>在主页右上角进入账号页。邮箱验证码用于注册，也可使用固定密码登录。登录后自动同步，无需手动启动同步。</p>



<h2 id="section-2">第一次登录：选择要载入的配置</h2>
<p>检测到开源版配置或 Pro 未登录数据时，会分别显示来源与条目概况。查看后确认才载入；不会自动上传旧数据。重复连接和模型由你选择保留当前内容或使用来源内容。旧工作区的访问授权不随本机导入迁移。</p>
<p>设置 → 账号与云同步 → 本机配置，可以再次载入来源，或清除未登录缓存。清除前会列明范围并要求确认；账号云端数据、开源版原文件和设备身份不会删除。切换账号分别使用独立工作区。</p>



<h2 id="section-3">自动同步的内容</h2>
<p>连接与加密凭据、模型基座、OpenCode 账号、扩展设置、视图和偏好、支持的浏览器历史与收藏、习惯记忆，以及 CShell 智能体访问策略随账号同步。权限保留机器范围与单机覆盖；多端同时更改策略会要求处理冲突，不自动合并为更大授权。</p>
<p>CAgent 自身远程访问授权、设备身份、运行中进程、终端输出、远端文件和浏览器 Cookie 不作为通用配置恢复。Android 保留暂不使用的加密云字段，避免手机保存覆盖桌面扩展配置。</p>



<h2 id="section-4">同账号设备</h2>
<p>CAgent 登录后显示 Pro 身份标识，并由同账号 CShell 自动发现。标识代表登录身份，不代表已付费。会员可使用中继连接无需公网 IP 的在线机器，连接仍验证设备身份与访问权限。</p>



<h2 id="section-5">应用网络出口</h2>
<p>设置 → 网络与代理，可选直连、手动 HTTP/HTTPS/SOCKS5 代理，或会员账号中的机器作为出口。例如选择美国机器后，受支持的模型 API 请求通过该机器访问。出口不可用时请求失败，不回退本机网络。</p>
<p>CAgent 机器内也可选择另一台同账号机器作为受支持应用的出口。新终端中的程序需支持 ALL_PROXY；已有终端不会自动改环境。此功能不接管全机流量、UDP 或第三方应用的独立网络实现。</p>

<h2 id="sync-0810">0.8.10 准备中：排序与扩展账号同步</h2>
<p>本节对应正在验证的补丁，当前正式下载仍为 0.8.9。补丁修复按 ID 合并配置时顺序丢失的问题，保留连接等有序列表的排列；Android 保存账号配置时保留手机暂不支持的 FTP / SFTP 连接位置与未知字段，不将它们转换成 SSH。</p>
<p>Tavily 账号及 Key 纳入加密云同步和确认后的本机导入。是否允许按量付费、扩展安装状态和运行授权仍由本机管理，不随账号复制。没有配置过 Tavily 时不增加空字段；明确删除最后一个账号后记录空列表，避免其他设备把已删账号恢复。旧云数据缺少该字段时保留本机内容，失败回滚恢复原状态。</p>


<h2 id="sync-compatibility-0810">新增同步内容与旧客户端</h2>
<p>0.8.10 新增可选的 Tavily 与机器桌面外观加密段。账号写入新段后，应使用支持它的新版桌面客户端；0.8.9 会安全拒绝不认识的段，不会为兼容而清空云端。没有新段的账号继续按已有格式同步。</p>
<p>机器桌面的背景、主题、命名方案与对应图片纳入本轮同步验证；窗口位置、临时运行状态和原生桌面会话不会作为外观恢复。最终范围见本页和版本验收记录，不把同步外观当作复制设备权限。</p>
