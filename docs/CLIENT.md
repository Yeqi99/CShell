# CShell Agent（0.6.0 开发版）

Agent 是独立轻量受控端，使用 Node 与原生 PTY，不携带 Electron/Chromium。CShell 的 **Agent 扩展**负责配置本机或已连接的远端 Agent；关闭 CShell 不会退出独立 Agent。控制端新建连接选择 CShell Agent；内部保留兼容的 `client` 协议标识。

运行 Agent 的 `run` 命令启动本机受限管理入口，远程监听仍关闭。在 CShell 插件页配置监听 IP、端口、对外地址、密码和权限，再显式启动远程访问。终端选择只列出真实环境：Windows CMD/PowerShell/WSL 发行版，Linux/macOS Bash/Zsh/Sh。首次连接先核对证书身份，再发送密码；之后使用设备证书连接。监听或密码变更会断开连接，需明确确认。CLI 的 `recover` 提供本机恢复说明。

本机通过仅当前用户可读的发现文件和随机凭证接入回环控制接口，不扫描局域网、不自动授权。旧 Windows Client 可在新 Agent 首次配置前，从插件页显式导入旧身份、加密凭据和授权；旧数据保留，不自动监听。新增 HTTP 请求、远程管理、服务托管、中继权限默认关闭。控制端已有连接名称、分组、收藏不变。

HTTP 请求工具调用接口；Agent 的 HTTP 服务模块提供接口，两者职责分开。服务默认回环监听，支持固定响应、回调记录、自定义代码。代码在有限时/有限输出的独立工作进程运行，拥有 Agent 系统账户权限，**不是权限沙箱**；启动需单独确认代码。人工和 AI 共用后端权限、配置版本与启停日志。当前托管运行于 Agent 主机，不冒充 WSL 环境。

可选中继支持 A 可达目标的直连转发，以及内网 B 主动连接 A 的反向通道。注册凭证与控制端转发凭证分开；中继核验外层身份，控制端仍在内层 TLS 核验目标 Agent 身份。默认关闭、限制连接数/流量、凭证单独复制，不自动改防火墙。安装包与公网/各平台验证状态以发布记录为准。

Windows Agent 的 WSL 页在目标机器检查、生成安装计划、执行安装和初始化真实 Linux 用户。需要管理员时由用户在目标机器明确操作，不静默提权或重启；网络代理配置也只修改目标 Windows。Agent 连接选择具体发行版，命令执行绑定该环境；WSL 终端连接不提供冒充 Windows 主机的 HTTP 发送能力。详见 [HTTP 联动](HTTP.md)。

以下为旧独立 Client 0.1.0 的历史说明，不是新版安装流程。

## 历史：独立 Client

CShell Client 是独立 Windows 受控端，通过 GitHub 分发；CShell 主程序提供发行页入口。[0.1.0 Windows x64 安装包](https://github.com/Yeqi99/CShell/releases/download/v0.5.0/CShell-Client-0.1.0-win-x64.exe) 与主程序 0.5.0 一同发布，校验值见该版本 SHA256SUMS.txt。

## 连接流程

1. Client 设置监听接口、端口、至少 12 字符的连接密码及允许打开的 CMD / PowerShell，保存后启动服务。
2. CShell → 新建连接 → 添加连接记录 → 连接方式选择 CShell Client。手动填写地址、端口、密码，或点击“粘贴连接信息”读取 Client 复制的信息。
3. 核对受控电脑上的设备指纹后连接。成功后连接记录统一保存在左侧服务器列表，可命名、分组、收藏和双击连接；再次打开终端使用已授权的设备证书。
4. Client 的“复制连接信息”包含地址、端口、设备标识和公开证书，不含密码、长期私钥。通过其他可信方式提供密码。

默认不启动监听、不提升权限、不修改防火墙。监听默认回环接口；连接其他电脑时应选择本机真实网络接口。密码与权限修改要求先停止服务，保存新密码清除所有已授权设备。单独撤销设备会即时断开其终端；持有当前密码的人仍可重新申请连接，彻底收回共享密码访问需更换密码。

## 连接方式

新建入口支持 SSH、CShell Client、本机 PowerShell、CMD；启用 WSL 插件后列出真实检测到的发行版。RDP 使用 Windows mstsc 独立窗口，认证由系统客户端完成，目前不嵌入工作台，也不提供 RDP 配置保存。未实现的 Telnet / VNC / FTP 不显示成可用选项。

## 安全边界

- 原生 TLS 1.3 与客户端证书。首次手动检查仅获取设备公开信息，不发送密码；用户确认身份后，重新建立连接并固定证书指纹，身份变化时拒绝发送密码。
- 密码由 scrypt 和随机盐派生摘要，连同权限、身份与授权记录通过 Windows DPAPI 独立加密保存；无安全存储时拒绝降级明文。不进入外观方案。
- 每分钟全局最多五次密码注册尝试，跨连接和更换客户端证书共享限制。证书授权后仅能打开 Client 授予的 Shell。密码变更先清除设备授权，再提交新摘要；服务启动与密码修改互斥。
- 协议 v1 暂保留旧单次邀请的兼容接口，新的界面使用地址与密码；复制信息的 JSON 不包含邀请令牌。设备证书授权后无需每次重复传密码，控制端不保存密码。
- 会话具有握手、空闲与请求超时以及连接、帧大小、输出缓冲限制。断连、撤权与停止释放 ConPTY。审计仅记录元数据，不记录输入输出和密码。

## 交互与工程

Client 使用 560 × 580 紧凑窗口；连接、授权控制端、活动与设置按需切换，服务启停始终可见。语言、主题与编辑状态切换不重建服务。主程序连接方式切换保留草稿。WSL 环境安装仍待接入 Client，不放置空入口。

`pnpm build`、`tests/client.test.ts` 和 `scripts/client-smoke.ts` 验证真实 TLS 与本机两个独立进程。覆盖密码、限流、设备探测、证书替换前不发送秘密、改密清除授权、复制信息不含密码、权限限制、CMD / PowerShell 的真实 ConPTY 输出及撤权断连。UI 还覆盖复制填入与手动检查设备、连接方式切换保留草稿、中英文与主题、窄窗口。

当前仅本机回环完成集成测试，未验证跨机器局域网、RDP 登录、休眠恢复和长期网络中断。没有 NAT 穿透、中继、无人值守 Windows 服务、文件传输、屏幕控制或 Client AI 工具。

本次验证结果：60 项单元/集成测试及两端打包版双进程界面回归通过，GitHub Windows 检查也已通过。Windows 包未代码签名；安装前可核对发行页校验值。

## 左侧列表统一管理

不再提供独立 Client 设备页。启动时将旧 Client 记录补入公共连接配置，保留加密身份和证书授权；重复启动不会覆盖自定义名称、分组、收藏和默认终端。公开配置只保存连接元数据，认证材料仍在独立加密仓库中。删除 Client 连接同时移除控制端配对记录，避免下次启动重新出现。Client 元数据不能走 SSH 连接通道。

60 项测试通过；本机双进程界面回归覆盖创建后出现在侧栏、收藏切换、编辑名称与分组、切换默认终端后双击重连，以及旧会话保持和撤权断连。
