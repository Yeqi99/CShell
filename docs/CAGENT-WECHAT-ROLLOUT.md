# 微信扩展接入进度（2026-10-31）

## 分发与安装

微信工具实现和构建脚本保存在私有仓库 `Yeqi99/Weixin-Toolkit`。CAgent 通用能力、任务调度与事件接口仍按本项目许可证提供。

发行时，只有二进制、许可证、接口说明、兼容清单与摘要进入公开 Release。市场按固定清单直接下载，不要求安装者访问私有仓库，不向客户端附带维护者的 GitHub 凭据。公开附件发布及匿名下载校验前，不添加市场条目。

新受管协议要求 CAgent 0.8.17 或更新版本；当前已发布的 0.8.16 不含此次接入。本次尚未发布新应用或把未验证附件加入市场。

安装、服务配置、操作授权、微信进程绑定、原生验证分开进行。配置在扩展详情中完成，服务凭据留在后端。绑定需要用户选择实际进程，不自动挑选账号。完成配置及授权的服务随后随 CAgent 启停；退出采用正常清理，不关闭微信。

## 已验证内容

- 两个独立 Windows 工具包支持初始化、前台服务、健康检查、正常停止、进程查询、显式绑定和原生验证命令；不依赖用户安装 Python。
- 固定清单、文件摘要、公开下载来源、独立授权、回调签名及操作所有权有自动测试。
- 通用自动化支持定时任务、事件来源/类型、可选字段筛选、持久队列、过期、暂停、取消和运行记录。执行沿用原调用方权限与审核；不重放结果未知的操作。
- Core 与 Pro 接入相同框架；Pro 的账号、云同步和网络功能在合并时保留。
- 扩展配置界面在 1000 与 360 像素宽度检查了进程选择、绑定、原位错误、配置保存和横向溢出。
- 本机 4.1.15.56 通过真实受管链路：校验文件、隔离测试配置、显式绑定、只读原生验证、启动 API、查询异步状态、正常停止。测试没有发消息，没有修改已有微信配置。
