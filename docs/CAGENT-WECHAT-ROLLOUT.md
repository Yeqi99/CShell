# 微信扩展接入进度（2026-10-31）

## 本轮版本与加固

独立工具包版本为 **0.1.1**，与微信版本分别编号。4.1.15.56 与 4.2.0.12 各自绑定精确 DLL 摘要、配置目录和验证记录；不能把旧版本的绑定带到新版本。4.1.15.50 的历史崩溃隔离保留，不加入可安装市场条目。

4.2.0.12 已接入与旧版相同的 CAgent 配置、能力调用及事件框架，仅声明已迁移的文本收发、状态与操作查询。研究源已有文件传输助手收发、签名回调、幂等和清理验证；新冻结包另通过冷启动、鉴权、配置隔离及正常退出验证。本轮没有重新向真实联系人发送消息，不将冷测试描述为实机业务验收。联系人和群聊文本接口按授权可调用，其实测覆盖与长期稳定性单独记录；数据库历史、媒体、朋友圈与财务能力不属于此包。

原生操作超时或无法证明卸载完成时，任务标记为结果未知，保留回调所需的进程，不强杀、不重放。API 与验证命令共用按微信 PID 和进程创建时间隔离的执行锁；重启服务不能清除尚未确认的原生状态。业务未就绪时，HTTP 健康检查不会冒充微信功能可用。

0.1.1 两个旧版包完成 16 项构建与隔离回归；4.2 包完成 20 项回归及独立冷启动验收。HTTP 服务 44 项测试、CAgent 验证生命周期 16 项测试通过。源码仅在私有仓库，公开市场附件不得包含明文实现或用户数据。发布状态以下方分发记录为准。

## 分发与安装

微信工具实现和构建脚本保存在私有仓库 `Yeqi99/Weixin-Toolkit`。CAgent 通用能力、任务调度与事件接口仍按本项目许可证提供。

发行时，只有二进制、许可证、接口说明、兼容清单与摘要进入公开 Release。市场按固定清单直接下载，不要求安装者访问私有仓库，不向客户端附带维护者的 GitHub 凭据。两个工具包已发布至 [wechat-toolkit-v0.1.1](https://github.com/Yeqi99/CShell/releases/tag/wechat-toolkit-v0.1.1)，并经生产安装器匿名下载及完整摘要校验后加入固定市场目录；没有提供维护者凭据。

新受管协议要求 CAgent 0.8.17 或更新版本；0.8.16 不含此次接入。0.8.17 应用发行已正式公开，三个本机应用最终包已安装并启动；工具包与主程序仍各自保留独立版本和验收记录。

安装、服务配置、操作授权、微信进程绑定、原生验证分开进行。配置在扩展详情中完成，服务凭据留在后端。绑定需要用户选择实际进程，不自动挑选账号。完成配置及授权的服务随后随 CAgent 启停；退出采用正常清理，不关闭微信。

## 已验证内容

- 两个独立 Windows 工具包支持初始化、前台服务、健康检查、正常停止、进程查询、显式绑定和原生验证命令；不依赖用户安装 Python。
- 固定清单、文件摘要、公开下载来源、独立授权、回调签名及操作所有权有自动测试。
- 通用自动化支持定时任务、事件来源/类型、可选字段筛选、持久队列、过期、暂停、取消和运行记录。执行沿用原调用方权限与审核；不重放结果未知的操作。
- Core 与 Pro 接入相同框架；Pro 的账号、云同步和网络功能在合并时保留。
- 扩展配置界面在 1000 与 360 像素宽度检查了进程选择、绑定、原位错误、配置保存和横向溢出。
- 本机 4.1.15.56 通过真实受管链路：校验文件、隔离测试配置、显式绑定、只读原生验证、启动 API、查询异步状态、正常停止。测试没有发消息，没有修改已有微信配置。

## 业务能力与实测边界

| 能力 | 4.1.15.50 | 4.1.15.56 |
| --- | --- | --- |
| 独立 API / 生命周期 / 配置协议 | 已实现并冷启动验证 | 已实现并冷启动验证 |
| 当前机器原生验证 | 缺此版本测试环境；旧隔离状态保留 | 已验证只读 attach / drain / detach |
| 文本收发及回调 | 历史实现存在，隔离未解除 | 先前已有 filehelper 收发/回调证据；本次未重新发送消息 |
| 通讯录、历史、媒体、备注、朋友圈 | 旧适配存在，不能据此宣称稳定可用 | 尚未完成对应原生适配 |
| 财务相关操作 | 不因接口存在视作可用；本次未执行 | 未完成适配，本次未执行 |

两版本功能尚未对齐。沿用旧研究的 SQLite API 表发现方法，已独立定位新版数据库接口；并非所有适配都必须依赖旧版 DLL。被动数据库线程查询的五项独立进程测试通过，包括只读限制、取消、代码恢复和卸载。进一步恢复了新版联系人服务的主动查询链，六项生命周期测试通过；无需手动操作微信界面，真实读取通讯录表结构成功，代码恢复与卸载通过，旧分页查询所需字段均存在。通讯录分页与历史业务接口尚未完成验证。旧版仍缺实际测试环境；新版业务数据格式及其他原生能力仍需逐项验证。

旧包缺失的资源已从可核验的安装原件补入私有构建，并进行了离线校验；这不等于解除旧版本的运行隔离。两版工具包已用最新配方重新构建，冷启动、鉴权、停止及包内容核验通过；4.1.15.56 与 4.2.0.12 的文本能力包现已公开，市场目录仅包含这两个精确版本；4.1.15.50 不在市场中。未迁移的联系人数据库、历史、媒体与财务功能没有借此开放。后续私有手动跨版本适配研究不包含在本次冻结的 0.1.1 附件中。
