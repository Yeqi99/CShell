# CShell 0.8.13：取消操作与编辑保护

## 三项独立修复

- 浏览器上传取消后，不再继续发送尚未开始的分块；已在途请求不会自动重放。关闭后的读取响应不再写入旧连接。
- 取消退出 CShell 后，自动检查与下载更新继续按原设置工作。取消安装不会启动安装器，真正退出时才清理定时任务。
- 重新读取远端文本或 Python 文件期间继续输入，新草稿不再被较晚返回的内容覆盖。保留原文件版本校验、暂停实时同步，并提供明确提示；再次确认重新读取仍可正常应用。

开源版和 Pro 同步以上改动，保留账号、连接、凭据及扩展配置。每版使用独立的新标签和更新渠道。

## 验证与当前状态

三项均有旧实现失败、新实现通过的回归。浏览器取消覆盖真实 Node Duplex；更新器覆盖实际模块、延迟事件、文件下载与摘要；编辑器覆盖真实 React/CodeMirror、等待期间输入、暂停同步及后续保存版本。真实 SSH/SFTP 原子保存及两版类型检查通过。

2026-10-27 已公开发布。开源标签 v0.8.13 固定于 e8563ce980371b62f3590fde486e946f65c63b46，Pro 标签 pro-v0.8.13 固定于 ca0daa8d04b441752b5efb9f685fc5f9b93b2a63；后续分支提交不属于这些安装包。

## 限制

尚未解决此前 Android 10 模拟器偶发点击计数不足的根因；后续通过不代表该问题已经关闭。Windows 代码签名、macOS 公证及实体设备验证以实际结果为准。机房独立安装包不自动改标为本版本。本机窗口访问受限时不强行关闭无法核对的活动会话。
