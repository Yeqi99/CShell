# CanpAI 同账号机器接入（0.8.22）

在 CShell Pro 和 CanpAI Work 登录同一邮箱账号。API / MCP 设置中创建独立客户端、授权机器与能力，再在“同账号 CanpAI 接入”选择该客户端。Work 的“我的终端”随后可直接选择在线 CShell 及授权机器，不需要公网 IP。

默认关闭。云端只按账号路由有界命令，机器密码、私钥与同步保险库不会交给 CanpAI。桌面每次调用仍通过所选客户端的原有 MCP 授权；不同调用会话隔离。删除或关闭客户端、关闭 API / MCP、退出账号均停止调用。断线和执行结果未知时不自动重放。

CanpAI 使用 CShell 邮箱身份和个人会员；短信登录暂不公开。已有 CShell 账号、会员、机器与权限配置保留。CAgent 通过 CShell 中已有机器连接提供能力，不新增独立 CAgent 云桥接协议。

该版本基于已发布的 0.8.21，保留其连接管理、手机和桌面修复。
