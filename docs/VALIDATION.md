## 0.1.8 模式操作、命令联想与 Docker

- Vim 增加普通/插入、行尾插入、字符/整行/块选择和替换模式；常驻退出编辑器，更多操作包含退出所有窗口、全部保存退出和确认放弃修改。Nano 支持取消原生提示。仍通过当前活动会话发送单次操作，不影响终端已有键盘行为。

## 0.1.4 工作台设计与监控

设计依据：先检查实际截图与工作流，再参考 [Windows 表单布局](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/forms)、[Fluent 2 输入控件](https://fluent2.microsoft.design/components/web/react/core/input/usage)与 [WinSCP 连接配置流程](https://winscp.net/eng/docs/ui_login)。采用分组、按内容分配字段宽度、清晰的操作优先级；连接编辑仍在工作区页签内完成。

- CPU 补充在线逻辑核心数；内存和根文件系统补充已用/总量。容量单位为 KiB/MiB/GiB，内存使用量为 MemTotal − MemAvailable，磁盘使用率保留 df 的报告值。依据 [Linux /proc 文档](https://www.kernel.org/doc/html/v6.13/filesystems/proc.html)和 [GNU df 文档](https://www.gnu.org/software/coreutils/manual/html_node/df-invocation.html)。首次 CPU 采样不伪造占比，采集异常清除过期读数。
