# 0.8.20 桌面语言与 Ping 文案

本轮修复共享的机器可视化桌面（Linux / Windows / Android 的已提供应用）、工作台可视化内置入口、窗口标题与操作提示、应用菜单、桌面右键菜单、外观设置、Ping 全部与单机 Ping 状态，以及智能体权限树的产品标签和说明。统一读取现有 LocaleContext；切换语言不会修改机器、分组、自定义应用、已保存外观方案的名称，也不改变权限。

0.8.19 源码中的 Ping 全部已经是 Activity 波形图标按钮；0.8.20 保持此形态，补齐其英文无障碍名称、悬浮提示与自动检测菜单。菜单打开时仍隐藏按钮 tooltip，保留窗口边界约束。

验证：`desktop-locale-smoke.ts` 在独立 Electron 真实渲染下验证 320 / 390 / 700 CSS px 的英文桌面、应用菜单、Ping 浮层边界、无可见按钮文字、中文切换及自定义名称保留。截图位于 `test-results/desktop-locale-020/`，系统 125% 缩放下 320 CSS px 截图为 400 像素宽，不将物理像素误报为 CSS 宽度。另有既有 `ping-all-ui-smoke.ts` 覆盖逐目标请求、排除 HTTP、定时设置与缩放边界；`desktop-i18n.test.ts` 检查翻译和未知名称保留，类型检查通过。

范围限制：这不是整个项目所有历史页面的完整国际化审计。远端返回的错误、操作系统终端名称与自定义内容不翻译；应用内部的其他专属页面需各自按语言契约处理。本轮未变更 0.8.19 的已构建附件。
