# 多机器视图

默认工作台首页提供“当前连接”的三种布局，以及已保存视图和快捷连接入口。
顶栏“视图”进入配置页。创建命名视图，添加已保存的 SSH 连接或 CAgent
远程桌面或终端，也可添加本机 CMD / PowerShell，选择显示器和排列方式，再保存并打开。视图使用独立窗口，每个显示器
一个窗口；主工作台原有会话保持不变。

也可把当前已打开的 SSH / CAgent / 本机终端临时编排为视图。终端复用原会话和历史，
持续转发新输出；关闭临时窗口不会断开原连接，不会重新执行启动命令。
CAgent 复用机器身份，同一机器工作区的桌面窗口共享采集流，各窗口独立处理渲染背压。保存临时视图时保存的是连接引用和布局，
不会把远端正在运行的程序猜成启动命令；需要跨重启恢复指定服务的输出，
请在视图配置中补充 screen 会话名等明确来源。未保存的临时连接须先保存到服务器列表。

## 已实现

- SSH 区域拥有独立真实终端，使用原连接的认证和主机身份校验。没有保存认证时，
  在区域内补充；视图数据只保存连接 ID，不复制密钥或密码。
- 工作目录和启动/观察命令可保存，但必须在区域点击执行。恢复布局不会再次启动服务。
- 已有 GNU screen 会话使用 `screen -x` 自动共享附加，不创建会话、不踢出现有终端。
  已有服务应运行在 screen/tmux 等独立进程管理器中。普通前台程序可能随终端关闭退出。
- CAgent 使用现有已配对机器身份、桌面权限、视频和键鼠协议；打开视图自动连接桌面。
  未安装、未授权或离线情况在对应区域反馈。
- CAgent 终端使用真实 Agent Provider，本机终端使用 ConPTY；关闭借用的当前终端视图不会断开原终端。
- 按系统显示器 ID 分配，支持平铺、主次、小窗预览三种模式。小窗模式持续渲染所有
  来源，点击后在当前视图窗口放大操作，返回预览或按 Escape 恢复。切换和放大不重建连接。
  主次模式点击区域标题即可更换主要区域。每个区域用 12×12
  相对网格表示，可交换位置、编辑行列和宽高；保存前拒绝越界、重叠和重复区域。
- 显示器缺失时，受影响区域在主屏重新排列；运行中拔屏会把窗口移到主屏。
  不自动覆盖原显示器映射，点击保存布局才持久化。
- 不同显示器保存布局只合并当前窗口所属区域，避免覆盖其他窗口的新布局。
- 关闭配置视图窗口释放它创建的终端和视频会话，不关闭复用的主工作台会话。关闭配置页不关闭已打开视图。
- 资源边界：每屏最多 12 个区域、每个视图最多 96 个区域、100 个命名视图；
  每个终端保留 3000 行显示历史。这些限制会显示错误，不静默丢失来源。

## 验证与边界

`tests/monitor-views.test.ts` 验证布局无重叠、输入边界、字面路径处理及磁盘持久化。
`scripts/monitor-views-smoke.ts` 用 Electron 与真实 SSH 测试服务器验证双终端、
显式执行、screen 附加命令、拖放保存、缺失显示器回退、重开和连接清理。
同时验证工作台入口、复用当前终端历史、不新建 SSH 会话，以及关闭临时视图保留原连接。
screen 命令由测试服务器记录，未模拟真实 Minecraft 服务或 screen 运行环境。
既有桌面视频管理回归测试覆盖关键帧/背压、断线恢复与撤权。
Windows 本机 CMD / PowerShell 已做输入输出验收；`scripts/monitor-agent-smoke.ts`
使用本机真实 CAgent 验证保存视图中的 CMD / PowerShell 输入输出和关闭清理。
共享桌面回归覆盖慢窗口不阻塞、关闭其中一窗保留流、撤权关闭全部订阅。

多个实体显示器、多个远端 CAgent 同时播放、macOS/Linux 窗口管理尚未实机验收。
布局尺寸是相对网格，不保存任意像素的操作系统窗口位置；窗口每次填充目标屏幕工作区。
当前首版不提供独立指标图表、文件尾部专用数据源或 tmux 会话浏览器，
可通过 SSH 命令运行现有监控工具。修改来源配置后须关闭再打开视图生效。
旧终端 target 与新机器工作区 target 尚未跨 target 合并桌面流；同一机器建议从机器工作区打开视图。
