# MCP 接入

在偏好设置的“AI 与安全”区域选择允许访问的服务器，填写端口并勾选启用，再点击底部“保存”。建议为各客户端单独创建令牌与能力授权。状态显示正在运行后，在 MCP 客户端添加 Streamable HTTP 服务：

```json
{
  "mcpServers": {
    "cshell": {
      "url": "http://127.0.0.1:3777/mcp",
      "headers": { "Authorization": "Bearer <在 CShell 中复制的访问令牌>" }
    }
  }
}
```

不同客户端的配置字段可能不同；协议地址和 Authorization 头保持一致。当前只接受本机客户端，CShell 必须保持运行。不要公开导出的客户端配置中的令牌。

旧入口保持兼容。新接口、授权、按需发现、真实 Provider 工具、任务与恢复边界见 [API 与 MCP 说明](API.md)。渐进模式通过 discover_capabilities / invoke_capability 使用同一目录；标准 MCP 工具列表始终包含完整输入 schema。

兼容工具：

| 工具            | 用途                                         |
| --------------- | -------------------------------------------- |
| list_servers    | 列出明确授权的服务器，不返回凭据             |
| connect         | 用已保存凭据、已信任指纹建立 MCP 独立连接    |
| disconnect      | 关闭 MCP 连接                                |
| list_files      | 查看 MCP 连接上的文件列表                    |
| monitor         | 查看 Linux 资源指标                          |
| execute_command | 单独授权后才可用，按已配置审核策略复核 |

允许范围只来自设置里勾选的保存连接，不能传入任意主机地址。请先在 CShell 中连接一次、确认指纹并保存凭据。默认没有授权服务器，也不允许执行命令。文件读取、上传、下载、重命名、删除等能力按实际 Provider 与独立授权提供；通过能力目录读取当前契约，变更仍受范围、审核与并发检查。

更换令牌会撤销旧令牌并断开 MCP 会话。端口冲突会显示错误，不能把“已勾选启用”当作服务运行成功。审计记录存放于本地用户数据目录的 mcp-audit.jsonl，约 1 MB 后轮换，保留一份前序记录。

## 工作台与命令行

[命令台与 CLI](CLI.md) 使用同一授权目录与调用接口。浏览器的页面文本、截图、元素交互与有限同源爬取，以及 CAgent 支持的原生远控截图和输入，分别使用 browser.read / browser.control / desktop.view / desktop.control。新权限默认关闭，不自动继承通用管理权限。浏览器复用真实机器出口及既有登录分区，断线不回退本机网络。

截图在 MCP 返回标准 image 内容块；HTTP API 返回有界 JSON 图像数据，CLI 可保存为文件。没有实现或未授权的能力不出现在当前目录中。

### 页面、框架与截图

浏览器通过 `browser_frames` 列出当前真实框架，`browser_snapshot` 可带 `frameId` 读取跨域框架或开放 Shadow DOM 元素；点击、填入和选择使用同一次快照的 `ref`。页面文本、属性或节点变化后旧引用失效，须重新读取，避免误点。工具不开放任意 JavaScript；验证码、系统认证等必须由使用者完成的步骤仍需人工操作。抓取一次最多 5 个同源地址，沿用当前机器的登录分区，不导出 Cookie。

截图最长边不超过 1920 px，JPEG 数据不超过 2 MiB。智能体将截图作为独立图像输入发送；加密历史只记录图片引用和来源，不塞入 16,000 字符工具文本日志。视觉能力以服务商明确提供的输入模态为准；未知标为未确认，文字模型提供页面文字快照方案。服务端拒绝图片后不会自动重发。普通输入/选择可能含密码或验证码，工具审核、历史与检查点不回显输入值；文本快照也遮蔽工具刚填入的内容。

远控按当前 CAgent 的真实身份、查看/控制授权打开短时连接。获取画面不取得输入权限；输入需要单独授权，断线或撤权不重放。桌面连接票据仅留后端，截图/工具结果不包含它。
