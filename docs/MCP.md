# MCP 接入

在偏好设置的 MCP 服务区域选择允许访问的服务器，填写端口并勾选启用，再点击“应用 MCP 设置”。状态显示正在运行后，在 MCP 客户端添加 Streamable HTTP 服务：

```json
{
  "mcpServers": {
    "cshell": {
      "url": "http://127.0.0.1:3777/mcp",
      "headers": { "Authorization": "Bearer <在 CShell 中复制的访问令牌>" }
    }
  }
}
```

不同客户端的配置字段可能不同；协议地址和 Authorization 头保持一致。当前只接受本机客户端，CShell 必须保持运行。不要公开导出的客户端配置中的令牌。

工具：

| 工具            | 用途                                         |
| --------------- | -------------------------------------------- |
| list_servers    | 列出明确授权的服务器，不返回凭据             |
| connect         | 用已保存凭据、已信任指纹建立 MCP 独立连接    |
| disconnect      | 关闭 MCP 连接                                |
| list_files      | 查看 MCP 连接上的文件列表                    |
| monitor         | 查看 Linux 资源指标                          |
| execute_command | 单独开启后才可用；每条命令需在 CShell 中批准 |

允许范围只来自设置里勾选的保存连接，不能传入任意主机地址。请先在 CShell 中连接一次、确认指纹并保存凭据。默认没有授权服务器，也不允许执行命令。MCP 的文件上传/下载、直接文件变更接口暂未提供。

更换令牌会撤销旧令牌并断开 MCP 会话。端口冲突会显示错误，不能把“已勾选启用”当作服务运行成功。审计记录存放于本地用户数据目录的 mcp-audit.jsonl，约 1 MB 后轮换，保留一份前序记录。
