# Linux 可视化桌面（0.7.10 本地开发构建）

0.7.9 修复原生浏览器最小化与本地任务栏状态不同步：远端通过 X11 窗口属性报告最小化状态，本地同步最小化；重新激活时恢复远端窗口。旧代理缺少该属性时仍在重新激活时尝试恢复，并提供手动恢复入口。图形安装依赖明确包含 x11-utils/xprop。桌面改为单击选中、双击或 Enter 打开，支持空白处拖动框选与 Ctrl 追加选择，禁用桌面文字拖选；任务栏提供明确带文字的“桌面”按钮。实机验收实际点击 Chrome 原生最小化按钮，再从任务栏恢复画面，结果记录在 `test-results/linux-079-real.json`。

## 桌面交互

0.7.8 将菜单式首页替换为桌面：应用图标、独立应用窗口和底部任务栏。窗口支持拖动、右下角缩放、最小化、最大化与还原；显示桌面保留所有应用状态。收起窗口不会结束远端应用，结束远端应用仍从画面右下角操作菜单明确执行。

桌面设置包含背景、图片上传、明暗主题、命名外观方案导入导出、显示操作信息及真实设备信息。外观按设备身份保存在本机，不修改服务器权限。直接 cagent 连接复用同一桌面，并保留智能体与设置权限入口；SSH 桌面中的终端使用该机器保存的连接信息建立独立真实终端，原 SSH 会话保持不变。

0.7.8 验证：TypeScript 与生产构建通过；桌面夹具验证拖动、最小化恢复、文件草稿、滚轮范围、中文输入、背景主题持久化、窄屏和断线清屏。本机安装后的美国机器实测验证浏览器完整画面（视口高度与滚动内容高度同为 492 CSS px，无外层滚动）、文件草稿保留、独立 SSH 终端真实执行命令及最小化恢复，无渲染错误。记录在 `test-results/linux-desktop-installed.json`，安装目录与最终构建的 app.asar 摘要一致。

浏览器默认最大化，移除原有机器标题、应用导航、远端应用工具栏和重复窗口标签层级。原版浏览器自身地址栏保留，画面完整等比适应窗口，外层不滚动。非被动滚轮监听仅绑定实际画面，阻止本地滚动链；文字输入与结束应用按需展开。当前远端仍为固定 1440×900，显示区域比例不同时会留边，不裁切或拉伸画面。

## 架构与边界

CShell 自研工作区外壳、导航、文件界面与应用入口。Linux 端复用标准 X11 协议与精简图形组件（Xvfb、Openbox、Xauthority），不安装 GNOME/KDE 桌面。真实应用连接虚拟显示器；FFmpeg 采集窗口所在显示器，画面通过已认证的 cagent 通道返回，xdotool 发送明确的用户输入。该实现不是从零编写的显示服务器或合成器。

Windows 本机不加载远端网页，也不使用 iframe 代理网站。浏览器的请求、Cookie 和配置保存在 Linux。当前首个可启动应用是官方 Chrome；QQ、微信等原版 Linux 应用在图形协议层具有接入路径，但还未完成安装配方、具体版本、登录、输入法、弹窗、音视频、托盘与保活验收，不能标记为可用。后续可按应用清单注册入口；需要 Wayland 时再接合成器和 XWayland。

## 已实现入口

- SSH 连接顶部选择「SSH 终端 / CAgent 工作区」。首次展示目标、依赖和安装计划，用户执行后通过独立 SSH 通道部署，不向正在使用的终端注入安装命令。按连接保存入口偏好。
- cagent 使用当前用户的原有数据目录及身份。控制服务只监听回环地址；SSH 桥接只开放工作区所需方法，不提供修改监听、密码、中继或任意工具调用。传统 SSH 会话继续存在。
- cagent 直接连接的 Linux 机器也能进入首页、文件、终端、可视化应用与应用市场。
- 文件区沿用真实文件操作和分块传输。切换视图保留目录草稿；远端可视化进程不因切换标签或 SSH 断线退出，显式结束会话时提示未保存内容风险。
- 应用市场的远程浏览器安装计划包含 Google 官方签名软件源、Chrome、中文字体、精简 X11 运行环境以及无登录权限的 `cagent-browser` 用户。没有自动 sudo、重启或防火墙变更。

## 数据与权限

浏览器保持 Chromium 沙箱，root 运行的 cagent 会以专用普通用户启动图形应用。X11 禁止 TCP 监听，Xauthority 为私有文件；浏览器没有开放调试端口。专用用户和进程隔离不等于任意应用的权限沙箱。

每个 cagent 控制端拥有自己的显示会话；SSH 入口属于已经认证的系统用户本机控制面。该用户的多个 SSH 连接共享其工作区。管理权限仍由 cagent 校验，工具/API 不因增加 UI 就开放可视化输入。

没有自动同步本地剪贴板。用户粘贴或点击发送才提交文本；中文文本使用远端 UTF-8 剪贴板。截图不作为历史存储，失去新画面后停止输入。拖动输入具有释放和超时机制。SSH 桥接断线后不重放未知操作。

## 当前限制

- 首次部署支持 Linux x64/ARM64，可使用普通用户；需已有 curl、tar、xz、sha256sum、Python3、make、g++ 及兼容官方 Node 二进制的系统。缺少工具时停止，不运行 apt 或提权。
- 浏览器安装配方目前限定 Linux x64。其他架构不展示该配方。
- 当前使用有界 JPEG 画面与 SSH/RPC 传输；服务端采集上限 8 FPS，实际交互速度受网络影响。尚非视频播放、游戏或低延迟远控方案。
- 可视化输入支持点击、拖动、滚轮、常用键、显式粘贴与中文发送。尚无音频传输、完整本地输入法协议、双向剪贴板、独立窗口视频流和系统通知集成。
- 应用目录为明确的内置适配清单；本版不接受任意第三方启动命令，不宣称所有 Linux GUI 软件即装即用。
- cagent 是独立 Node 进程，无 Electron 依赖。首次 SSH 部署使用 CShell 随构建携带的代理程序并核对 SHA256；属于本地部署，不表示该版本已在 GitHub 发布。

## 0.7.10 安装隔离与路径

安装前可指定绝对路径（例如 /data/cagent），检查可写性并显示目标磁盘空间；修改路径使旧计划失效。目标必须为空，不覆盖已有文件。私有 Node 22.23.3、固定依赖、构建缓存、日志和新建数据放入所选目录，用户目录只保留工作区定位链接。上传的约 2 MB 程序使用 /tmp 临时文件，安装结束清理。安装阶段 PATH 仅在子 Shell 内改变，运行中的终端继续继承原系统环境。已有身份目录保留并解析真实路径，不重置身份或权限。浏览器等系统应用仍是另行检查和执行的安装计划。

主力机实测：程序、缓存和身份数据已迁至 /data/cagent，约 284 MB，旧入口保留链接；设备身份不变。系统 Node 20.20.2/npm 10.8.2 保持，PTY 子进程验证使用原版本。修复安装前后 dpkg、apt 手工包列表、软件源、.bashrc 和 .profile 摘要一致；此前失败安装造成的历史状态不在这一比较范围内。


## 0.7.11：浏览器改为本地渲染

桌面“浏览器”使用 CShell 自有标签栏、地址栏和导航控件，网页运行于本机隔离的 Chromium WebContentsView；页面滚动、GIF、动画与输入不再依赖远端截图。当前网络通道绑定已认证 SSH 会话，SOCKS5 CONNECT 将域名直接交给 SSH 目标解析，含 127.0.0.1 的访问也在目标服务器执行。没有在服务器安装浏览器或代理软件，也不改变系统网络设置。

缓存、Cookie、站点存储按保存的连接身份和地址/用户划分独立持久分区。网络出口属于服务器，但浏览器运行环境仍属于本机；不承诺伪装为 Linux 浏览器。SSH 断线关闭通道、停止网页并拒绝后续请求，禁止本地直连回退。禁用 QUIC 与非代理 WebRTC UDP；网页无 Node/CShell preload，保留沙箱、同源策略和证书检查。当前拒绝设备权限及网页下载，未接入下载管理；最多 12 个网页标签。同一机器浏览器在一个工作区使用，避免共享站点数据的同时切换网络通道。

“Linux 应用”单独保留 X11 远端应用路径，现有远端 Chrome 是已验证的兼容样例。QQ/微信尚未完成实机适配，不列为可用；不把本地网页渲染等同于任意原生 Linux 应用本地运行。直接 cagent 连接尚未接入浏览器网络中继，浏览器入口明确要求 SSH 工作区。

应用市场使用独立组件样式，修复桌面容器中表单失去原页面样式的问题：紧凑固定宽度图标卡片、独立搜索与刷新、默认收起的权限编辑、统一字段与焦点样式。安装授权与原安装计划语义保持。

实测主力机回环测试页可访问，而本机同端口服务未收到流量；本地动画约 61 帧/秒、中文输入、最小化恢复及双标签通过。断开 SSH 后强制无缓存请求失败，本机回退探针请求数为 0。网页中 require 和 window.cshell 均不存在。窗口合成画面经 Windows 原生捕获检查，网页正常显示，应用市场未被网页覆盖。

## 0.7.12 机器桌面

已将桌面窗口与任务栏复用于 Windows、Android 和受限终端 cagent 连接，按真实平台显示入口。远程控制按需检查能力，授权就绪后连接；窗口隐藏时释放键鼠，保留会话用于恢复。原生应用入口是应用文件夹，目前仅列出已验证且可启动的 Chrome，未把 QQ/微信标记为可用。默认窗口按桌面实际尺寸居中留白，连接标签栏悬停或键盘聚焦显示；网页提供独立缩放。

机器桌面智能体使用消息区、底部输入区、按需任务历史与模型设置；任务草稿按任务 ID 保留，继续任务调用远端 resumeId，停止操作绑定当前任务。执行记录默认折叠，目标机器与当前模型显示在对话内。远端接口仍为任务与检查点续作，不声称提供尚未实现的完整多轮会话协议。

## 0.7.13 恢复与连接状态

普通连接使用居中状态卡片，检查、连接、失败与首次安装区分；已安装连接不闪现安装表单。去掉标签栏装饰灰条。桌面窗口按设备保存位置、大小与最小化状态；浏览器按原有稳定机器分区保存标签、历史与收藏，新增资料使用系统加密并原子写入。退出前等待 Cookie 和站点存储落盘，沿用旧分区而不清理登录资料。旧版本没有记录的历史不能补回。

浏览器处理自行关闭/已销毁 WebContents，状态快照与动作执行前清理失效标签。测试覆盖无 destroyed 通知的失效包装器、断线恢复、关闭窗口恢复；另用两个真实 Electron 进程验证标签、收藏、历史、持久 Cookie 和 localStorage 跨进程保留。

### 0.7.14 登录弹窗修复

- 使用 Electron 原生 createWindow 接入桌面标签页，保留 opener/WindowProxy、POST 和 referrer；不再 deny 后用 loadURL 重建登录页面。支持 about:blank 初始化的弹窗。
- 弹窗关闭回到发起页面；后台弹窗关闭不抢夺当前标签。清理失效视图，保留原机器代理、会话分区和安全限制。
- 通过类型检查、构建以及 8 项存储/模拟弹窗/代理/工作区回归测试。按用户要求未打开真实浏览器测试页、未访问 Google/Claude、未操作账户或授权；真实第三方登录结果尚未验证。

### 0.7.15 弹窗实例接入修正

- 修复 0.7.14 的 Invalid webContents 主进程异常：WebContentsView 必须接收 createWindow options 中 Electron 已创建的 webContents，不能仅复制 webPreferences 后另建实例。
- 安全选项在 overrideBrowserWindowOptions 中提前设置，避免在接管已创建实例时才尝试覆盖。
- 模拟测试补充 supplied webContents 对象身份断言；此前模拟未提供该字段，漏掉了真实 Electron 的实例一致性要求。类型检查与构建通过；未运行真实浏览器/账户登录验证，未访问 Google 或 Claude。

## 0.8.0 收口

浏览器新增活动网页的剪贴板写入与全屏权限、历史单项删除、机器资料清理和本地地址联想。修复 Windows cagent 浏览器重复显示 SSH 提示。

新增 coding.* 与 ide.* 机器应用接口，均保留认证控制端归属，不通过通用 API/MCP 管理目录暴露。Codex 使用 app-server JSONL，Claude Code 使用 stream-json；官方登录由独立客户端配置目录承接，API 密钥在 Agent vault 加密保存。客户端安装使用独立 npm 配置及缓存；取消只影响所属安装任务。

Android 使用原生 WebView Profile 隔离机器资料，回环 SOCKS 通过已认证 Agent RPC 转发。域名交给目标机解析，不设置 DIRECT 回退，移除隐式 localhost 绕过。切换机器先销毁旧页面和通道。移动 UI 使用底部工具栏，编码应用侧栏按需展开。原生代理测试与原生 WebView fixture 接入 Android 仪器验证；真实账户与外部站点登录未验证。

code-server 安装使用 GitHub 官方独立资产及 SHA256；版本核验完成后才标记可用。运行时绑定 127.0.0.1、独立配置/扩展目录和随机访问密码，不自动开放防火墙。平台和已知限制见 RELEASE.md。
