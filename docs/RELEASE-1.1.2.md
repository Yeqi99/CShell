# CShell Pro 1.1.2

## 账号与基座

远程机器智能体提供云端基座选择。官方模型使用机器所登录账号的会员额度。打开模型与权限，点击“同步当前 CShell 账号”，即可通过已核验身份的连接登录目标 cagent 并恢复加密云配置。每台机器使用独立登录凭据。目标已登录其他账号时，在目标机器退出后重新操作。运行中的智能体任务需完成后再切换账号或模型。

## 机器知识库

应用市场提供机器知识库，用于保存文档、JSON 结构化数据和包含步骤及结果的解决经验。读取与写入分别授权。记录位于机器数据目录的 knowledge/records.sqlite，重启后保留。智能体会检索相关经验、核对环境，并在验证成功后保存可复用步骤。Milvus、嵌入服务和 WebDAV 可按知识库文档配置。

## 界面回归

远程智能体调整消息宽度、输入区、模型选择和浅深色主题，机器身份放在紧凑标题区。保持任务草稿、历史、停止操作与工具记录。

## 验证范围

Windows 安装后的 CShell 和 cagent 已核验为 1.1.2。真实配对机器窗口验证模型入口、账号同步入口、切换设置保留草稿和浅深色布局。知识库使用真实磁盘和智能体工具调度验证重启读取，模型回复由回归测试驱动。

Android 安装包已校验应用标识、版本和发布证书。Mac 检查架构、启动辅助程序执行权限及签名页完整性。Mac 未经 Apple 公证，Mac 与安卓仍待实机体验验证。线上 Milvus、嵌入服务和 WebDAV 联调尚待实际配置。
