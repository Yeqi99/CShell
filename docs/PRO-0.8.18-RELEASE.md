## 已验证范围

- 首次 CShell 配置采用用户要求的宽松智能体默认；既有明确关闭的权限、账号隔离和云端缺字段不被扩大，MCP 仍需单独启用。Windows 普通版/Pro 实包及八个 POSIX 原生架构构建均通过相关验收。
- Windows CShell 精确安装器通过 SSH、文件、布局、设置、权限持久化和双版本同时隔离测试。CAgent Windows 原生旧宿主恢复修复已在独立安装产物验证，不重放未知写操作。
- Android 双 API 仪器验证与 Android 16 真机完成 H.264 画面、点击、文字、连续删除及同身份断线重连；系统投影失效后的重新授权仍由系统要求。
- 微信证据按实际阶段记录：手机真实入站由原生层捕获，诊断路径将该事件投递并执行一次；最终冻结包自动重投同事件返回 204 且不重复执行，独立合成新事件各执行一次。没有把分段证据写成首次真实自动全链路成功。
