# Linux 原生桌面

SSH 机器的可视化工作区新增「原生桌面」应用。它显示服务器真实图形桌面，与 CShell 自己的机器工作区分开；不要求安装 CAgent。

## 使用

1. 连接 SSH，点击标签栏的「桌面与显示方式」图标，选择「服务器原生桌面」；也可从 CShell 可视化工作区打开「原生桌面」应用。它复用当前 SSH 会话，在工作区应用窗口中自动检查当前用户的图形会话。
2. 检测到一个 X11 会话时，点击「开启并连接」。缺少组件时显示「安装组件并开启」及安装范围。
3. CShell 在独立应用窗口中显示桌面，支持键盘、鼠标、等比缩放及窗口最小化恢复。
4. 「断开」只结束观看，保留服务器图形会话。再次打开可重新连接；「停止共享」仅停止由此功能启动的共享进程，不注销桌面。

已有 VNC 服务可展开高级入口填写服务器回环端口（5900–5999）、VNC 密码或 Unix 套接字。密码只用于当前连接，不写入外观或日志。共享现有屏幕还是独立虚拟桌面由远端 VNC 服务决定。

## 安装与访问范围

自动开启适用于当前 SSH 用户已经运行且可访问 Xauthority 的 X11 桌面。共享使用 x11vnc；Debian/Ubuntu 缺少组件时，从配置的软件源下载软件包并解包至当前用户的 `~/.local/share/cshell/native-desktop/package`，核验可运行后才启动。不使用 sudo、不修改全局 PATH、不安装显示管理器、不重启机器、不修改防火墙。

共享仅监听权限受限的 Unix 套接字，经现有已验证 SSH 连接传输。启动时显式禁用 IPv4/IPv6 VNC 端口，并检查进程是否意外留下 TCP 监听；发现时立即停止。运行日志和进程记录在上述专用目录中。默认不安装开机自启；重启后从 CShell 再次开启。

只读检查不会开启共享。点击开启意味着允许键鼠控制所选真实桌面；不绕过系统锁屏或桌面认证，不自动共享其他用户的桌面。自动剪贴板同步关闭。失去 SSH 连接后不回退网络、不重放操作。

## 当前边界

- Wayland 的会话捕获与系统授权不同，本版不自动开启；可连接已经配置的兼容 VNC 服务。不声称支持内嵌 RDP。
- 无图形会话、多个候选会话、缺少 Python 3 或其他系统依赖时提供明确提示，不猜测目标或静默提权。
- 多屏显示完整远端画布，等比缩放时可能留白；尚未提供单屏选择、音频与远端分辨率调整。
- 原生桌面当前从 SSH 工作区进入，直接 CAgent 连接不伪装成已具备这条 SSH 传输能力。

## 2026-10-28 实测

- 实训箱210，Ubuntu 22.04 ARM64，现有 GNOME/X11：2944×1080 双屏真实画面；noVNC 渲染无页面错误，远端收到 2 次按键事件、3 次鼠标事件。
- 美国机器，Ubuntu 26.04 x64：经授权安装 XFCE/TigerVNC 测试桌面，1440×900 真实画面；普通测试用户，Unix 套接字仅用户可访问，不新增 TCP 监听。
- 新增传输边界/关闭读取测试，连同资源解析与真实 SSH 基础回归 13 项通过；生产构建通过。完整客户端更新验证另行记录，不把隔离组件测试当成已安装版本验收。

## 同轮界面修复

- 硬盘挂载点和容量改为分行布局，长设备名可换行，不侵入数值列。
- ARM CPU 型号增加 `lscpu` 回退并保留大小核名称；实训箱报告 `Cortex-A53 + Cortex-A72`。
- 标签允许适度收缩；窄工作区的文件操作收为带说明的图标，优先保留标签显示空间。

- 回归脚本 `node scripts/test-native-desktop-ui.cjs` 覆盖从入口打开、关闭后再次打开原生桌面，以及 600px 工作区在 15/22/28px 字号下的标签显示、自动显露当前标签与滚轮横向导航。
