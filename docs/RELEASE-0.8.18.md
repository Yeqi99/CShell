# 0.8.18 · 配置同步与跨设备工作区

状态：候选验收中，尚未发布。正式版本、下载目录和本机升级须在平台检查完成后一起切换；本文不代表已上线。

## 账号与设备

CShell 与 CAgent 共用账号中的模型基座，设置、插件选择、OpenCode 独立凭据按同步矩阵恢复。设备监听、MCP 令牌和本机授权仍由各设备独立保存。新设备恢复不会把旧设备的对外权限一起开放。

设备可按邮箱或限次、限时分享码借用给其他账号，接收方获得连接授权而非机器密码。账号网络规则按“来源机器 → 出口机器”配置，拒绝循环；出口离线时报告失败，不回退到另一条网络。

## 工作区与智能体

- 重复双击机器建立独立标签。RDP 标签也拥有各自的原生会话，关闭、切换和重连不影响同机器的其他标签。
- 设置、权限、扩展、统计与历史采用统一的分区和控件；常见授权、会员及未启用状态使用普通提示，真实错误进入统一诊断通道。
- 智能体的目标和事件菜单保留对话上下文与草稿，空闲时可在同一对话更换模型。目标支持秒级间隔与可更新的记忆。
- CAgent 原生窗口和网页设置提供模型选择、自动化管理及适用的云端外观设置。已有明确关闭的权限保持关闭。
- 机器列表提供紧凑的 Ping 全部及周期设置。测量始终指向该机器，不把本地代理响应当服务器延迟。

## 远程操作

修正 Windows 远控剪贴板消息处理及文件暂存生命周期，文本、PNG、小文件已完成两台真实 Windows 的往返验证，测试后完整恢复双方原剪贴板。远程桌面仍遵守系统登录、锁屏和显示会话条件，不绕过系统登录。

Android 候选已用持久发行证书签名并在 Android 16 手机正常安装、启动，真实屏幕视频已验证。手机控制、电话和短信受 Android 系统授权、设备及 SIM 状态约束；详细结果以验收记录为准，不将模拟器结果写成全部实机能力通过。

微信作为独立能力包安装，通用事件订阅和自动化不与微信业务写死。工具包的精确版本支持、实际回调验收及清理修复独立记录；没有通过的能力不会列为可用。

## 验证与限制

Windows 本机成品、真实 SSH/SFTP、ConPTY、RDP 多标签、云数据恢复、公网会员中继和跨 CAgent 网络出口已有实证。最终 Core 构建 `41292173361` 与 Pro 构建 `41292194243` 均已通过，覆盖 Windows 及 macOS/Linux 的 x64、arm64；各平台原生包检查与 macOS 原位 DMG 更新检查通过。Android API29/35 输入与视频仪器验收通过，物理手机的最终触控验收仍单独进行。下载归档与安装包须全部核验摘要后才能发布。Windows 安装器未进行 Authenticode 签名；macOS 签名与公证限制仍保留，CI 原生运行不等于每类物理设备均已测试。

OpenCode 目录可读取不等于模型请求成功；当前账号部分免费模型受上游地区或额度限制，不自动改用付费模型。完整范围见 [同步矩阵](CLOUD-SYNC-MATRIX.md)、[逐项验收](UNIFIED-FINAL-AUDIT-20261101.md)、[候选包核验](PRO-0.8.18-CANDIDATE.md) 和 [Android 实机记录](ANDROID-FOLLOWUP-20261101.md)。
