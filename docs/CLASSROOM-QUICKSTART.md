# 机房：从安装到集中管理

本页对应新的 Windows 课堂部署包。不要拿旧 0.8.10 安装器套用课堂脚本。

## 学生机

1. 将完整课堂 ZIP 解压到本机，核对 ZIP 的 SHA256。
2. 双击 `Install Classroom Student.cmd`。新安装会装好 CShell 与 CAgent、启用机房扩展，CAgent 初始密码为 `123456`，监听 `24443`，立即启动并在当前用户以后登录时启动。
3. 已有用户数据会保留，不会把现有密码或权限重置为课堂预设。失败时保留控制台提示；先解决原因再运行，不要删除身份目录。

自定义机房名、端口或安装目录可使用 `Install-ClassroomStudent.ps1 -Apply -Room '301机房' -Port 24443` 及对应 Destination 参数。详细参数见[部署说明](DEPLOYMENT.md)。

## 教师机

打开 CShell 的「扩展 → 机房 → 集中管理」。学生机明确启用的发现公告会自动出现。全选目标、检查真实设备身份，确认后填写一次机房密码，批量加入左侧统一机器列表。发现不会自动给陌生设备发送密码。

加入后即可从机器工作区使用文件、机器信息与已授权的远程控制。集中管理可以多选机器：

- **智能体基座**：选择教师端已经配置的兼容 HTTPS 基座，检查后确认下发。密钥通过已认证加密通道发送并加密保存；只改模型，不改学生端授权。运行中的智能体任务会拒绝此次更改，结束后再下发。
- **环境变量**：保存到 CAgent 私有配置，影响之后新开的终端与脚本；不会更改系统注册表或已经启动的程序。需要全局系统变量时，使用具备相应权限的显式管理脚本。
- **脚本**：用目标支持的 Shell 执行，按机器显示结果。可分发静默安装命令；脚本必须检查安装器退出码及最终版本，不能只把启动安装器当作安装成功。
- **应用安装**：仅列出实际目标提供且授权的目录应用。其它软件可用脚本部署，但须由管理员提供可信来源、校验与正确静默参数。

每次先检查逐机计划，再一次确认；最多4台并行。结果未知时不要盲目重发，先检查目标。取消会请求停止，不能回滚已发生的安装或文件变更。

## 屏幕共享

「机房 → 共享我的屏幕」选屏幕后点击「开始共享」。其他启用扩展的同网段机器在「观看屏幕」自动看到它，点击即打开独立观看标签。任何时候可停止共享。安装不会默默共享屏幕。

## 部署范围

当前是 Windows 用户进程及用户登录自启，不是登录前的系统服务。机房网络须允许相应局域网通信；安装器不自动改防火墙。无人值守安装要求软件提供静默安装方式，且 CAgent 的运行账号已有所需权限；需要 UAC、重启或交互的软件不能保证全程无人操作。实体多机局域网仍需在实际机房验收。
