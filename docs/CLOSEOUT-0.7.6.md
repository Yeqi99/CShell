# 0.7.6 收口记录

## 范围

- README 以产品用途、CShell / CAgent 分工、入门和平台差异组织，提供简体中文、英文、日文；不主动介绍特定社交应用能力。
- 应用品牌统一为蓝色 CShell 与绿色 CAgent，保留对应 Pro 图标资产。
- 视图支持逐个关闭区域、保存剩余布局；复用会话不被误终止。
- 视图中的终端右键 AI 绑定真实终端上下文；智能体可作为紧凑视图区域或独立窗口。
- Android 修复跨窗口输入焦点与退格后的光标位置，覆盖连续退格、Unicode 字符和选区编辑。

## 验证证据

源码验证提交：`32a1a61a86519c8958fe8a5ab0dbd41ee8dcec29`。

[跨平台验证运行](https://github.com/Yeqi99/CShell/actions/runs/39533858686)包含 Windows x64、macOS arm64/x64、Linux arm64/x64、Android 签名 APK 和 API 29 / 35 原生模拟器回归。上述构建与回归任务全部通过。该运行使用 `publish=false`，构建附件不等同 GitHub Release 发布。

本机单元测试 361 项通过；视图关闭、终端右键 AI、320px 智能体窗口与品牌加载均有交互检查。CShell 与 CAgent 已更新到 0.7.6 并打开核验。Android APK 已重新构建、lint 与签名核验。

测试修正保留原断言：Android 测试画面不再依赖被 CI 禁用的系统动画；Python 终端测试等待真实命令回显后再按回车；连接生命周期检查补充有界清理与阶段诊断。

API 终端延迟综合运行曾出现单次超标，独立复测空载 p95 176ms、混合负载 p95 225ms，低于原预算 527ms。未修改阈值，保留两次测量记录；这不等同长期性能验收。

## 维护边界

0.7 系列进入以错误修复、兼容性、稳定性和文档为主的维护阶段，新增产品功能主要进入 Pro。已有开源代码保持 MIT。

跨平台构建通过不代表能力完全相同。macOS / Linux 尚无与 Windows 等价的 CAgent 原生桌面被控能力；Android 不提供完整桌面多窗口工作台。实体多屏、Windows 锁屏/UAC/无显示器及 Android 厂商后台和锁屏投影行为仍需真机验收，详见[平台能力](PLATFORMS.md)。不将这些边界标为已全部解决。
