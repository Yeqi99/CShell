# 官网工作区视觉改版 · 2026-10-27

本轮重构首页布局与 home.css，不继续叠加旧首页补丁。参考既有十站调研及本轮真实页面截图，采用产品工作台自身的窗口、视图切换、连接线路和工具入口作为视觉语言。

## 改动

- 首屏从标题、说明和平台列表改为紧凑标题、下载操作、完整工作区画面。桌面与手机首先看到产品；四客户端平台入口放在画面之后，全部保留。
- 场景标题改为实际功能名称，产品画面保留示例说明，不冒充用户数据或跨平台实机截图。
- 账号同步用四平台到同一账号的连接关系图表达，替换泛用同心圆装饰；设备权限仍明确独立授权。
- 扩展、下载、版本对比与文档采用统一间距、色板与控件。下载区采用明确的平台选中态、架构选择、文件格式与真实附件链接。
- 手机导航保留全部入口、Escape、焦点恢复和无 JavaScript 回退；减少动态偏好保留。

## 验证

本地完整首页在 320/390/1440px 通过：四平台、全部架构链接、场景与键盘、图片解码、搜索交接、下载空态、菜单与焦点、无横向溢出。增加首屏约束：图片顶部小于 400px，至少 80% 的画面可见。初始固定 180px 门槛不适合 320px 等比例缩小图片，已修正为可见比例。

机房页面 320/390/1440px 通过溢出和本地链接检查。文档与下载的综合回归功能断言通过，但隔离浏览器退出曾停滞；首次新增首屏检查复测也曾遇到本地加载超时，均保留记录，不改写为首次全通过。

## 边界

这是首页整体布局重做，不代表所有文档页面和下载页的个性化设计目标已全部达成。后续仍需统一这些独立页面的视觉与操作体验。官网改版不提高客户端版本，不替代三个独立客户端改进的发布要求。
