# Tavily 搜索扩展

在插件市场启用 **Tavily 搜索**，打开其配置页。输入 API Key、可选名称，点击“保存并检测”；可配置最多 32 个 Key，逐项停用或移除。密钥使用 CShell 私有加密存储，不写入外观配置，不返回给模型。

在智能体访问权限开启“网络搜索（Tavily）”后，工具 `tavily_search` 提供基础/高级搜索、结果数量、主题、时间范围和域名过滤，返回标题、来源 URL、摘要。外部内容始终视为不可信数据。插件停用后工具移除，旧调用也重新检查插件与 Key 状态。

选用逻辑：读取官方 `/usage`，取 Key 与账号可用额度的较小值，扣除本地已用及在途预留，优先选择余额较多的 Key。额度缓存两分钟，查询合并；最多四个并发搜索。默认不使用按量付费余额，配置页可显式允许已在官方配置的按量额度，不修改 Tavily 计费设置。

同账号多个 Key 不代表多个套餐；没有账号 ID 的官方用量响应不能可靠合并账号，页面分别展示 Key 和账号用量，不汇总成总余额。其他应用消耗及同账号跨 Key 消耗可能使缓存滞后，最终以服务端拒绝和下次官方刷新为准。

基础搜索 1 credit，高级 2 credits；明确关闭自动参数升级，正常请求不隐式提价。鉴权失败、限流、额度拒绝会暂时跳过当前 Key，一次调用最多尝试三个 Key。超时、连接错误或结果未知不会自动重复请求，暂按预计费用计入本地消耗，等待官方刷新校正。服务端错误正文不透传，防止秘密回显。

配置页“保存并检测”调用用量接口，不发付费测试搜索。自动测试使用模拟官方响应；未使用用户真实 Key 完成线上搜索验收，不能据此声称实际账号/额度可用。

参考：[官方用量接口](https://docs.tavily.com/documentation/api-reference/endpoint/usage)、[官方搜索接口](https://docs.tavily.com/documentation/api-reference/endpoint/search)。

范围：本次是 CShell 插件和 CShell 智能体工具。未声称已在独立 CAgent 或外部 MCP/API 目录发布同一扩展。
