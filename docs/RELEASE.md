# CShell 0.7.0

本版集中完善终端与多机器工作台、CAgent 远程桌面、内置文本编辑和智能体模型接入。

- 紧凑工作台与平铺、主次、小窗视图；支持 SSH、CAgent 桌面及终端、本机终端的组合与布局保存。
- 远控加入五档画质预设、默认键鼠控制、采集恢复与同目标多窗口共享；Android 同步画质和输入恢复行为。
- SSH 文本编辑支持手动保存、实时同步、有界回退及真实 Python 环境补全。
- OpenCode 账号级模型选择、Go 用量显示，多面板布局与流式等待反馈优化。
- 微信文件发送与权限入口完善，工具包实验能力与正式功能明确区分。

建议同时更新 Windows CAgent，以使用本版远控恢复和无上限自适应能力。旧身份、连接与明确关闭的权限继续保留。

平台包以本发行实际附件为准。Windows 包未做商业代码签名；macOS 签名和公证以产物说明为准。锁屏、纯无显示器、真实公网长时间视频和部分移动设备场景仍需实机验收，不宣称全平台被控能力完全相同。

详细范围与已知限制见 [0.7.0 说明](https://github.com/Yeqi99/CShell/blob/main/docs/RELEASE-0.7.0.md)。
