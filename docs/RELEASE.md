# CShell 0.3.2 预发布

Android 重新设计为移动工作台：服务器首页、搜索与分组、独立连接页、会话列表和设置。保留终端与表单草稿，支持明暗主题、极简模式与还原，连接操作固定在底部，不遮挡滚动内容。服务器列表只保存连接元数据，凭据不落盘。

桌面和 Android 的设置加入“检查更新”。从 GitHub Releases 查找适配安装包（包含预览版），下载后验证 SHA256。桌面打开系统安装包，Linux 显示已下载 AppImage 的位置，由用户替换并赋予执行权限；Android 额外校验包名、递增版本号和签名，再请求系统安装确认。更新不会在后台自动终止会话，请先保存工作。

**Android 升级注意**：从此版起采用持久化发布签名。0.3.1 使用临时调试签名，无法保证直接覆盖；如果安装提示签名冲突，需要先卸载旧版，卸载会清除本地配置。0.3.2 及后续版本使用同一发布签名，支持覆盖升级。APK 文件名仍保留 android-test，表示预览测试渠道。

Windows x64、macOS Apple Silicon/Intel、Linux x64/ARM64 与 Android 的可下载文件以本发布页实际附件为准。Windows 未商业签名，macOS 未签名或公证。Android 真机键盘、系统安装流程、后台会话保持仍需测试，移动端功能不等同于桌面全集。

Docker、Conda、Python 编辑器、AI 工作台仍主要面向桌面。代理配置和 Agent Runtime 重构不包含在此版。MIT 源码、插件和应用清单继续由 GitHub 托管。SHA256SUMS.txt 用于校验下载完整性。
