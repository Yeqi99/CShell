# CShell / CAgent 0.6.39 开源预览

## 本次更新

- Windows CAgent 远程桌面新增可选系统桌面服务与虚拟显示配置。系统服务经显式管理员安装，CAgent 以管理员运行后可进入当前会话的系统桌面采集路径；仍须输入 Windows 登录凭据，不切换 RDP 会话。
- 通过系统服务提交 Ctrl+Alt+Delete，仅在 Windows 策略允许且当前会话已授权控制时显示按钮。提交不等于登录成功。
- 无显示器主机可检查并安装固定版本的签名虚拟显示驱动，提供独立设备、布局检查、失败回滚和任务恢复/移除；Windows Server 明确为实验支持。
- OpenCode 多密钥、真实调用检测、模型选择与官方设备授权；Tavily 多密钥网络搜索与用量选择。
- 远端 CAgent 微信消息接入 CShell 事件规则，按机器、账号和订阅隔离游标。人工对话可管理规则，事件触发会话不能自行修改规则。
- SSH 文件页面重新打开入口、扩展配置和模型选择界面优化。

## 验证与限制

Windows 本地 323 项自动化测试、生产构建通过；原生输入状态 41 项断言、管道取消/EOF 测试、虚拟显示布局与 ABI 检查通过。发布平台以实际附件和校验清单为准。Windows 包未做商业代码签名。

**锁屏输入、真实虚拟驱动加载、纯无屏与重启远控尚未实机验收。** 用户安排后续统一验收，源码和模拟测试不等于硬件兼容证明。普通 CAgent 不会静默取得系统桌面权限；升级 CAgent 后需要更新系统服务的运行时注册。详见 `docs/DESKTOP-SYSTEM-BROKER.md` 与 `docs/CAGENT-VIRTUAL-DISPLAY.md`。

Android/macOS 实机验收、OpenCode 实际账号与额度、不同网络环境下长期远控仍待验证。微信桥接限适配版本；安全软件分类复核尚未结束。API/MCP 已进行分钟级并发、撤权及资源回收测试，不宣称完成小时级、多物理主机综合验收。

本版本不宣称消除所有商业化前风险，详见 docs/OPEN-SOURCE-CLOSEOUT-0.6.33.md 与 docs/AGENT-RELIABILITY-0.6.35.md。
