# CShell 0.8.4

本版统一连接工作区，并完善连接整理、网络诊断与智能体使用体验。

- SSH、CAgent 与 RDP 从连接列表进入机器桌面；离线保留工作区和重试入口。SSH 提供终端、文件及 CAgent 安装检查。RDP 使用系统查看器；仅有 RDP 凭据不能自动执行远程安装。
- CSV 与多连接文本批量预览导入，凭据不显示在预览；支持侧栏机器拖动排序与分组。
- 可自定义字体、字号、侧栏密度。终端默认复制粘贴，折叠操作栏保留中断等原生控制；可切回原生快捷键，辅助配色可关闭。
- 真实 TCP 延迟诊断明确源与目标；机器信息展示 CPU、内存、磁盘、网络与系统支持的 GPU 数据。大文件分析明确目录和扫描上限，可取消。
- 智能体会话草稿与历史恢复、后台并行任务；权限支持全选和分区批量设置。改善小模型工具调用与错误反馈。
- 应用代理设置支持手动代理；所选代理失效不回退直连。会员机器出口由 Pro 服务核验。

Windows 安装器未 Authenticode 签名，macOS 未公证；macOS/Linux 安装体验未实机验证。Android 系统仍要求用户确认安装。各平台仅公布成功构建并核验的附件。
