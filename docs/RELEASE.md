# CShell 0.3.0 预发布

MIT 开源终端工作台。此次版本加入按屏幕可用区域缩放的窗口、保留会话的极简模式、多个 AI 基座、加密会话记录、机器/分组权限和三种审核等级。

插件与应用目录位于仓库的 `marketplace/`，版本固定为发行标签，通过 GitHub HTTPS 提供，不需要自建市场服务器。离线仍可使用随包目录；远端应用从官方供应商或系统包仓库下载。内置功能提供器随客户端编译，市场清单用于安装/启停；第三方 v1 插件仅支持声明式命令，不运行任意扩展代码。

Windows：NSIS `.exe`；macOS：Apple Silicon / Intel `.dmg` 和 `.zip`；Linux：x64 / ARM64 `.AppImage` 与 `.deb`。只以成功上传的实际附件为准，缺少的附件表示未完成该平台发布。桌面包暂未购买签名证书，macOS 未公证。

Android 使用独立原生 SSH 层；目前是移动终端实现，**不等同于桌面功能全集**。在完成 APK 编译、签名和设备验证前不发布或列为可用下载。Docker、Conda、Python 编辑器和 AI 桌面工作台尚未移植到 Android。

SHA256SUMS.txt 用于核对下载完整性。AI 使用前请阅读 `docs/AI.md`；默认无远端操作权限，“全放行”仍受已授权范围限制。
