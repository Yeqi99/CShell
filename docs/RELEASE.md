# CShell 0.4.7 预发布

本版更新 Windows 本机终端与智能体工作流，并修复 AI 消息 Markdown 显示。

- **Markdown**：表格、加粗、列表、行内代码与代码块正确显示；宽表格在消息内部横向滚动。已有聊天记录自动使用新渲染，代码复制使用桌面剪贴板。
- **智能体**：紧凑消息与输入区、会话历史和独立草稿、流式回复、兼容模型空工具调用；模型配置与权限按需展开，权限树提供明确保存反馈。
- **权限**：按应用能力与机器范围统一授权，支持机器覆盖；审核策略不扩大授权范围。新增受权限控制的 CShell 连接清单工具，连接提取沿用模型路由。
- **Windows 本机终端**：通过 ConPTY 支持 CMD / PowerShell；环境覆盖单独保存，仅对新会话生效。WSL 通过插件发现真实发行版并提供安装入口。
- **工作台**：统一连接入口，标签单行横向访问，保留真实会话与编辑草稿。

## 下载与验证

提供 Windows x64 EXE、macOS arm64/x64 DMG 与 ZIP、Linux x64/arm64 AppImage 与 DEB、Android 测试 APK。所有附件由同一发布流水线构建，SHA256SUMS.txt 提供校验值。

本地 42 项自动化测试及打包后 Windows 智能体回归通过，覆盖 Markdown、复制、会话草稿、明暗主题和窄窗口。发布流水线另行执行平台构建与既有桌面测试。

Windows 未商业签名；macOS 未签名/公证。Android 使用既有持久化发布签名。本版仍为预览版，跨平台构建不等于所有平台真机交互验收；Android 不等同桌面功能全集。本轮未重复 Windows 安装/卸载测试。
