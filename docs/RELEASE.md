# CShell 0.4.0 预发布

本版收口工作台交互、统一连接边界、本机统计与 Android 移动界面。

- **连接架构**：Provider 管理连接生命周期、配置校验及终端/文件能力；Agent 继续经统一 Tool 注册表与权限审核调用。SSH 为实际内置适配器，环境子会话纳入相同生命周期。新增 Provider 声明与 Client 能力发现数据协议。
- **统计与历史**：顶栏独立标签，日期/类型筛选、活跃图、来源分布、记录搜索、CSV/HTML 导出、暂停与清空。只存本机元数据，不记录密码、命令、路径或聊天正文。仅统计启用后的真实操作，不补造历史或 Token。
- **Android**：按浅色/蓝色移动概念重构首页、连接、终端、文件、设置导航。真实 SFTP 目录、文本预览、系统选择器上传下载；切页保留终端与草稿。沿用 0.3.2 签名，可覆盖升级。
- **工作台**：分类设置、精简 AI 配置、插件专属入口、明确拖放预览、双击服务器直接连接、Vim 六种退出、本地多目录面板、CPU 型号/GPU/进程检查。
- **小窗**：极简拖动/缩放/置顶，独立浮窗复用同一 SSH 会话，支持仅观察、自动隐藏标签和还原。
- **AI 填写**：表单仍为主入口，可选已配置基座提取连接文本，只填字段、不执行工具或自动连接。

## 下载与更新

Windows x64 EXE；macOS arm64/x64 DMG 和 ZIP；Linux x64/arm64 AppImage 和 DEB；Android 8+ APK。SHA256SUMS.txt 包含全部十个安装附件的校验值。设置中可检查、下载并校验更新，安装由系统完成；Linux AppImage 需手动替换并赋予执行权限。

Windows 未商业签名；macOS 未签名/公证。Android 使用持久化发布签名，旧 0.3.1 临时调试签名可能需卸载后重装（会清除配置）。本版仍为预览版，macOS/Linux 交互和 Android 真机、软键盘、后台会话与文件选择器须继续验收。

## 明确边界

Provider 协议不是已完成全部连接器：Client、RDP、VNC、直连 TLS Docker 尚未交付，远端大文件/屏幕通用流协议和隔离第三方插件宿主仍待实现。Docker 现有功能通过 SSH 隧道访问 Engine HTTP API。Android 不等同桌面功能全集；没有用虚构任务填充任务页。统计中的文件/AI 是请求次数，不是手动 Shell 命令数、Token 或业务执行成功率。代理配置仍未包含在本版。
