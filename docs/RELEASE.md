# CShell 0.8.10

0.8.10 已正式发布；GitHub 标签、全部附件及香港分平台更新渠道已核验。

- **Pro 配置同步**：保留按 ID 合并列表的顺序；Android 保存手机未消费的 FTP / SFTP 连接位置与未知字段。
- **Tavily 账号**：账号与 Key 纳入加密同步和确认导入，按量付费许可、安装和运行权限留在本机。未配置时不添加字段，删除最后账号后保留空列表删除标记；旧云缺字段不覆盖本机，失败回滚恢复原数据。
- **机器桌面外观**：补齐背景、主题、命名方案与图片的可选同步段，不恢复运行窗口或原生桌面临时状态。本机与云段、定向回归及真实界面验证已完成。
- **SSH 多面板**：文件和机器信息不再因打开智能体而被强制隐藏，收起后可恢复，窄工作区保留入口；继续复用原生 SSH PTY。
- **SSH 输入传输**：TCP 连接建立后关闭 Nagle 小包合并等待，及时发送交互输入；网络往返和服务器处理延迟仍存在，不把此项当作用户延迟根因已确认。
- **输入与模型**：模型菜单补齐键盘焦点、空结果与定位；命令台异步结果不抢焦点。OpenCode 按钮明确为“设为默认模型”，与可用性检测分开。

新增 Tavily / 桌面外观云段需要新版桌面客户端。0.8.9 遇到不认识的段时安全拒绝恢复，不清空云端；没有新段的账号继续正常兼容。OpenCode 服务端拒绝仍按真实结果显示，不自动切换付费模型。

完整步骤见官网手册，最终证据及边界见 [0.8.10 验收记录](RELEASE-0.8.10.md)。本版继续使用直连 SSH，并禁用客户端 TCP Nagle 小包合并等待，不宣称用户网络延迟已消除。Windows 签名、macOS 公证、跨平台实机限制和 Android 必需系统确认沿用实际发行说明。
