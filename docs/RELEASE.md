# CShell 0.8.9

本版补齐独立文件连接、工作台命令入口和可视化工具，并统一开源与 Pro 的连接体验。

- **FTP / FTPS / SFTP**：新建连接直接进入文件工作区，支持普通文件上传下载、目录浏览、重命名和传输队列。SFTP 不要求 Shell；FTPS 校验证书，不回退明文。CSV 和多连接文本可预览导入这些协议。
- **原生与可视化**：默认双击 SSH 打开原生终端，RDP 打开远程桌面；全局与单台连接均可记住可视化选项。可视化 SSH 复用同一 PTY，并可折叠打开文件与机器信息，保留历史和草稿。
- **工作台与 CLI**：概览、命令行、可视化三种视图；应用内命令台和外部 `--cli` 共用真实能力目录、参数契约、目标范围和授权。
- **MCP 与智能体**：浏览器标签、元素读取、截图、交互和有限抓取；受支持的 CAgent 远控可获取画面、输入鼠标键盘。浏览器读取/操作、远控观看/输入分别授权，截图使用标准图像内容。
- **自定义扩展**：独立进程工具包可导入或拖入，授权后进入智能体、CLI 和 MCP。安装、启用和运行授权分开，更新内容后重新授权。微信扩展继续独立提供，不捆绑主程序或公开市场。
- **OpenCode**：输入区直接提供账号与模型二级菜单，自动刷新目录和失效状态，无需逐个填入基座。桌面接入官方 1.19.4 私有运行时，模型请求使用所选网络出口。实测部分免费模型仍被服务端返回 403，官方客户端接入不等于服务商允许调用，不自动换付费模型。
- **界面与兼容**：多面板分类布局、较小的侧栏默认字号、折叠外观菜单；RDP-only 提供 Windows 安装指南。硬件和应用市场按目标实际能力兼容，支持安全握手的 CAgent 等空闲后核验更新。

完整步骤见官网可搜索文档与仓库 `docs/manual`；验证及平台边界见 `docs/RELEASE-0.8.9.md`。

独立 FTP / FTPS / SFTP 入口和工作台命令模式属于桌面端，Android 保留其已实现功能并保留不消费的云字段。Windows 安装器未代码签名，macOS 未公证；原生 CI 不等于所有实机验证。Android 和系统安装器保留必要确认。应用内更新使用香港分平台渠道，开源、Pro 与 CAgent 不跨渠道替换。
