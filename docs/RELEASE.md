# CShell 0.8.1
本次为 0.8.0 后续修复版：代码编辑器安装后直接进入编辑界面；改善手机机器桌面、连接恢复与应用布局；修复浏览器切换机器时旧请求覆盖状态、打开失败仍继续导航及手机开发应用重连后仍离线的问题。


本版收口机器桌面、浏览器与远程开发应用，为后续 Pro 开发保留统一的机器能力边界。

- Linux 与 Windows cagent 连接进入机器桌面，应用窗口与任务栏保留状态；远控作为独立应用。
- 浏览器在控制端渲染，通过所选机器访问网络；连接中断时停止访问。标签、历史、收藏及登录资料按机器保存，支持历史删除、登录资料清理、地址联想、网页复制与全屏。
- Android 增加原生浏览器操作栏、标签切换、历史/收藏、站点数据清理、全屏和系统文件选择。需要支持代理覆盖、独立 Profile 与 document-start script 的 Android System WebView；不满足时不显示入口。
- Codex 与 Claude Code 提供项目会话、流式输出、执行记录、独立官方登录资料和多基座配置。切换模型服务新建会话；密钥加密保存。客户端在目标机器安装和执行，Android 是控制端，不宣称在 Android 本机运行官方 CLI。
- 应用市场增加“代码编辑器”，基于 code-server 独立包，安装目录可选，校验上游 SHA256 和实际版本。编辑器仅监听目标机器回环地址；手机提供文件、搜索文件、命令、保存触控入口。

code-server 自动安装支持其实际提供的 Linux/macOS x64/arm64 独立包；Windows 请使用真实 WSL 环境，未实现的 Windows 原生包不显示为可安装。上游缺少可核验摘要时拒绝安装。安装不修改系统软件源、全局 PATH 或已有 Node/Python。

Android 浏览器一次绑定一台机器，切换机器会关闭旧浏览器通道并恢复对应机器的标签。网页下载暂未接入，文件传输使用机器文件应用。为保持目标网络边界，移动网页的 WebRTC 与 Service Worker 网络功能暂不开放。账户网站是否接受内嵌浏览器由服务方决定；未代用户执行真实账户登录验收。

发布附件以完成构建、Android 持久签名及摘要核验的实际产物为准。Windows 安装包未做商业代码签名，macOS 未做商业签名或公证；Android 原生回归通过后才进入发布步骤。
