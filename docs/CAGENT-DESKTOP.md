# CAgent Desktop 自研远程桌面

状态：开发中，尚未发布、尚未通过远程服务器验收。不能将 CShell 的 mstsc 启动入口称为本应用。

## 范围与架构

作为 cagent 应用市场独立可选应用。自研采集调度、媒体管道、传输协议、显示和输入链路；系统原生采集与编解码 API 可用，不依赖其他远程桌面软件引擎。

Windows 被控端优先 Desktop Duplication + Media Foundation H.264 编码。能力探测报告真实显示尺寸、刷新率、编码器、硬件/软件路径和失败原因；远程会话、锁屏或安全桌面不可采集时明确报告，不伪造帧。后续平台使用同一版本化协议实现原生后端。

输入控制与画面分离。可靠加密控制通道负责身份、权限、输入状态、关键帧请求和统计；低延迟视频通道使用有界最新帧调度。拥塞时丢弃过时画面而不是不断堆积；预测帧丢弃必须恢复关键帧依赖。断开释放所有按下的键和按钮；恢复必须重新认证并以新会话代次拒绝旧输入。

不设产品级分辨率、帧率、码率上限。自动模式根据源显示、编解码吞吐、链路带宽、RTT、抖动、丢包和排队时间调整。协议长度、内存预算、原生 API 数值范围仍必须检查，并向用户说明实际能力限制。手动模式允许指定目标，报告实际达成值和瓶颈。网络恢复时缓慢提升，降级速度快于升档。

复用 cagent 身份和明确授权原则，应用安装默认不打开监听、控制或防火墙。公网连接需要设备身份核对、加密、独立观看/控制授权与恢复；中继不得终止目标端到端加密。CShell 客户端和未来手机/Windows/macOS/Linux 客户端使用公开协议，不绑定私有桌面客户端实现。

## 验收计划

先核验原生采集/编码/解码与输入，再核验本机端到端、受限身份与撤权、键释放、断线恢复；最后在用户指定测试服务器进行公网测试。记录捕获/编码/网络/解码/呈现时延、帧龄、实际 FPS/码率、丢帧和资源占用，加入限带宽、延迟、抖动和丢包条件，分别验证降级与恢复。仅通过实际测试的项目才能写入可用清单。

用户指定测试映射为外部 51919→内部9998、外部53090→内部9999。服务器凭据只由用户提供，不进入源码、日志、文档或发行附件。现有 RDP 仅作为部署/观察渠道，不作为自研远控引擎。

用户已明确：浏览器中的页面仅管理服务器参数，不能操作服务器桌面。部署入口是本机后台已打开的 Windows 远程桌面窗口，不应继续索取网页远控地址。当前 Windows 桌面操作工具初始化失败（kernel assets 路径不存在），尚未通过该窗口部署程序。

## 2026-10-17 会话与观看集成补充

上述早期遗留中的运行时接入、身份认证、观看/控制独立授权及客户端呈现已完成本机代码接线：可选能力包安装不自动授权或监听，桌面票据经既有已认证管理 RPC 下发，短期单次使用；媒体使用加密 UDP，控制使用加密 TCP。客户端主进程保管票据，渲染器仅接收帧。原生输入仍未向真实桌面注入验收。

公网部署目前需要可达的 Agent 管理通道（默认 TCP 24443，或另行配置的管理中继），另外需要桌面 TCP 和 UDP 端口。现有两项映射 51919→9998、53090→9999 仅覆盖桌面通道，不能独自完成首次管理连接和票据交换。管理通道与桌面端口复用、中继及自动断线恢复仍待实现/验收；未自动开放防火墙。

连续观看排查发现并修复两项调度竞态：质量重配时旧采集器 stdin 已结束后的迟到写入误关闭新会话；慢媒体发送与恢复定时器重复发放采集信用，导致重叠发送。新增每帧发送延迟 1150 毫秒的回归验证最大并行发送为 1，服务层 6 项测试通过。

旧 Electron UI fixture 通过 DevTools 将每帧转换成大 JSON 数组并往返 ACK，本身存在明显传输开销，不适合判定生产帧率。已确认动画标记位于唯一采集显示器且持续计时，实测无 UDP 丢帧但该 fixture 解码稀疏，不能据此宣称流畅。真实 Electron IPC 持续观看验收由主集成流程另行记录。公网性能、自适应网络恶化及恢复、真实键鼠跟手体验仍未验收。

## 桌面观看自动重连

已建立的桌面会话遇到明确网络故障时，观看器保留已应用画质，按 0.5、1、2、4、8 秒最多重试五次；持续连接 30 秒后重置重试次数。连接状态在观看区域可见，可随时断开。首次连接失败仍显示原因，由用户重试。权限撤销、认证失败、协议错误及未知错误不自动重试。

每次重连重新检查目标授权、重新请求一次性票据并建立新通道，不重用旧票据。主进程和观看器使用新代次，旧键鼠输入、帧回执和旧通道事件不能进入新连接；断线时释放按键并清空等待解码的帧。用户停止、切换目标或卸载观看器会取消定时重试；迟到的票据与连接会关闭。该机制不绕过已关闭的管理连接或授权。

验证：`tests/desktop-views.test.ts` 的故障注入测试覆盖新票据、画质保留、旧代次拒绝、取消、权限失败不重试及次数耗尽；`scripts/desktop-view-race-smoke.ts` 覆盖重连提示和迟到关闭事件。此处是隔离故障测试，不代表已完成公网断网恢复验收。

## 管理通道 TCP 媒体与现有中继（2026-10-17）

已增加 Agent 管理端口上的专用桌面二进制通道：先以既有 TLS 1.3 连接核对目标证书并认证调用方，再升级专用连接。桌面服务仍复核独立观看/控制授权及单次票据，桌面控制与视频各自使用方向隔离的 AES-GCM 密钥。透明正向或反向 Agent 中继只转发字节，目标身份和桌面会话密钥仍由两端验证。

`desktop.open` 可选择 `transport: management`；主进程调用 `ClientProvider.openDesktopStream`，把返回流传给 `connectDesktop`。该模式媒体和控制复用专用 TLS 连接，不建立 UDP Socket 监听，不需要额外桌面公网端口。配置 `directListener: false` 可停用独立桌面 TCP 监听，安装/授权仍不会隐式开启服务。旧 `direct` 模式继续保留 UDP 媒体；也可以让桌面 TCP 与 UDP 都使用 9999，通过外部53090的all映射访问，而管理TCP使用9998→51919。因此前文“三端口依赖”描述不适用于管理通道模式，也不是两项all映射的必然限制。

TCP媒体逐个有界分片写出，与控制消息交错；最多一帧正在发送，写入停滞5秒终止会话，接收记录长度和重组预算严格限制。TCP重传可能引入队头阻塞，因此它是防火墙/NAT/中继兼容路径，不能把可靠交付等同低延迟保证。

本机隔离测试已覆盖直连管理TLS、透明正向中继、仅出站反向中继三条真实socket路径：512KiB合成帧完整接收、错误票据proof拒绝、管理权限不隐含观看授权、撤销调用方后关闭会话并停止采集。另覆盖TCP媒体非法记录长度拒绝。没有在用户公网服务器部署验证，不宣称跨公网性能或真实网络恢复验收完成。

整网断开恢复补充：桌面首次连接从真实已连接终端取得已配对设备 ID 与证书指纹，并在主进程绑定到该观看生命周期。网络故障导致终端 `activeTargets` 消失不会自动撤销这条绑定，恢复时仍按原设备身份重新认证；不能凭渲染器任意设备 ID 创建绑定。显式关闭连接、删除设备、身份改变、扩展停用或桌面权限拒绝会终止恢复。`tests/desktop-targets.test.ts` 模拟终端与桌面同时掉线、跨过授权巡检后重新连接原设备，以及设备身份变化后的终止；没有重新打开交互终端。

## 2026-10-17 公网部署与原生性能修复

用户已在获准的 Windows 服务器启动隔离验收服务，并提供设备证书供控制端精确绑定。公网管理 TLS 及桌面加密通道已握手成功；首帧失败定位为服务器 RDP/Hyper-V 显示的 DXGI `0x80070005`，不能把通道握手成功记作观看通过。原生程序现优先 DXGI，失败时仅在当前会话 Default 输入桌面使用 GDI BitBlt/DIBSection；每帧检查桌面，不切换安全桌面或提升权限。服务器修订程序 `--probe` 已返回真实 1920×1200 桌面与 GDI 回退，服务器仅报告系统软件 H.264 编码器。

硬件路径改为 DXGI GPU 纹理、D3D11 视频处理器 NV12 转换和 Media Foundation GPU 表面输入；CPU 回退保留。颜色统一 BT.709 limited，GPU/CPU 各 30 帧真实编码与浏览器解码色块对照通过。高精度私有等待计时器避免系统 Sleep(1) 粒度限制，不修改系统计时器分辨率。本机原生 20 秒实采 1151 帧（57.55 FPS）；真实 Electron IPC、管理 TLS、中继及断流恢复组合 34.428 秒解码 1677 帧，末尾 2.5 秒 53.2 FPS，解码 P50 1.7 ms/P95 4.6 ms、失败 0。这些是本机实测，不能当作公网服务器性能。

自适应不再把静态画面的低传输量误当带宽上限，以有界窗口 P75 过滤尖峰，按并行处理阶段判断负载；普通异常持续后降级、严重拥塞立即响应、恢复设置滞回，修复仅比例变化不重配。故障状态增加同一调用方可读的 `lastFailure`，保留 HRESULT、安全摘要和时间，过滤原始路径；加密关闭原因先发送再断开。

服务器更新暴露同版本能力包摘要变化后只刷新旧文件的缺陷，已修复为重新核验并安装，仍仅保留旧权限与新权限的交集。桌面包升级为 0.1.1。更新后的服务器监听恢复、真实公网画面渲染、键鼠反馈及公网中继尚待后续验收；未更改防火墙、未修改开机启动、未发布 GitHub 发行版。
