## 0.8.16 合并范围与使用文档

0.8.15 没有单独公开发布。其当前用户 X11 原生桌面、标签与资源布局、字号即时预览、配置响应竞态保护、Linux 指令安装改动并入此候选；历史验证范围见 [0.8.15 记录](RELEASE-0.8.15.md)，不得据此复用旧草稿包。

本轮补充：

- 真实网卡速率、计数与有界进程网络采样，长挂载路径/容量分行；本机 ICMP 与 TCP 检测分开。证据见 [网络验收](REMOTE-NETWORK-ACCEPTANCE.md)。
- 内嵌 Windows RDP、覆盖层与独立远控会话恢复流程；需以最终首帧、真实键鼠验证判定，不能仅凭显示设备检测标记可用。
- Core / Pro MCP 端口及令牌隔离，客户端按实际服务查询能力；同令牌历史来源不作未证实归因。
- DeepSeek 等模型兼容及网络出口处理；认证、生成与工具调用分别验证。
- 文件大小采用二进制单位，真实传输进度和平均吞吐率；[传输验收](FILE-TRANSFER-ACCEPTANCE.md) 记录实际美国服务器 16 MiB 上传、下载摘要一致、真实进度及断连取消；高延迟线路下载吞吐仍有限，不能据单次上传测速承诺固定速率。
- SSH / SFTP 文件权限面板：读取、单项修改、句柄读回；不递归、不提权，FTP/CAgent/Windows ACL 不显示未实现编辑。见 [权限实现与边界](FILE-PERMISSIONS.md)。
- 终端尺寸与工作区稳定性继续收口；长时间会话/最终安装包证据须由对应任务更新，不将组件测试当作网络延迟或成品运行验收。
