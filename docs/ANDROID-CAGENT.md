# Android 内置 CAgent

Android CShell 提供可选的内置 CAgent 扩展。无需安装第二个应用，手机同时可以作为 SSH / CAgent 控制端，以及屏幕共享被控端。

## 开始使用

1. 在手机 CShell 的「扩展」中打开 CAgent，启用并保存连接密码。
2. 配置监听端口，默认 24443。填写其他设备可访问的 IP 或域名；使用端口映射时填写对外端口。
3. 点击开始屏幕共享，在 Android 系统窗口中确认共享整个屏幕。
4. 如需操作手机，在系统无障碍设置中启用 CAgent 服务。
5. 复制连接信息，在另一台设备的 CShell 中导入并核对设备身份，输入连接密码。

复制内容包含地址、端口和设备身份，不包含密码。手机监听所有网卡；连接使用 TLS 1.3、密码配对及持久化设备身份。修改监听端口、密码或停用扩展会结束当前共享，修改对外地址不会重置设备身份。

## 连接与控制

Windows、macOS、Linux CShell 复用 CAgent 桌面协议进入手机工作区；Android CShell 也可使用已有桌面观看和触摸操作入口。手机工作区按实际能力提供远程控制、文件和应用入口，不显示虚构的 CMD 或 PowerShell。远控画面默认完整适配，窗口按手机实际横竖屏比例调整；连续同尺寸画面不会重置手动拖动的位置。

左键对应点击，拖动在松开时提交触摸手势；右键对应长按，滚轮对应滑动。Esc 对应返回，Windows 键对应主页。支持普通可编辑控件的文本输入及部分基本按键；无障碍服务不等同于系统级任意键盘注入，不保证所有应用和快捷键都支持，密码控件不会通过此接口写入。

当前采用 TCP 视频传输与系统 H.264 编码，队列有界，支持关键帧恢复、质量调整及断开后重连。编码尺寸、帧率和码率受手机实际编码器能力约束，不宣称达到桌面端的「无上限」模式。

## 智能体界面、短信与电话工具

CShell 连接实际手机后，可以通过该机器的能力工具读取当前无障碍界面结构（密码文字不返回），并结合真实桌面画面与输入进行操作。手机端必须先授予辅助控制权限；电脑端的授权不能替代 Android 系统授权。

手机支持电话硬件并授予对应权限后，工具目录按实际状态提供：

| 工具 | 用途 | 手机系统条件 |
| --- | --- | --- |
| `android_ui_read` | 读取当前可访问界面结构 | CAgent 辅助控制已开启 |
| `android_sms_read` | 读取最近收件短信，支持时间和条数筛选 | 读取短信权限 |
| `android_sms_send` | 使用手机默认短信 SIM 发送短信 | 发送短信权限及有效默认短信 SIM |
| `android_call` | 拨打非紧急电话 | 拨号权限及可用电话服务 |
| `android_call_answer` | 接听当前来电 | 接听电话权限及当前有来电 |

发送、拨号和接听需要唯一操作编号；同一个编号重试不会重复执行。返回“已提交”只表示已交给 Android，不表示短信送达或电话接通。操作结果不明时不会因重新连接自动重发。当前实机验收未发送短信或拨打电话，不能把画面和输入验证视为运营商能力验收。

## 是否需要每次重新开启共享

普通断线或关闭电脑上的观看窗口，不会主动结束手机已有的屏幕共享。只要手机投影仍有效，重新连接即可继续观看和控制，无需再点录屏确认。0.8.18 Pro 已在 Android 16 实机验证同设备身份断开后重新连接。

手机重启、覆盖安装、进程被结束，或者用户及系统停止投影后，需要在手机上重新开始共享并确认。录屏授权属于本次投影会话，不能设置为永久授权；服务保持运行也不等于授权永久有效。锁屏导致投影结束时同样适用。

## Android 系统边界

- 每次重新开始共享都需系统录屏授权；授权不保存，进程结束后不会静默恢复录屏。
- 设备连接通过 `connectedDevice` 前台服务保持，屏幕共享期间同时使用 `mediaProjection` 类型。关闭页面不停止连接；通知中的「停止连接」、关闭扩展或更改监听/密码会停止服务并使旧票据失效。
- 系统结束录屏时，仅关闭当前视频与输入，保留已认证的设备管理监听及配对身份。解锁手机后，若共享授权仍有效，可以重新连接桌面；若授权已被系统撤销，需在手机上点击重新共享并确认新的系统授权。不会复用失效授权或把缺少授权显示成应用未安装。
- 系统锁屏、受保护画面和应用禁止截屏区域不能由普通应用绕过。
- Android 15 QPR1 及后续版本锁屏会自动结束屏幕投影。息屏/锁屏期间停止向观看者发送画面和注入输入，管理状态会说明恢复步骤；这不是可以远程输入系统锁屏密码的方案。
- 需要可达网络：同一局域网、可达公网 IP 或正确的端口映射均可。运营商 NAT 不保证入站连接；同账号设备发现与会员中继可在账号设置启用；仍需手机 CAgent 服务运行及后端身份和权益校验。系统录屏和无障碍授权不随账号同步。
- 屏幕共享期间即使暂时没有观看者仍运行采集，需留意电量；后台保活还受手机厂商系统限制。
- 模拟器协议、录屏测试与实体手机验收分开记录，不将模拟器结果视为所有手机兼容保证。

前台服务不保证网络永久在线：Doze、省电策略、厂商后台限制、网络切换和强行停止应用仍可能中断连接。没有静默开机启动、自动解锁或强制关闭系统省电的逻辑。

此处「管理连接」指已有认证、设备状态、应用安装状态及桌面状态查询。Android 被控端不提供系统终端或任意远程设置。0.8.20 增加下述受限文件与应用能力；手机作为控制端访问其他机器的文件是另一项能力。

官方依据：[屏幕投影生命周期与锁屏](https://developer.android.com/media/grow/media-projection)、[前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types)、[Doze 网络限制](https://developer.android.com/training/monitoring-device-state/doze-standby)。新增原生回归覆盖模拟投影撤销后的监听、配对身份、安装状态和恢复；真实手机锁屏、系统撤销、通知停止及再次授权仍需实机验收。

## 0.8.20 文件与应用

在手机机器桌面打开「文件」，可浏览 CAgent 的专用共享目录，以及在手机文件页通过系统选择器授权的目录。支持分块传输、新建文件夹、重命名和删除；系统授权撤销或只读时明确提示，不开放其他应用的私有数据。当前单文件上传上限为 512 MiB。

「应用」列出手机真实可启动的应用，支持按名称或包名搜索并请求打开。Android 可能限制后台启动，发送成功不等于应用已经到达前台；可在远程控制中核对结果。应用和文件能力同时注册为智能体工具，继续遵守当前连接授权。

新入口需要匹配的 0.8.20 手机端。旧手机未提供能力时不会用占位数据冒充。新版本仍处于验收阶段，发布状态以官网更新目录为准。
