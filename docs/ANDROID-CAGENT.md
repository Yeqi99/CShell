# Android 内置 CAgent

0.7.1 开发构建为 Android CShell 增加可选 CAgent 扩展。无需安装第二个应用，手机同时可以作为 SSH / CAgent 控制端，以及屏幕共享被控端。

## 开始使用

1. 在手机 CShell 的「扩展」中打开 CAgent，启用并保存连接密码。
2. 配置监听端口，默认 24443。填写其他设备可访问的 IP 或域名；使用端口映射时填写对外端口。
3. 点击开始屏幕共享，在 Android 系统窗口中确认共享整个屏幕。
4. 如需操作手机，在系统无障碍设置中启用 CAgent 服务。
5. 复制连接信息，在另一台设备的 CShell 中导入并核对设备身份，输入连接密码。

复制内容包含地址、端口和设备身份，不包含密码。手机监听所有网卡；连接使用 TLS 1.3、密码配对及持久化设备身份。修改监听端口、密码或停用扩展会结束当前共享，修改对外地址不会重置设备身份。

## 连接与控制

Windows、macOS、Linux CShell 复用 CAgent 桌面协议进入手机工作区；Android CShell 也可使用已有桌面观看和触摸操作入口。手机只报告实际具备的屏幕共享能力，连接后不显示虚构的 CMD、PowerShell 或文件管理。

左键对应点击，拖动在松开时提交触摸手势；右键对应长按，滚轮对应滑动。Esc 对应返回，Windows 键对应主页。支持普通可编辑控件的文本输入及部分基本按键；无障碍服务不等同于系统级任意键盘注入，不保证所有应用和快捷键都支持，密码控件不会通过此接口写入。

当前采用 TCP 视频传输与系统 H.264 编码，队列有界，支持关键帧恢复、质量调整及断开后重连。编码尺寸、帧率和码率受手机实际编码器能力约束，不宣称达到桌面端的「无上限」模式。

## Android 系统边界

- 每次重新开始共享都需系统录屏授权；授权不保存，进程结束后不会静默恢复录屏。
- 共享由前台服务维持，通知提供停止入口。关闭页面不等于停止共享；停止共享后服务器关闭，旧连接票据失效。
- 系统锁屏、受保护画面和应用禁止截屏区域不能由普通应用绕过。
- 需要可达网络：同一局域网、可达公网 IP 或正确的端口映射均可。运营商 NAT 不保证入站连接；本版本没有同账号自动发现或云端穿透。
- 屏幕共享期间即使暂时没有观看者仍运行采集，需留意电量；后台保活还受手机厂商系统限制。
- 模拟器协议、录屏测试与实体手机验收分开记录，不将模拟器结果视为所有手机兼容保证。
