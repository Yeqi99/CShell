# 机器网络出口与 SSH 跳板

设置 → 网络与代理 → 机器出口可选择已保存的 SSH / CAgent，用于 CShell 本地模型 API 请求。SSH 必须先正常连接并核对指纹、保存凭据；CAgent 必须已配对并授予 HTTP 访问权限。不会改变系统代理，也不复用浏览器 Cookie。

SSH / SFTP 连接编辑里的“连接跳板”可选择另一台已保存机器。连接通过跳板的网络到达目标，但仍单独校验目标 SSH 身份及认证。最多八层，循环拒绝；失败不回退直连。RDP、FTP 不提供此选项。

这些配置不等于给远端所有进程设置代理。远端应用环境变量或软件代理需单独配置。

验证：两版 TypeScript 检查，机器路由并发复用、关闭清理、保存地址变化、未知 SSH 身份拒绝、循环拒绝、CAgent 目标地址传递测试。尚未执行真实跨机器 API 出口及 SSH 跳板验收，不应把单元测试称为实机验证。

## 远端应用代理终端

网络设置中的“远端应用的网络出口”选择当前 SSH 机器 A 与已保存的 SSH / CAgent 出口 B，打开独立代理终端。服务在 A 的回环随机端口监听，通过 SSH 反向通道和 B 的已认证网络通道转发 HTTP / HTTPS CONNECT。只有从此终端启动且遵守 HTTP_PROXY / HTTPS_PROXY 的软件使用代理；不改变系统设置和已有终端。关闭此终端、SSH 或 CShell 后停止代理。A 必须有 Bash 并允许 SSH 远程端口转发。CAgent-only 机器作为 A 暂不支持，作为 B 支持。

补充验证：真实本地 SSH 协议服务器验证指纹固定与 TCP 转发；真实 HTTP socket 验证 GET / CONNECT 经指定出口、非回环来源拒绝与服务释放。仍需真实远端 UI 操作验收。
