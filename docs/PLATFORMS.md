# 平台能力

本文对应 **0.7.6 源码实现**，不是已发布附件或全部真机验收完成的声明。CShell 作为控制端连接某台机器，与该系统上的 CAgent 能否作为被控端提供桌面，是两种不同能力。

## CShell 控制端

| 功能 | Windows | macOS / Linux | Android |
| --- | --- | --- | --- |
| SSH 终端、远端文件 | 支持 | 共用实现 | 支持 |
| CAgent 身份认证、机器连接、终端与文件 | 按目标实际能力 | 按目标实际能力 | Android 10+，按目标实际能力 |
| 控制 Windows CAgent 桌面 | 支持 | 共用桌面控制端 | 触摸、拖动、滚轮与文本输入映射 |
| 连接 Android CAgent 屏幕 | 共用桌面控制端 | 共用桌面控制端 | 共用移动控制端 |
| 五档画质、控制输入开关 | 支持 | 共用实现 | 已接入预设及挂起/恢复 |
| 多机器视图、多显示器、单区域关闭 | 支持 | 共用实现，实体多屏待验收 | 不提供桌面多显示器工作台 |
| 视图中的智能体会话、终端右键 AI | 支持 | 共用实现，沿用真实会话与授权 | 不等同桌面视图功能 |
| SSH 内置文本编辑器 | 支持 | 共用实现 | 尚未对齐桌面编辑器 |
| 本机文件浏览 | 桌面文件区 | 共用桌面文件实现 | 系统目录授权后浏览、文本预览、导入与导出 |
| 插件、智能体、事件工作流 | 桌面工作台 | 按目标能力启用 | 移动端功能集，不等同完整桌面插件运行时 |
| 本机 CMD / PowerShell / WSL | Windows 专属 | 不提供 Windows 本机入口 | 不适用 |

视图可组合 SSH、CAgent 终端、CAgent 桌面及已存在的智能体会话。关闭区域不结束从主工作台复用的终端，也不停止其引用的智能体任务；视图自行创建的终端会释放。关闭后保存布局才能保留下次打开的内容，其他显示器的布局不会随之删除。Windows 本机终端布局在其他系统上显示不可用原因，不会尝试启动 CMD。

Android 本机文件仅访问用户通过系统文件选择器授权的目录；预览最多读取 64 KiB UTF-8 文本，导入/导出采用流式传输。取消授权后需重新选择目录。它不要求“管理所有文件”权限，也不代表 Android 被控端向远端开放了手机文件系统。

## CAgent 被控端

| 能力 | Windows x64 | macOS / Linux | Android 内置扩展 |
| --- | --- | --- | --- |
| 身份与加密连接 | 独立运行时 | 独立运行时 | CShell 内可选启用 |
| 原生终端、文件、HTTP 与管理 | 按真实授权 | 按真实授权 | 不提供等价桌面能力 |
| 本地配置界面 | 原生小窗口 | 系统浏览器界面 | CShell 扩展页 |
| 自研桌面采集与输入 | Windows 采集与注入 | 未提供等价原生被控实现 | 系统录屏与无障碍服务 |
| 微信、WSL 应用包 | 依赖、版本及授权满足时提供 | 不列为可安装能力 | 不提供 |
| 系统桌面服务、虚拟显示驱动 | 可选，见专门文档 | 不适用 Windows 附件 | 不适用 |

Android 10+ 无需独立安装第二个 CAgent 应用。管理监听和屏幕投影生命周期分开；系统结束投影时仍可查询已授权的设备状态，但不能继续发送画面或注入输入。普通应用不能绕过锁屏、受保护画面或系统投影授权。Android 15 QPR1 及后续系统锁屏可能结束投影，需在手机重新授权；这不是远程解锁密码输入方案。Doze、厂商后台限制与网络切换仍可能影响连接。见 [Android CAgent](ANDROID-CAGENT.md)。

## 验证与发行范围

- 常规 CI：Windows 构建、单元测试、桌面交互检查与安装包；Android Web 类型检查、Java 文件流回归、原生构建和 lint。配置存在不代表某次执行已经通过。
- Release 矩阵：Windows x64、macOS arm64/x64、Linux x64/arm64。各架构执行构建与单元测试、CAgent 原生终端包检查；macOS 另有桌面观看/全屏检查，Linux 使用 Xvfb 与 DBus 检查打包应用。
- Android Release：持久签名密钥构建 APK；API 29、35 的 x86_64 模拟器协议与投影检查。它们不能覆盖所有厂商真机，尤其不能替代 Android 15 QPR1 后锁屏行为验证。
- 本轮本地可验证 Windows/共享 TypeScript 逻辑、界面 smoke、Android Java 编译与 lint、文件流有界读写；macOS/Linux 原生窗口、实体多屏、Android 系统选择器持久授权与后台锁屏仍需对应系统验收。
- 桌面构建配置不等同 Apple 公证或 Windows 可信签名。发行状态以实际构建、核验和上传的附件为准，不将尚未生成或上传的平台标记为已发布。

## 远程桌面边界

- 无上限画质依赖新版目标 CAgent，按网络、采集、编解码余量调整，不承诺固定最高帧率。
- 同一桌面控制端进程内的同目标视图可以共享流；不同设备不共享进程内连接。旧终端 target 与机器工作区 target 尚未合并。
- 当前桌面会话层最多 4 个订阅，布局每屏最多 12 个区域；终端区域与桌面订阅不是同一计数。
- Android 桌面使用 TCP，没有独立 UDP 或中继配置入口。连接要求地址可达；没有同账号云端穿透。
- Windows 锁屏、UAC、无显示器、GPU 重置、真实公网长时间视频和多个实体显示器仍需硬件验收，Windows Server 无头支持属于实验范围。参见 [系统桌面服务](DESKTOP-SYSTEM-BROKER.md) 和 [虚拟显示](CAGENT-VIRTUAL-DISPLAY.md)。
