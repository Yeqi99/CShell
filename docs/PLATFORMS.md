# 平台能力

版本：0.7.0。客户端能连接某台机器，与该系统能作为远程桌面被控端是两种不同能力。

| 功能 | Windows CShell | macOS / Linux CShell | Android CShell |
| --- | --- | --- | --- |
| SSH 终端与文件 | 支持 | 支持 | 支持 |
| CAgent 身份认证与终端连接 | 支持 | 支持 | Android 10+ |
| 控制 Windows CAgent 桌面 | 支持 | 复用桌面控制端实现 | 支持，触摸与文本输入映射 |
| 五档画质及键鼠控制意图 | 支持 | 与 Windows 控制端共用实现 | 已对齐预设及挂起/恢复 |
| 多机器视图与多显示器 | 支持 | 共用实现，窗口管理待实机验收 | 不提供桌面多显示器工作台 |
| 内置 SSH 文本编辑 | 支持 | 共用实现 | 尚未对齐 |
| 扩展、AI 与事件工作流 | 支持 | 按目标能力启用 | 不等同完整桌面工作台 |
| 本机 CMD / PowerShell / WSL | Windows 专属 | 不显示 Windows 专属入口 | 不适用 |

## CAgent 受控端

| 能力 | Windows x64 | macOS / Linux |
| --- | --- | --- |
| 独立运行时、身份与加密连接 | 支持 | 支持 |
| 原生终端、文件、HTTP 与管理 | 按真实授权提供 | 按真实授权提供 |
| 本地界面 | 原生小窗口 | 系统浏览器界面 |
| 自研原生桌面采集与键鼠注入 | 支持 | 未提供等价实现 |
| 微信、WSL 应用包 | 对应 Windows 依赖与版本可用时提供 | 不列为可安装能力 |
| 系统桌面服务、虚拟显示驱动 | 可选，实机边界见专门文档 | 不适用 Windows 附件 |

## 使用边界

- 无上限画质要求新版目标 CAgent；旧端仍可使用其他预设。它依据真实网络、采集、编码与解码余量调整，不是固定高帧率保证。
- 同一桌面控制端进程内的同目标视图可以共享流；不同客户端设备之间不共享该进程内连接。旧终端 target 与机器工作区 target 尚未合并。
- 当前桌面视图会话层最多 4 个订阅；布局每屏最多 12 个区域，终端区域与桌面订阅不是同一计数。
- Android 当前通过 TCP 传输桌面，没有独立 UDP 或中继配置入口。
- 锁屏、UAC、纯无显示器、GPU 重置、真实公网长期播放与多个实体显示器仍有待验收项目。Windows Server 无头支持属于实验范围。
- 平台源码检查、原生构建、模拟器测试和用户真机验收分别记录，不能互相替代。具体发行只以成功构建、核验并上传的附件为准。

发布状态见 [0.7.0 版本说明](RELEASE-0.7.0.md)，硬件范围见 [系统桌面服务](DESKTOP-SYSTEM-BROKER.md) 和 [虚拟显示](CAGENT-VIRTUAL-DISPLAY.md)。
