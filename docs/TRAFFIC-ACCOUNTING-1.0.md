# 流量额度与成本台账

默认没有月上限，保留既有账号权益。管理员可按账号分别配置中继与 MCP 上限；空值表示不限。扩容量绑定明确 UTC 月份，到月结束自动失效，扩容编号幂等且记录原因。成本费率独立于会员额度，按月、类别、入站和出站分别配置 CNY / USD 每 GiB 单价；没有配置时显示“尚未配置费率”，不虚构价格。

## 计量与硬限额

- 中继以每方向最多 1 MiB 的预算窗口放行数据。窗口用完、下一次传输发现已超过 5 秒或连接关闭时，结算实际放行字节、释放未用额度。新窗口必须重新核验设备租约和会员。额度服务不可用时停止放行，不回退无限模式。
- MCP 桥接在分发前预留请求与最大 8 MiB 结果预算，无法预留则不执行；成功、超时、撤销均结算已知载荷并释放剩余预算。未知执行不会自动重发。
- 预留和结算使用 SQLite 原子事务，包含全部同账号同类在途预算；重复结算必须具有相同计数。预算在取得时所在 UTC 月结算，跨月完成不会重复记入新月份。
- 统计值为服务授权转发的应用载荷字节。中继含目标端加密隧道载荷，不包含外层 TCP/TLS/IP 开销；MCP 为请求/结果 JSON 字节。因此成本列是按配置费率得到的估算值，不能冒充云厂商账单。

## 异常恢复

服务或进程崩溃时，已发出的预算持久保留。它不会因为重启被释放后再次消费，也不会未经核实计为零。后台“流量与成本”的待结算预留显示编号、账号、月份与预算；管理员核实传输记录后填写实际入站/出站量并说明原因，结算写入审计。无法核实的记录保持待结算，不伪造精确成本。

生产发布需同时更新 cloud-sync 和 cloud-relay；先更新支持窗口 API 的云同步服务，再更新中继。当前测试覆盖原子并发、幂等、真实 HTTP 鉴权、双向转发拒绝及后台响应式交互，尚需上线前负载与实机长连接验收。
