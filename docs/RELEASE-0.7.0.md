# CShell 0.7.0 开源收口说明

本文是 2026-10-20 的发布范围与验收边界。0.7.0 保持 MIT 开源许可，不包含 CShell Pro 商业服务。文档完成不代表发行完成：Windows 最终构建、安装核验、GitHub 上传及其他平台流水线结果由发布执行记录补充；未完成对应步骤的平台不得标记为已发布。

## 本版范围

### 工作台与多机器视图

- 工作台整合连接、已保存视图及当前连接编排入口，提供适应小窗口的紧凑布局。
- 支持平铺、主次、小窗预览；可从明确配置的来源创建命名视图，也可编排当前已打开的终端。保存显示器映射及相对布局，下次恢复。
- 来源包含 SSH、CAgent 远程桌面、CAgent 终端及本机 CMD / PowerShell。借用当前终端保留原会话与历史，关闭临时视图不关闭原终端。新建的配置视图拥有自己的资源，关闭时清理。
- 同一机器工作区的桌面视图共享采集流，多个窗口独立处理视频消费；慢窗口不应堵塞其他窗口。旧终端目标与机器工作区目标尚未跨目标合并。
- 配置视图中保存的任意启动命令仍由用户点击执行，恢复布局不会重新启动服务；明确配置的已有 screen 会话使用共享附加。
- 每屏最多 12 个区域、每个视图最多 96 个区域；具体恢复、资源边界见 [多机器视图](MONITOR-VIEWS.md)。

### 远程桌面与界面

- 远程桌面提供低、中、高、超高及“无上限”预设。无上限表示按实际显示器、编码器、网络及解码能力动态争取更高质量，不是无限码率、无限帧率或所有设备均能达到高帧率的保证。
- 控制端默认请求键鼠控制；目标端的实际授权、输入就绪状态和撤权仍生效。不能把默认勾选当作绕过远端权限。
- 极简模式和视图内观看收起不常用工具，保留可发现的展开入口。修复观看/控制状态切换期间迟到输入产生的错误；恢复不重放旧输入。
- 扩展区域按真实工作区宽度调整导航和留白，OpenCode 模型列表、智能体模型选择及输入工具行避免窄宽互相挤压；智能体等待状态增加克制动效。
- 仍使用自研采集、编码、传输和输入实现；Windows RDP 不是其底层引擎。系统桌面服务和虚拟显示属于单独的可选能力，限制见后文。

### OpenCode 与智能体

- OpenCode 保持独立扩展，可配置多个 Key 或使用官方设备授权流程。保存并检测验证账号、接入一个账号基座；之后直接在新智能体会话选择该账号下的 Go / Zen 目录模型，包含目录内的免费模型，不再逐模型手工添加基座。
- Go 与 Zen 路由分离，不因失败偷偷切换计费目录。公开模型目录表示协议已适配，不证明账号已购买对应套餐；实际权限和计费以官方服务为准。
- 保存账号不自动发推理请求。只有显式“检测所选模型”会发送简短请求并可能使用额度。凭据仍在后端加密保存；不读取浏览器 Cookie。
- 修正官方 Go 用量的 `usage.rolling`、`usage.weekly`、`usage.monthly` 结构，显示百分比与重置时间，兼容旧格式。未知格式不伪造余额；不提供现金余额查询。
- 会话固定所选模型并持久化，子任务继承；修改账号基座的默认模型不会把已有会话切到另一个模型。
- Chat Completions、Responses、Anthropic 和 Gemini 适配保留流式更新。首段文本不等待整个响应结束；首次输出前的等待动效不是虚构模型思考内容。
- 延续任务检查点、长任务启动/查询/停止、上下文压缩、日志分离、时间/成本代理/无进展限制。重启后未确认的副作用属于结果未知，不自动重放。成本代理不是供应商精确账单；详见 [智能体可靠性](AGENT-RELIABILITY-0.6.35.md)。

### 事件工具与微信范围

- 人工智能体会话在 `events.manage` 授权下可通过 `ai_event_list`、`ai_event_save`、`ai_event_set_enabled`、`ai_event_remove` 管理订阅。事件自身触发的运行仅能查询规则，不能通过收到的消息修改自动化。
- 已连接 CAgent 的微信消息可作为独立事件来源；设备、账号、订阅及处理会话分别绑定。事件游标加密持久化，断连、撤权、缺口和未知结果如实反馈；不会悄悄切回本机微信。
- 监听租约、规则启用、读取权限、发送权限是不同状态。创建规则不会自动启动监听或扩大权限；重启后不能承诺原生监听自动恢复或离线事件完整补齐。
- 微信正式能力受精确 Windows 微信版本和 DLL 摘要约束。小文件原生发送已有用户确认收到并打开的证据，但不代表所有附件类型及长期稳定性通过。文件发送需要独立 `sendFiles` 权限和收件人授权。
- 本次发布范围不将微信公众号留言、支付领取、红包，以及维护探针中的朋友圈点赞/评论/回复实验列为正式完成。朋友圈正式读取仍主要依赖已实现缓存，纯文字发布与实验互动不能混为一谈。
- Tavily 多 Key 搜索、SSH 文件区重新打开、内置文本编辑与有界回退继续保留。文本编辑目前主要针对 SSH UTF-8 文本，不能宣称 CAgent/手机文件编辑和全部语言 IDE 功能已对齐。

## 升级与兼容

1. CShell 保留原服务器列表、设备身份、加密凭据、模型账号、会话及授权数据。安装前保存正在编辑的内容；退出/重启会中断运行任务，恢复时先核对未知结果。
2. CAgent 建议与 CShell 一并更新到本次构建，尤其是远控输入就绪、画质及共享流相关路径。仅更新控制端不能替换远端原生程序。安装成功后核对实际后台版本，避免旧后台继续提供服务。
3. 保留旧 CAgent 数据目录、配对身份、协议 ID 与 CLI 别名；不因更名或升级重置明确关闭的权限。安装应用能力包与授权、系统依赖安装分别处理。
4. 旧 OpenCode 单 Key 引用仍绑定 `default` 账号；已有基座继续兼容。需要账号级模型菜单时，在扩展中接入对应账号即可。删除账号后关联调用失败，不自动切到其他 Key。
5. 视图保存的是来源引用和布局，不能保证恢复普通前台程序；跨重启观察持续服务应使用明确的进程管理方案。未保存的临时连接须先保存到服务器列表。
6. Windows CAgent 更新不自动安装系统桌面服务、虚拟显示驱动，不自动提权、重启或放开防火墙。相关安装仍需要明确执行计划和系统权限。

## 尚需实机验收或明确保留的限制

- **锁屏与无显示器**：系统服务、SAS 及虚拟显示计划/安装/拓扑回滚已有代码与专项验证，但真实锁屏密码输入、UAC、多会话、驱动实际加载、纯无头、重启和 GPU 重置未完成全面验收。Windows Server 2022 无头兼容性仍属实验候选；不宣称普遍可用。
- **远控体验**：公网长视频、网络恶化/恢复、共享多窗口高负载、持续键鼠跟手仍需多设备实测。历史本机帧率和回环结果不能外推所有公网机器。
- **视图数量**：当前桌面会话层最多 4 个订阅，布局每屏最多 12 个区域；终端区域不使用桌面订阅名额。
- **多显示器与平台**：多个实体显示器、多台远端 CAgent 同屏、Android/macOS 用户设备验收仍待完成。历史 0.6.39 平台构建成功不等于本次 0.7.0 已构建或发布；macOS/Linux 受控端原生采集及原生 CAgent 窗口也不能视作 Windows 等价实现。
- **线上服务**：本轮已取得用户账号官方用量响应用于字段修正，未用该 Key 逐个完成线上模型推理验证；设备授权流程、各套餐/限流/模型工具调用仍存在真实账号验收边界。Tavily 真实多账号扣费与并发额度也不能由夹具证明。
- **微信**：仅固定版本适配；真实跨机持续事件收发、全部历史分片、长时间稳定性及大文件/各类型附件仍需验收。微信更新可能使工具包不可用，应明确失败而非继续使用旧偏移。
- **分发信任**：代码签名、Windows 安全软件分类复核按实际发行材料报告；不宣称免误报。不通过排除防护、换名隐藏或绕过系统驱动签名解决兼容问题。
