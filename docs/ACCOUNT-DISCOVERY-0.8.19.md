# 同账号设备自动发现（0.8.19）

我的账号 → 同账号设备 → 自动发现设备。开关随账号加密云同步，独立于外观方案，不会开启手机录屏、受控服务或系统权限。

启用后每 15 秒检查已注册账号设备；只有设备证书与已解密的连接凭据一致才创建可连接的记录。未同步到凭据时显示等待计数。首次新记录放入“同账号设备”，已有名称、分组、收藏、顺序不被发现刷新重写。设备离线保留，查询失败显示状态未知。关闭发现不删除已有连接。

## 兼容和部署顺序

设置位于 store.accountPreferences.autoDiscoverDevices，可选，没有给旧数据默认注入 false。明确开启或关闭才使密文 schema 提升到 4。旧本机设置仅在本账号尚无云开关时迁移，云端已有 true/false 优先。注册初始快照不包含访客账号设置。

服务端须先部署 schema 4 读写门禁，再部署客户端。旧账号 schema 1–3 仍可由旧客户端读取；实际写入新设置后，0.8.18 等读能力不含 4 的客户端收到 426 升级说明，不能读取后丢字段写回。CAgent 和 Android 声明读 4，保留未消费的账号设置；无新字段时仍用原写 schema。

验证：真实 Store 跨目录导出/导入与重启、明确 false 保留、外观修改不改变开关；服务端 schema 4 拒绝 1/2/3 旧读写且密文不变；CAgent 登录/退出隔离及加密云往返保留此字段。Android 真实登记/反向中继由对应仪器与实机验证，不能以这些桌面测试代替。
