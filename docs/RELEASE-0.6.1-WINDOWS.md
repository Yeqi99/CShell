# CShell 0.6.1 Windows 开发预览

本次提供 Windows x64 主程序和独立微信实验工具包。macOS、Linux、Android 与独立 Agent 的既有 0.6.0 下载继续保留，本次没有为这些平台发布新版二进制。

## 更新内容

- 微信扩展提供本机进程绑定、联系人候选、文本发送和限时接收、有限本地历史分页、读取与修改好友备注。
- 发送授权填写 `*` 允许所有有效收件人；发送黑名单优先拦截。留空禁止发送。旧配置保持原授权范围，修改后点击保存生效。
- 微信读取、发送、修改备注具有独立的智能体权限；接收、历史和备注范围不会因发送 `*` 扩大。
- 包含此前本机验证的智能体侧栏调宽、运行环境上下文、可见/静默执行、权限批量选择，以及剪贴板 SSH 连接识别和单次导入提示。
- 包含 API/MCP 服务与能力发现更新；长期负载、受控撤权及部分真实桌面响应验收仍未完成，不宣称完整验收或性能保证。

## 安装

1. 保存任务并正常退出 CShell，运行 `CShell-0.6.1-win-x64.exe`。
2. 如需微信功能，下载并解压微信实验工具包。准备 Windows x64 Python 3.12，在解压目录执行 `./install.ps1 -Python "C:/path/to/python.exe"`。安装器校验包内摘要，使用随附 wheels 离线安装依赖。
3. 在 CShell 插件市场启用“微信（实验）”，选择微信进程，配置授权并保存，再在智能体访问权限中授权所需微信能力。
4. 核对 `SHA256SUMS.txt`。主程序没有商业代码签名。

## 微信适配范围与限制

仅适配 Windows Weixin 4.1.15.50 的精确模块摘要，不保证任意同版本安装文件均兼容，更不自动支持未来版本。原生实验适配仍可能使微信崩溃。微信重启后须重新绑定，切换账号后须重新核对授权。

历史工具覆盖本地 `message_0.db` 的有界读取和游标分页，其他分片、删除记录和未落盘消息不在完整性保证内。客户端空闲时可能需要打开会话或滚动历史。监听与发送当前串行；发送返回不等于送达，未知结果不能换幂等键重试。

好友接受只保留独立本机维护入口；删除好友、拒绝请求、置顶、媒体收发等未作为已验证智能体能力提供。发布不改变这些限制。

工具包不含微信程序、账号配置、联系人、消息、验证票据或测试记录。源码为 MIT；第三方依赖遵守各自许可证，详见随附声明。适配维护步骤见 `docs/WECHAT-ADAPTER.md`。
