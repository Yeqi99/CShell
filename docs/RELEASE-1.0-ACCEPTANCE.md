# 1.0 收口验收（2026-11-03）

当前线上基线为 0.8.21。本文是待办与验收门槛，不代表功能已交付。

用户已确认：先实现可配置额度、扩容和成本台账，保留现有权益，不直接给存量用户施加新限额。

## 发布门槛

- 同步：跨 CShell / CAgent / Android 的模型、插件、偏好、权限和连接覆盖审计；并发冲突、断网重试、凭据重加密与恢复测试；存储容量及扩容持久化。
- 中继：设备身份、会员及租借权限服务端复核；重连与撤销；按账号、UTC 月、方向记录真实流量；容量预留和硬限额在并发下不超卖。
- MCP 长连接：会员远程入口、可撤销客户端身份、会话恢复和心跳；禁止恢复时重放未知执行；完整工具与权限节点对照表。不得只把本机 MCP 端口暴露公网。
- 成本：存储占用与网络流量分开；MCP 经中继传输只归属一个业务类别；入口/出口分别记录，成本费率与用户额度独立。扩容有到期、审计和幂等处理；默认不降低存量权益。
- 安卓文件：真实授权目录、上传下载、取消恢复、拒绝权限反馈；不能绕过系统存储限制。
- 跨机器文件：直连、授权中继、本机转发按真实能力选择；目标身份校验、摘要核验、进度速率、覆盖确认；不因快路径失败绕过权限。
- UI：CShell / CAgent / Android 窄屏、缩放、长文案、键盘、断连与空态；设置、权限树、标签、文件、市场、统计统一回归。
- WSL：真实下载进度、停滞超时、国内镜像校验、离线导入、普通用户设置及 CShell 识别。
- 发布：开源与 Pro 同步，平台成品验收，官网、admin、文档、香港和 CF 更新清单一致，再升级本机。

## 当前新增实现

- 内部流量台账原型：累计计数重报与乱序不重复累计；账号隔离，单流类别不可切换；重启持久化。尚未连接真实中继/MCP 数据路径，不作为在线计费数据。
- 同步存储扩容后端：新增管理员 POST /v1/admin/storage-grant（id、account、bytes、expiresAt、reason）；沿用管理员认证，不允许用户自行增加额度。扩容编号幂等、到期恢复基础额度、管理员和用户读取一致；超额旧数据可读取和缩减。当前实现总上限 256 MiB，默认额度不变，尚未上线。
- 2026-11-03：云服务 23 项回归通过，CI 改为发现全部 test_*.py，覆盖新台账、扩容、租借、网络与原同步协议。尚需 HTTP 端到端、负载内存、后台 UI 及生产迁移演练。
- 所有其他发布门槛仍需逐项核验，不以历史小版本记录替代。
