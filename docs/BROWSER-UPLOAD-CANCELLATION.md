# 浏览器上传取消回归（下一版候选）

正式发行仍为 0.8.12。此改动只计为一个独立问题，未递增版本或发布。

## 复现与修复

CAgent 浏览器隧道把一个大写入切成 64 KiB 分块。关闭流时，第一个远端写入可能仍未返回。旧实现等它完成后继续调用 browser.write，甚至以成功回调结束已取消的上传。

回归使用实际 Node Duplex 和可控的远端调用，第一块挂起后 destroy，再释放确认。旧实现实际发送序号 [0, 1, 2]，测试失败；修复后只有 [0]，只关闭一次，写入回调报告取消。每个分块发出前与确认返回后均核对流状态，已关闭时不发送后续分块。已经发出的第一块不能撤销，不声称取消能回滚远端内容。正在读取的响应在关闭后丢弃，不恢复旧流。

正常 150000 字节写入继续按 [0, 1, 2] 顺序发送，合并内容完全一致；原有真实本地 TCP 回声、归属校验、写入顺序和 SOCKS 不直连回退测试保留。
