# 取消退出后保留自动更新

## 场景与原因

用户尝试退出，但因当前连接、传输或智能体任务选择取消。Electron 已先发出 `before-quit`，原更新器在此时清除了首次检查和周期检查定时器。应用继续运行，自动更新却不再检查，直到下次启动。

## 修复

开源与 Pro 更新器均在真正的 `quit` 事件清理定时器。取消退出保留原有自动更新偏好和计划；取消安装仍移除待启动的安装器回调，不关闭真实会话、不提前执行安装。

## 2026-10-27 验证

- 修改测试后，旧实现失败：取消退出后定时器数量实际为 0，预期为 2。
- `scripts/update-lifecycle-smoke.ts` 打包真实更新器，以隔离的 Electron 事件、网络响应及虚拟定时器运行；原生文件下载和 SHA256 校验路径仍实际执行。
- 开源不带参数、Pro 带 `--pro` 均通过：取消退出后首次自动检查并下载到 ready；取消安装后不启动安装器，周期计划保留；确认退出只启动一次安装器并清理计划。
- 开源更新目录测试 2 项、Pro 测试 3 项通过；两版 TypeScript 检查通过。
- 安装器由替身记录调用，没有在测试中安装真实程序。尚需未来候选包的窗口与退出确认实测，不把事件夹具当作完整桌面验收。
