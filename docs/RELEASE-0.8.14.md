# CShell 0.8.14：退出恢复与配置可靠性

**状态：0.8.14 已正式发布，GitHub、官网和香港更新渠道均已核验。** 开源与 Pro 同步以下修改，旧标签和附件保持不变。

## 本轮改进

| 场景 | 改进 |
| --- | --- |
| CAgent 后台已经结束，窗口仍提示退出失败 | 确认所持有的后台进程已结束后清理并退出；后台存活或状态不明时仍保留错误。 |
| 连续切换自动更新，或磁盘保存失败 | 按顺序保存；持久化成功后才改变运行状态，失败保留原设置，后续修改可继续。 |
| 教师同时下发代理和课程环境变量 | 按接收顺序基于最后成功保存的配置合并，不再互相覆盖；保留加密存储及新进程生效范围。 |
| 扩展取消后文件或目录仍忙 | 等待自己启动的子进程实际关闭，而非只等待终止工具退出；超时明确报错。 |
| 托管代码启动较慢，执行期限额外延长 | 进程启动与执行共用五秒预算，启动已超期不再派发代码，预取消任务不创建进程。 |

详细边界：[窗口退出](CAGENT-EXIT-RECOVERY.md)、[更新设置](CAGENT-UPDATE-SETTINGS.md)、[机房环境](CLASSROOM-ENVIRONMENT-SAVE.md)、[扩展关闭](PROCESS-EXTENSION-CLOSE.md)、[托管期限](HOSTING-STARTUP-DEADLINE.md)。
