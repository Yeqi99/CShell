# 0.8.14 待验收：退出恢复与配置保存

本页记录下一版候选范围，不代表已经构建或发布。正式渠道目前仍为 0.8.13，本机最近确认是 0.8.12；不移动已有标签。

## 三项独立改进

1. **CAgent 后台结束后仍可退出窗口。** 仅在确认窗口持有的后台进程已经结束时清理窗口；仍存活或状态不明的后台继续报告失败。详见 [退出恢复](CAGENT-EXIT-RECOVERY.md)。
2. **自动更新设置保存可靠。** 连续切换按顺序持久化，保存失败保留原运行状态，后续保存可以继续。详见 [更新设置](CAGENT-UPDATE-SETTINGS.md)。
3. **机房环境变量下发不再互相覆盖。** 同时修改代理和课程环境时，从最后成功保存的状态合并，继续保留变量限制、加密存储与新进程生效范围。详见 [环境保存](CLASSROOM-ENVIRONMENT-SAVE.md)。

## 当前验证

两版完整测试正在执行，日志为各自工作树 .local/test-0814-full.log。首次并行运行已记录 HTTP 托管超时用例失败，Pro 另记录应用管理和 WSL 用例失败；最终错误与退出状态尚未汇总，不能认定完整回归通过。须保留失败证据，待运行结束后定位，不能用重跑绿灯直接宣称根因解决。
