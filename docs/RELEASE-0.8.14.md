# 0.8.14 待验收：退出恢复与配置保存

本页记录下一版候选范围，不代表已经构建或发布。正式渠道目前仍为 0.8.13，本机最近确认是 0.8.12；不移动已有标签。

## 三项独立改进

1. **CAgent 后台结束后仍可退出窗口。** 仅在确认窗口持有的后台进程已经结束时清理窗口；仍存活或状态不明的后台继续报告失败。详见 [退出恢复](CAGENT-EXIT-RECOVERY.md)。
2. **自动更新设置保存可靠。** 连续切换按顺序持久化，保存失败保留原运行状态，后续保存可以继续。详见 [更新设置](CAGENT-UPDATE-SETTINGS.md)。
3. **机房环境变量下发不再互相覆盖。** 同时修改代理和课程环境时，从最后成功保存的状态合并，继续保留变量限制、加密存储与新进程生效范围。详见 [环境保存](CLASSROOM-ENVIRONMENT-SAVE.md)。

## 当前验证

三项均有修复前失败、修复后通过的针对性回归。两版原生窗口退出夹具重新编译通过，TypeScript 检查通过；环境与代理六项回归在两版通过。

两版完整测试已结束，日志为各自工作树 .local/test-0814-full.log。开源 564 项：558 通过、3 失败、3 跳过；Pro 609 项：601 通过、5 失败、3 跳过。开源失败为托管停止、托管执行时限、扩展取消后目录仍忙；Pro 失败为托管执行时限、私有文件权限设置启动超时、真实 WSL 调用、两项扩展执行超时。两轮均约 587 秒并以非零状态退出，不能认定完整回归通过。

现保留首次失败证据，以单套、文件串行方式复查失败模块，日志 .local/test-0814-failures-isolated.log。源码发现扩展终止等待的是 taskkill 结束而非实际子进程 close，仍需独立复现与修复验证；并行争用只是其余超时的可能因素，未作为已证实根因。不能通过放宽时限或只保留重跑绿灯关闭问题。
