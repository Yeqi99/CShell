# Windows CAgent 微信掌控

0.6.32 将现有微信后端接入 Windows x64 CAgent 的可选能力包 `cagent.wechat`。CAgent 携带独立 Python 运行环境与固定版本依赖，不使用控制端 CShell 的工具目录，不要求目标机安装完整 CShell。运行环境不包含用户账号、绑定、消息或授权。

## 使用

在目标 CAgent 的应用市场安装“微信掌控”，进入“微信账号与授权”，选择支持的微信进程，保存启用状态和所需范围。工具权限与微信账号范围分别生效；旧配置不自动导入。微信进程或版本变化后重新核验和绑定。

CShell 连接该机器后，在该机器的应用市场中使用相同配置入口。机器工作区中的智能体使用 CAgent 的模型配置与工具注册表；CShell 主智能体绑定该 CAgent 连接后，可发现 `remote_wechat_*` 工具，使用 CShell 的模型调用目标机器。主智能体还需要对应微信应用权限和该机器的 Agent 管理权限。

本机 `wechat_*` 与远端 `remote_wechat_*` 名称明确区分。远端工具仅在目标注册表实际提供时出现；不因远端失败而回退控制端微信。调用使用现有已配对设备的认证、证书核对和管理 RPC，目标端再验证具体工具参数、能力包权限及微信范围。CShell 不接受远端元数据降低写操作审核要求。

## 当前工具范围

复用正式微信后端提供的状态、通讯录、最近会话、历史、私聊和群聊文本收发、消息订阅与游标读取、备注读写、朋友圈缓存/互动通知读取、纯文字朋友圈发布。维护 CLI 中未作为正式工具交付的操作不因此自动开放。

当前仅支持已核验的 Windows Weixin 4.1.15.50 精确 DLL 摘要；不宣称通用版本兼容。历史仍限已实现的本地分片，朋友圈读取仍是本地缓存。未增加朋友圈点赞、评论、图片视频发布或自动升级适配。

订阅按控制端身份归属，其他控制端不能读取或停止不属于自己的订阅；账号配置管理者可执行停止全部监听。发送等幂等键按控制端身份划分，未知结果不盲目重试。停用、卸载、目标撤权和退出会停止监听。

## 远端事件规则接入（2026-10-19）

CShell 事件订阅现在为已连接且有已授权智能体会话的 CAgent 提供独立的“微信 · 机器名称”来源。先让普通智能体会话绑定该机器，并授权微信读取及机器管理；事件订阅页可选择该机器显式开启有期限的监听，随后新建规则、选择此来源和同一机器上的处理会话。已有 `remote_wechat_subscribe` 工具创建的所属监听也会被发现。规则创建、修改、停用继续使用智能体的事件规则工具；保存规则本身不会偷偷启动微信监听。

控制端每秒发起有界游标读取（每机器单请求，最多 16 台独立机器，单轮网络预算 5 秒），不依赖用户打开微信页面。每页最多 100 条，消息进入持久事件调度器后才保存加密游标。设备身份、微信账号、会话和消息 ID 分开约束，重复页由调度器去重。断连、身份变化、订阅停止或撤权使来源失效，已排队任务重新检查授权；重连到新会话须重新绑定处理智能体。缺口明确显示，不用历史推测补齐丢失事件。消息只作为不可信任务数据传入，不能授权自身触发的新操作。

CShell 退出停止本地读取；远端原生监听遵循自身租约及目标权限，不宣称应用重启可恢复原生探针。游标写入失败会停止读取，重启后从已落盘游标恢复；事件任务仍遵循原有次数、冷却和 token 预算。

验证：`tests/remote-wechat-events.test.ts` 覆盖身份隔离、持久游标续读、断连与撤权、处理失败不确认游标、缺口以及显式监听；连同本地事件调度与消息过滤共 13 项通过，TypeScript 检查通过。`scripts/ai-events-ui-smoke.ts` 的真实浏览器隔离夹具验证了远端机器选择、监听参数和既有规则编辑交互。未向真实微信发送测试消息；跨机真实账号持续接收仍需实机验收。

## 构建与验证

Windows 构建使用 `CAGENT_WECHAT_PYTHON` 指定 Python 3.12 x64 构建环境，依赖固定为 frida 17.24.0、pefile 2024.8.26、zstandard 0.23.0。构建脚本只复制解释器、标准库、依赖分发文件及仓库内适配器源码，并生成逐文件摘要；执行使用独立搜索路径和禁止字节码写入模式。各依赖保留自身许可证，整体包含第三方声明。

验证证据：`test-results/wechat-cagent-tests-0.6.32.log`、`test-results/wechat-cagent-e2e-0.6.32.json`、`test-results/cagent-wechat-settings-0.6.32.png`。端到端测试通过隔离 CAgent 和独立控制端身份建立 TLS 配对，执行配置、通讯录只读调用、发送拒绝与撤权；不发送真实消息。该测试不替代另一台物理 Windows 机器的微信安装和收发验收，也不证明长期无崩溃。
