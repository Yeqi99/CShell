# 0.8.11：统一桌面与机房部署

本页记录待发布内容。正式附件、源码提交及渠道验收在发布完成后补充；本机构建和机房预览包不代表全平台已经发布。

## 桌面

工作台可视化与机器连接桌面使用同一套窗口和任务栏。单击选择、Ctrl 多选、空白处拖动框选，双击或 Enter 打开；标题和应用名称不再被误选为文字。窗口支持拖动、缩放、最大化及最小化恢复，保留应用草稿。图标随桌面高度自动换列，空间不足可滚动访问。

工作台提供连接与视图、命令台、能力浏览器、扩展、智能体、偏好设置和桌面外观入口。工作台没有伪造的远端连接状态；外观单独保存，不改变其他机器的桌面。

## 机房与内网

- 教师与学生安装脚本支持预置扩展；现有身份、配置和明确权限保留。教师端和学生端安装包用途不同，安装不会自动覆盖现有配置。
- 机房扩展提供局域网发现、共享屏幕和集中下发入口。网络隔离、组播受限或防火墙阻断时不能保证自动发现；提供只读网络诊断工具。
- 发现启动失败后会有界重试，避免插网线或网络恢复后一直没有发现结果。
- 屏幕选择优先使用稳定显示器标识；失效时提示重新选择，不悄悄共享另一块屏幕。默认共享名称包含机器名，避免多台设备全部显示“我的屏幕”。
- 教学环境通过独立脚本下发。`dl` 环境及桌面快捷方式不作为固定客户端功能；安装脚本不会替换既有 base 环境。依赖下载、磁盘空间和完整环境安装需在目标学生机验收。

## 验证与限制

桌面两端的独立 Electron 交互回归已覆盖框选、无文字误选、双击/Enter、窗口移动与最大化、草稿恢复，以及宽窄和低高度窗口。模拟内容验证不代表远程服务器或学校网络已经实测通过。

Windows 安装包未签名；macOS 未公证。发布只列出实际构建和核验的附件。系统必须的安装确认仍保留，不宣称所有设备已静默更新。
