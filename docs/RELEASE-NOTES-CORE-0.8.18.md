# CShell 0.8.18

## 工作区与操作体验

- 双击机器建立独立标签，RDP 标签使用独立原生会话；切换、重连和关闭不再影响同机器的其他标签。
- 修复临时连接重连、终端焦点竞争与搜索体验，保留真实 PTY、滚动历史和未提交草稿；改进独立小窗的 DPI 尺寸处理。
- 设置、权限、扩展、统计与历史采用统一分区；常见权限、未启用等状态用说明提示，真实错误集中提供诊断。
- 提供紧凑的 Ping 全部及周期设置，测量本机到指定服务器，不把代理响应当作目标延迟。

## 智能体与 CAgent

- 智能体的功能菜单不覆盖当前对话，空闲时可在同一对话换模型；目标支持秒级间隔、记忆更新和通用事件订阅。
- 本机、SSH、CAgent 的身份网络规则统一管理，拒绝循环和失败后的静默直连；修复宿主终端出口环境继承，WSL 不混用宿主代理。
- 新建 CAgent 连接可按需展开平台下载区，严格使用普通版渠道和核验目录；普通版与 Pro 保持独立身份、配置和更新渠道。
- Windows 远控剪贴板文本、PNG、小文件经过双机往返验证；修复文件暂存生命周期和消息处理。
- OpenCode 目录与模型状态持续刷新，官方运行时请求在退出时正确取消并等待清理。
- CAgent 原生窗口可在本机后台更新后恢复读取连接；未知结果的修改操作不自动重放，认证拒绝不触发重连循环。

## 验证与限制

Windows 安装成品、真实 SSH/SFTP、ConPTY、RDP 多标签和 MCP 握手已验证。macOS/Linux x64、arm64 原生构建和包检查、macOS 原位 DMG 更新通过，下载文件提供 SHA-256 摘要。

Android 使用原发行证书签名，API29/35 的原生控件、WebView 输入与连续删除、无焦点拒绝、视频、旋转及重放拒绝测试通过。共享远控实现已通过 Pro 在 Android 16 实机的视频、点击、文字、连续清空、返回和同身份重连验证；不冒充开源版 APK 的独立实机安装验收。运营商短信和电话仍受系统授权与 SIM 条件限制。

微信为独立能力包：真实消息原生捕获和诊断事件触发任务已验证；最终冻结包自动重投该事件返回 204 且未重复执行，独立合成新事件验证触发。两版包通过冷启动和完整安装目录核验，4.2 的包测试不替代对应微信版本全部接口实机验收。

部分 OpenCode 免费模型仍受上游地区或额度限制；不会自动使用付费模型。Windows 安装器未做 Authenticode 签名，macOS 签名、公证及不同物理设备限制仍保留。远控遵守系统登录与显示会话条件。

账号云同步、设备借用与会员中继属于 Pro，不包含在普通版中。
