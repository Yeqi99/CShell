# CShell 0.6.38

本地收口更新，尚未声明 GitHub 发布。

- OpenCode 扩展支持多个密钥、保存后可用性检测、模型选择与官方设备授权流程。模型目录不代替身份验证；实际用户账号/套餐须使用自己的凭据验证，不宣称现金余额查询。
- 远端 CAgent 微信事件成为 CShell 订阅规则来源，按设备、账号和订阅保存游标。断线、权限撤销和游标持久化失败均停止对应来源。
- 智能体可在人工对话中创建和管理订阅；事件触发运行仅可查询规则，不能通过收到的消息自行创建、删除或修改订阅。
- 包含 Tavily 多密钥网络搜索扩展及 SSH 文件区重新打开入口。
