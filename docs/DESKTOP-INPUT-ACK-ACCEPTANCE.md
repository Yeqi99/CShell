# 桌面工具输入确认验收

2026-10-30：修复 desktop_interact 返回 completed 后鼠标仍未移动的问题。

## 根因与行为

旧路径只把输入写进加密控制流及原生进程 stdin，即返回完成并关闭临时桌面视图。排队不代表 Windows 已执行输入；关闭可能先结束采集进程。

工具调用现在逐个等待原生 input-status 的 generation/sequence 匹配确认，经认证加密控制通道返回后才报告完成和关闭。输入错误、断连、超时均返回失败，不重放未知结果。原生等待 5 秒、传输等待 7 秒，待确认输入最多 32 项；高频人工键鼠路径保持不变。旧受控端未声明 inputAcknowledgment 时明确要求更新，不伪称执行完成。

## 验证

- 真实 TCP 加密 loopback：远端确认前 Promise 不完成，确认成功、拒绝及中途关闭正确结算。
- 原生包装层：仅匹配 generation/sequence 结算，输入错误与进程退出 reject，监听器清理。
- 自动化：确认期间不释放/关闭私有视图；拒绝后不发送后续点击事件，不重放。
- 45 项桌面会话、客户端、服务、视图和自动化相关测试通过；TypeScript 检查通过。
- 远端 Windows console 实机键鼠验收由本轮升级后的新 CAgent 与新 CShell 共同完成，不能用排队或旧包结果替代。
