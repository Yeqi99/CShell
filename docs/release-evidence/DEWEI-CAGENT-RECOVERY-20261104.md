# 德威云账号中继与桌面恢复验收（2026-11-04）

## 根因与永久修复

- 目标旧后台为开源 CAgent 0.8.21，缺少账号注册实现，导致旧账号设备心跳过期，会员 lease 返回 409。Pro 构建未给 `__CSHELL_PRO__` 注入 edition，更新下载根错误落到开源渠道。
- `scripts/agent-build.mjs` 现在注入构建 edition 并写入 build-info；测试分别构建两个 edition 的实际下载地址。
- 旧原生窗口可能在升级后拉起旧目录后台。`installed-launcher.ts` 按安装器维护的 Open CAgent.vbs 指针检查已选安装目录，旧窗口启动 run/app/app-host/restart-app-host 被拒绝；开发目录不受影响。
- 更新系统桌面 broker 后出现 CLIPBOARD_OWNER_INIT：系统 worker 打开桌面的访问权缺少 DESKTOP_CREATEWINDOW，且剪贴板实例在采集初始化时立即创建，失败导致整个采集退出。
- 系统桌面句柄补齐消息窗所需权限；剪贴板改为授权操作时创建，创建失败仍向调用方返回真实错误，下次可重试；采集和键鼠不依赖剪贴板可用性。

目标使用 `0.8.21-1d67f7375464cd20` 安装目录。既有系统桌面服务 owner SID 已核对一致，再升级对应组件。系统 worker 修复构建 SHA256：

`77b22e1d86a157c588cc3c19b6a1da57f8b13c6b4bc087e2f691ee207d2e40ad`
