# Weixin Toolkit 0.1.2

CAgent 微信能力包二进制，分别匹配 Windows 微信 4.1.15.56 与 4.2.0.12。源码保留在私有仓库；本发行仅包含已核验的能力包、清单和运行工具归档。

- 安装包包含私有 Python 运行时及 SSL 公共信任资源，不改系统 Python、PATH 或软件源。
- 修复后台进程信号退出识别与清理结果；未知状态不会伪称成功。
- 消息回调接入 CAgent 通用事件订阅，可按事件条件触发任务；安装不替代权限授权。
- 包版本与微信版本严格匹配，不匹配或未完成检测时不标记可用。

验证范围：真实手机消息已由本机原生接口捕获；诊断投递该事件完成一个任务。最终冻结包自动重投同一事件返回 204 且未重复执行，独立合成新事件各触发一个任务。两版完整 93 文件包通过冷启动与安装目录验证；这不代表每个版本所有微信内部接口均已实机验证，也不把分段验收表述成首次新消息自动全链已验证。

请通过 CAgent 应用市场选择与当前微信版本匹配的能力包。敏感数据、授权与私有实现源码不包含在本发行附件中。
