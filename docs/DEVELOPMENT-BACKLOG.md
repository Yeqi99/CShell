2. **CAgent 独立应用**：已接入能力包市场、系统应用工具与独立授权；微信/Clash 等各个适配器、完整事件订阅生态、跨平台发行和自启动仍须逐项完成。当前不宣称 macOS/Linux 原生窗口或各平台安装包已发布。
3. **微信好友管理**：主动加好友、拒绝请求、删除好友、置顶/取消置顶、标签与朋友权限等仍需逐项完成并核验。不能把已经通过的历史记录当作仍可接受的待处理请求。
4. **微信历史与恢复**：当前历史读取不保证覆盖所有数据库分片、已删除或服务器历史；账号切换、客户端重启、版本升级仍需重新核对绑定，不保证无缝无人监管恢复。
5. **朋友圈交互**：点赞、取消点赞、评论、回复评论、媒体上传发布和服务端刷新尚未完整实现。通知只读解析已有源码，需随工具包验证发行；用户要求的逐条回复尚未完成。
6. **API/MCP 最终验收**：长期负载/泄漏、专用测试客户端受控撤权清理、真实桌面终端响应仍未完成。保留既有证据，不重复压力采样、不动既有客户端授权。

## 事件触发交付边界

规则配置不授予权限。事件只使用已有授权会话；每次执行前复核监听、账号、范围和会话绑定，外部消息作为不可信数据传入。默认忽略自己的消息，限制频率、模型调用和保守请求预算，失败或中断不盲目重发。独立旧自动回复程序与 CShell 微信监听不能同时占用单一接收探针；不自动迁移或创建真实回复规则。

事件触发当前首次接入微信，其他插件需要提供真实事件来源和授权适配后才能选择，不显示占位来源。
