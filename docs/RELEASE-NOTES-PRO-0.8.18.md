# CShell Pro 0.8.18

发布说明草稿；当前候选尚未公开发布。

## 配置随账号恢复

- CShell 与 CAgent 共享模型基座及 OpenCode 加密凭据；外观、适用设置、插件选择与可移植配置按账号恢复。
- 外部能力包恢复会核验来源、版本和摘要；不匹配的包显示待处理，不自动执行未知安装代码。设备监听、MCP 令牌及本机授权保持各设备独立。
- 新增按邮箱、时效或有限次分享码借用机器，接收方只能按授权连接，不能查看机器密码。
- 统一“来源机器 → 出口机器”网络规则，支持本机、SSH 和 CAgent，拒绝循环；出口失效不静默直连。

## 工作区、智能体和远控

- 双击机器新建独立标签，RDP 会话的切换、重连和关闭相互独立；修复终端焦点竞争、搜索和滚动历史保持。
- 重新整理设置、权限、扩展及统计页面；常见权限和会员状态使用说明提示，真实错误保留统一诊断入口。
- 智能体菜单保留当前对话和草稿，空闲时可更换模型；目标支持秒级检查和可更新记忆。CAgent 提供通用事件订阅及自动化能力。
- 修复终端网络出口继承、CAgent 连接下载入口和渠道隔离，以及官方 OpenCode 请求的退出清理。
- Windows 远控文本、PNG 和小文件剪贴板往返通过双机实测；CAgent 原生终端、包内 TLS 和授权边界经过验证。

## 验证范围

Windows 成品、真实 SSH/SFTP、ConPTY、RDP 多标签、云恢复、公网中继和跨机器出口已验证。macOS/Linux 的 x64、arm64 原生构建及包检查通过，macOS 原位 DMG 更新检查通过；下载文件均有 SHA-256 核验。

Android 使用原发行证书签名，API29/35 的真实控件输入、视频和旋转仪器测试通过。物理 Android 手机的最终触控仍待验收；电话、短信还受系统授权和 SIM 条件限制，不能视为均已实测。

微信为独立能力包，实际消息回调和部分版本功能仍有待验收，不宣称全部可用。OpenCode 部分免费模型仍可能被上游地区或额度限制拒绝，不自动替换成付费模型。

Windows 安装器未做 Authenticode 签名；macOS 签名、公证及各类物理设备验证限制仍保留。远控遵守系统登录、锁屏与显示会话条件。
