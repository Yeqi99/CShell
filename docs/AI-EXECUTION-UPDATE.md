# 智能体工作区与执行更新（2026-10-15）

- 智能体侧栏支持拖动与方向键调宽，保存宽度；窗口较小时限制占比。
- 智能体设置新增“执行过程”，可见模式在绑定机器的工作区展示真实命令与流式返回，静默模式隐藏过程与工具展开记录，保留回复和必要授权。命令仍使用独立执行通道，不向用户正在操作的 Shell 注入文本。
- 每次模型调用刷新 CShell 主机平台、绑定会话/机器、连接状态、当前基座和实际可用工具。区分本机应用配置与远端文件系统，切换 UI 标签不改变任务目标。
- 对短暂的纯进度宣告最多续接一次，仍未调用工具时显示错误；空响应、截断、过滤与超时明确显示未完成。不自动重放副作用。此策略不保证任意基座都能正确调用工具，也不根据截图断言某次中断的确切原因。
- 新增 `ai.providers.manage` 独立应用权限，默认关闭，在“智能体设置 → 访问权限 → CShell 本身”启用。提供 `list_ai_providers`、`save_ai_provider`、`test_ai_provider`。保存始终确认具体地址、模型与认证来源；不切换当前会话、不更改执行权限。
- 基座认证支持不使用密钥、同来源基座复用，以及从当前已授权机器的小型纯文本/JSON 文件由后端直接导入。读取仍需文件权限，密钥不进入模型工具结果或记录。其他格式使用设置中的安全输入。API 地址继续要求 HTTPS 或本机回环 HTTP。

验证：`ai.test.ts`、`ai-response.test.ts`、`ai-environment.test.ts` 共 10 项通过；TypeScript 与生产构建通过。隔离 Electron 工作区测试通过拖动、键盘调宽、重载持久化、按会话显示和静默抑制。界面流事件为测试夹具，真实后端流转由服务测试覆盖，不冒充用户基座/远端端到端验证。

旧 API/MCP 长期负载、撤权与真实终端响应验收仍未完成。本次未运行真实负载、未改变既有客户端授权、未发布 GitHub。安装前需正常退出仍在运行的用户 CShell，保留会话期间不强制替换。
