# CShell 0.6.2 Windows 修复预览

修复微信扩展在接收、历史和备注授权中填写 `*` 后无法保存的问题。

- 发送、接收、历史和备注授权都支持 `*`；每个字段独立授权，留空不授权。
- 发送黑名单仍只接受准确内部 ID，优先于发送 `*`。
- 实际工具调用仍须指定准确目标：接收一次指定 1–20 个账号，历史一次指定一个会话，备注一次指定一个好友。`*` 授权不代表自动监听所有消息或执行批量修改。
- 无效设置显示具体字段的中文提示，保存失败保留草稿，不改变已保存授权；旧设置不自动扩大权限。

保存任务并正常退出 CShell 后安装新版。已有微信工具包无需重装；首次安装请下载 [0.6.1 发行页的微信工具包](https://github.com/Yeqi99/CShell/releases/tag/v0.6.1)，按其中说明使用 Windows x64 Python 3.12 安装，再启用微信扩展和对应智能体权限。

本次仅发布 Windows x64，安装包无商业代码签名，请核对随附 SHA256SUMS.txt。微信仍为精确版本 4.1.15.50 的实验适配，存在崩溃风险；历史只覆盖有限本地数据库，不保证完整同步。其他平台继续使用原有发行附件。

验证：4 项微信专项测试、TypeScript 检查、生产构建和隔离桌面配置测试。桌面测试复现四个授权字段填写 `*`、保存和重载，并验证非法输入时的中文提示及草稿保留；未发送消息、读取真实历史或修改真实好友备注。
