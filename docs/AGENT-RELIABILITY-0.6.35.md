# 智能体收口 0.6.35

## 目标与约束

CShell 与 CAgent 均以任务目标、用户约束、执行证据和预算驱动持续执行。不以最近 80 条消息代替上下文管理，不在普通任务第 8／16 次模型调用时直接结束。事件订阅继续使用原有独立预算和历史隔离。原有机器身份、权限与人工停止保持有效。

## 实现

- 上下文超过约 90 KB 时，按完整工具往返压缩；每批携带前次摘要，保留目标、约束、决策、文件、完成项、待办、验证与未知结果。摘要成功保存后才替换模型输入；原始会话仍保留在加密记录中。模型压缩失败不会静默截断。
- `task_checkpoint` 保存结构化任务记忆；CShell 工具调用前持久化待执行项，完成后写结果；CAgent 在每次执行前后持久化事件。重启不重放操作，未返回结果的调用属于未知结果。界面提供检查点／核查后继续入口。
- `task_start`、`task_list`、`task_wait`、`task_stop` 提供当前会话的后台命令管理。独立 ID、最多四个运行任务、分页输出、30 秒有界等待。后台工作仍使用真实目标 Provider 和既有命令权限，不能跳到本机执行。
- 命令期限可显式设置至 24 小时；智能体本轮期限是更短的独立上限。CAgent 本机命令可实时返回输出到任务缓冲，后台缓冲保留最近 128 KB，过期游标返回 `gap`。底层 Provider 的输出截断仍如实保留，不冒充完整日志。
- 大工具结果存为加密日志，模型只收到摘要片段和 `task_log_read` ID；日志读取限定当前任务。事件触发任务不能调用普通任务检查点、日志与后台任务工具，避免跨会话读取。
- 普通任务默认 30 分钟、累计请求／响应 UTF-8 字节 2,000,000、相同工具参数及结果重复五次停止。CShell 基座设置与 Windows CAgent 模型设置可调整。累计字节是保守用量代理，不是供应商账单或精确 token，不能承诺金额封顶。
- 提示明确要求执行、观察、修正、验收；后台命令未退出不能正常结束任务。命令返回成功本身不证明用户目标验收通过。

## 恢复语义与实际限制

用户停止、授权撤销、运行超时会请求取消本轮后台工作。重启不保证子进程已经退出，不使用 PID 重放或接管未知进程；恢复先检查真实机器与历史未知结果。SSH 取消遵循 Provider 的 TERM 语义，不能保证所有后代进程退出。

CAgent 原生窗口继续当前所选任务时带入原目标与记录；“新对话”保持独立。CShell 连续会话保留检查点，CAgent 远端控制页与网页提供“核查并继续”。摘要内容由所选模型生成，原始证据可用于复核，不能保证模型不会遗漏或误判。没有把模型自报“完成”等同自动验收。

长期任务历史和加密日志暂不自动清理，随本机数据目录保留；需关注磁盘空间。本次未验证应用崩溃后远端进程实际存活的所有平台组合，未知结果明确保留给恢复核查。
