# CShell 0.8.20

- CAgent 应用市场适配窗口宽度，统一卡片与状态，刷新保留搜索。
- 补齐内置桌面、窗口操作、权限说明和网络检测菜单的中英文切换，保留用户自定义名称。
- 安卓远控默认完整适配，跟随手机横竖屏比例；改进有界视频队列，减少等待确认时反复丢帧。新增手机文件与应用快捷入口，按实际系统授权提供。
- 全部延迟检测改用紧凑图标，自动检测菜单保持在窗口内。
- 原生桌面入口只依据目标机器的真实检测结果显示，支持手动重新检测。
- CAgent 新配置的自动化默认值与智能体默认行为统一，已有明确关闭的权限保持关闭；权限行说明与焦点轮廓避免重叠。
- 保留系统代理和明确网络出口的行为，指定出口失效不会自动回退直连。
- MCP / CLI 补充连接创建与修改、加密凭据更新、首次 SSH 指纹探测与显式信任；分别授权，保存连接不会自动授予连接权限。
- 可找回当前调用方的会话和任务 ID、输出游标，并查询当前权限；应用重启后的未知操作不会自动重放。
- SSH 命令结果分别返回 stdout、stderr、真实退出码及截断标记，失败退出不再显示为成功。
- 修复普通版 CAgent 使用 Pro 更新目录的问题，并校验附件渠道和版本，避免跨渠道下载。

普通版使用独立更新渠道，不包含 Pro 账号云同步、会员中继或机器分享。保留现有连接、身份与凭据。

Windows 包未签名；macOS 包未签名、未公证。平台构建通过不代表所有实体设备实测。正式可下载附件及更新状态以最终发布验收记录为准。
