# Pro 会员、点数和模型周额度

**点数余额和本周模型额度是两笔账。** 余额用于购买服务，100 点等值 1 元。会员调用模型时消耗本周的模型额度，不逐次扣钱包里的点数。

| 操作 | 点数 | 得到什么 |
| --- | ---: | --- |
| 开通或续期 Pro | 3,990 | 30 天会员；有效期内续费从原到期日顺延 |
| 手动重置本周模型额度 | 588 | 恢复到 100%，不叠加剩余额度，不延长会员有效期 |
| 周一北京时间 00:00 自动刷新 | 0 | 新一周恢复到 100% |

**100% 对应 5 元模型成本。** 未使用时应显示 100%；查询失败不代表额度为零或已用完。会员选模型时可看极低、低、中、较高、高、极高六档提示。按 80% 未缓存输入和 20% 输出估算，每百万 token 成本分界为 0.3、1、3、8、20 元，分界值归入较低一档。比如一次调用实际计入成本 0.05 元，就消耗整周额度的 1%。同一模型发短消息和生成长文的成本可能不同。

## 管理号池

在管理员后台「会员模型号池」中分别管理供应商账号、模型和预算。只为获准对外提供服务的供应商账号开放共享；个人订阅和商用按量接口的密钥、地址、计量规则不能混用。账号有余额也不等于每种模型都可调用。

按量模型以请求返回的 usage 和适用单价结算：未命中缓存的输入、命中缓存的输入、输出分别计价。同一批缓存输入不能重复算作普通输入。请求前预留，结算后释放多余的预留；结果不明的请求需要核对。供应商的余额、套餐用量和会员已消耗的周额度应分别查看。供应商调价或新增型号时，应先核对官方型号、价格及适用条件，再开放给会员。

维护部署时保留数据库和加密配置；密钥只交给后端，不写入文档、日志或前端。

### 明杰 AIOPEN

在管理后台「会员模型号池 → 明杰 AIOPEN」添加 API Key，设置周预算，并录入该 Key 可调用的模型和采购价格。点击「查官方额度」可查看该 Key 的剩余和总配额，无限额 Key 单独显示。数值使用供应商原始配额单位，不计入人民币库存。后台定期刷新已启用账号。
