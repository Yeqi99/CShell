# SSH 机器信息分类修复（2026-10-26）

右侧文件与机器信息面板将 CPU、内存、硬盘、GPU、进程、网络分为六个独立分类。默认显示 CPU，型号直接换行显示，不再仅放在悬浮提示里。文件目录与终端会话不随分类切换重置。

GPU 名称支持换行；进程按需获取，保留搜索与刷新间隔。网络当前显示真实 SSH RTT，不将其称为 ICMP 延迟或吞吐量。指标失败清除旧结果，不冒充实时值。无型号的机器明确显示暂不可用。

验证：Core 与 Pro TypeScript 检查、生产构建、真实 SSH fixture + Electron 六分类切换/型号显示/窄窗口测试通过；资源解析测试通过。截图为隔离测试数据，不是用户机器实测。
