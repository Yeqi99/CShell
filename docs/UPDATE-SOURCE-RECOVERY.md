# 更新源故障容错

香港下载源为首选。CShell 桌面与 CAgent 在目录或附件请求遇到超时、连接失败、HTTP 5xx（包括 522）、408 或 429 时，自动读取官方 Yeqi99/CShell GitHub Release，无需打开浏览器。

开源只读取 vX.Y.Z，Pro 与 CAgent 当前发布渠道只读取 pro-vX.Y.Z；不选草稿或预发行。附件沿用同渠道、同版本、同文件名；操作系统与架构仍由原选择器核验。仅允许官方 Release 附件 CDN 的 HTTPS 跳转。404 不尝试其他版本，用户取消不会重试。大小、SHA256 和安装前再次校验保持原规则。

验证：Core 17 项、Pro 18 项更新测试通过，覆盖目录和附件 522、超时、404、取消、恶意跳转、跨渠道选择和损坏包拒绝。两树 TypeScript 检查通过。真实网络目录容错已取得两版 0.8.16 目录（开源 16 个附件，Pro 14 个附件）。本机 Node 直连 GitHub 附件域名遇 TLS ECONNRESET；经系统代理后，真实原生 updateRequest 成功下载两版 SHA256SUMS，且与独立 curl 校验一致。尚未以此通道完整下载大安装包。CAgent 优先读取 HTTPS_PROXY / ALL_PROXY / HTTP_PROXY，Windows 无环境覆盖时读取当前用户系统代理，不修改注册表；代理存在但失败时不回退直连。PAC/WPAD 暂不支持时明确报错。CShell 沿用系统代理。备用源仍需网络可达，不能替代源站修复。

已有旧客户端仅有香港单源，不会因服务端发布新目录而自动获得新代码；应优先恢复源站，或使用已验证安装包升级后获得容错。
