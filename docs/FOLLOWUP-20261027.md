# 2026-10-27 官网与 Android 后续验收

## 已确认

- Core 和 Pro 的 Android API 29、35 原生回归全部通过；参见 ANDROID-GESTURE-QUEUE-FOLLOWUP.md。生产手势队列改动尚未进入正式安装包。
- 官网原移动样式在 700px 以下隐藏版本对比、开发者入口。现改为显式折叠菜单，所有目的地保留；支持 Escape 恢复焦点、点击页内目标后焦点转移、点击外部关闭、无 JavaScript 降级。
- 本地 320/390/1440px 回归通过，人工查看了 1440 全页、390 首屏及展开菜单截图。覆盖四平台及所有架构选择、场景切换、键盘、搜索交接、下载空态、图像解码、无横向溢出、无 JS 错误。
- 旧回归写死 0.8.8，已改为严格对照当前 package.json 版本并验证每个架构链接。该测试修复不单独计入小版本功能数量。
- 官网仅部署 index.html、home.css、showcase.js 三份文件，部署前对照线上摘要，保留远端备份，部署后逐一验证公开 URL 摘要。下载清单、客户端版本、已有 style.css 未提交修改不变。

## 仍需推进

手机导航修复不等于官网整体个性化设计完成。当前首屏依然是标题、平台列表与单幅截图的纵向排列，产品操作过程表达不足；下载、文档、机房入口需要统一的整体设计验收。保留十站调研作为依据，不将 2026-10-24 历史设计验收当成用户最新目标已达成。

客户端正式版仍是 0.8.11。下一版须包含至少三个独立、实际有用的改进，并完成各自验证后统一构建发布。继续保留 Android 真机、取消/拒绝/超时故障注入以及本机 CAgent 运行时切换的未完成项。
