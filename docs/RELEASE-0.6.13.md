# CShell 与 CAgent 0.6.13

## 发行状态

本说明对应 0.6.13 待交付源码。Windows 本机验证与 CI 配置已具备；独立 CAgent 的 macOS/Linux 四种架构仍须在各自运行器完成构建和成品验证，不能将计划附件视为已发布。[GitHub Releases](https://github.com/Yeqi99/CShell/releases) 中实际上传的文件与校验结果是下载依据。

此前已发布的 CShell 0.6.0 macOS、Linux、Android 附件继续保留，其验证记录属于旧版，不代表这些平台已经获得 0.6.13 的全部功能。

## Windows 工作台与独立 CAgent

Windows CShell 安装包内置同版本 CAgent。CAgent（Canp Agent）也可独立安装，不依赖完整 CShell、Electron 或捆绑 Chromium；它既是精简本地智能体，也是 CShell 可授权访问的代理端。旧数据目录、设备身份、加密凭据和旧命令别名保持兼容，更名不授予新权限。

Windows 使用原生 WPF 小窗，以消息和输入区为主，会话、应用市场、设置及权限按需展开。macOS/Linux 包包含本架构运行时与原生 PTY，界面入口使用系统浏览器，**不是 Windows 同款原生小窗**。

独立 Windows ZIP 完整解压后运行 `Install CAgent.cmd`，安装到当前用户目录。安装器校验文件摘要，不申请管理员权限、不自动开放防火墙或远程监听；遇到旧后台仍在运行时提示退出，不强制结束会话。首次使用需要配置模型和权限。ZIP 摘要用于校验完整性，不等同于开发者代码签名。

## 连接与能力

- Windows RDP 连接可保存名称、分组、主机、端口、用户名及可选加密密码，与左侧连接列表共用编辑和双击连接。连接调用系统 mstsc；远端或本机策略可能要求再次认证。
- CAgent 应用市场将能力包安装、版本核验、权限配置和系统应用安装分别处理。安装工具包不等于授权执行，配置不完整或平台不支持时不显示可用。
- 自研远程桌面是独立可选能力包，与系统 RDP 入口分开。Windows 被控端自行采集、编码、传输和处理键鼠；服务启用、观看权限、控制权限独立，默认关闭。
- CShell 桌面观看器支持画质调整、明确网络故障后的有界自动重连。恢复时重新认证并取得新票据，旧代次输入不进入新会话；用户停止、撤权或身份变化会终止恢复。

## 已执行验证与边界

Windows 本机真实 Electron IPC、管理通道中继与断流恢复测试在一次 34.428 秒观察中解码 1677 帧，最后 2.5 秒为 133 帧；解码耗时 P50 1.7 ms、P95 4.6 ms。这是指定本机与测试负载下的观察，不是跨设备性能保证，也不是公网延迟测量。

自有本机测试窗口验证了字母数字输入、鼠标点击，以及连接断开后 Shift 释放（该次记录约 98 ms）。关闭控制权限后新控制连接被拒绝，重新显式授权和新票据后可再次输入。没有将测试输入发送到其他应用。

整网掉线后设备绑定保留、旧输入拒绝、权限失败不重试等另有隔离故障测试。**公网端到端验收尚未完成**；本机结果不能替代公网、长期运行、休眠恢复、UIPI/安全桌面或复杂网络条件的验收。macOS/Linux 被控桌面实现与手机观看器不属于本次已验证能力。
