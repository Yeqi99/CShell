# 机房环境变量并发保存保护

教师端接连下发代理与课程环境变量时，CAgent 原先在请求到达时复制旧值。多个保存同时进行，会让较晚保存的旧副本覆盖前面的变更，即使各请求均报告成功。

现按接收顺序串行合并和保存。每项变更基于最后成功持久化的配置；写入失败不更新运行中配置，也不阻塞后续保存。变量总数限制在合并后检查。沿用加密存储、变量名限制和 Windows 大小写规则，只影响 CAgent 新启动进程，不修改系统环境变量。

## 复现与回归

测试 tests/managed-environment-save.test.ts 同时保存代理、课程环境与删除旧变量。旧实现得到空配置，修复后保留代理和课程环境，重新加载仍一致。另验证保存失败后的恢复，以及并发变更达到 100 项限制时拒绝超限、删除后继续保存。

两版运行上述三项测试与 tests/classroom-proxy.test.ts 三项测试，均通过。代理验证保留地址校验、不携带嵌入凭据、不制造直连回退的约束。测试使用受控存储失败与异步完成，不代表已在真实学生机批量部署。
