# 问题反馈

> 本页描述 1.0 待发布功能；当前正式版仍为 0.8.21。

在设置中打开“反馈问题或建议”，填写操作步骤、期望结果和实际现象即可提交。不需要 GitHub 账号。遇到错误时，也可从错误提示旁的反馈入口打开表单。

联系方式选填。提交前可以查看版本、平台及反馈编号；错误代码由你勾选后附带。不会自动读取或上传连接配置、完整日志、截图、密码或模型密钥。请勿在描述中填写秘密信息，程序也会对常见凭据格式进行过滤。

提交成功后显示反馈编号，便于后续查询。提交失败会保留内容，可重试；同一内容的网络重试不会生成重复记录。反馈不会自动执行修复、改动权限或重启应用。

## 管理员

反馈存储在云服务数据库，读取与处理需要管理员认证，普通客户端不能枚举其他人的反馈。管理员接口和客户端提交接口分离，管理员凭据不随应用分发。

反馈不是自动崩溃上报。程序异常日志仍保留在本机，除非用户主动提交，不会上传。
