# CShell 0.8.19

本次更新改善侧栏网络检测，并对齐共享的 CAgent 能力恢复及 Android 传输实现。

- 全部延迟检测改为紧凑图标，保留悬停说明与键盘入口。右键自动检测菜单在小窗口、窗口底部及缩放场景保持可见。
- 能力包的可携带配置在安装前验证；不支持的配置或权限字段不会先触发安装再报错。
- Android 共享传输层对齐反向 TLS 与委派验证接口；开源版不因此启用 Pro 账号、中继或云同步入口。

更新保留已有连接与设置，使用普通版专属更新渠道，不转入 Pro。Windows 包未签名；macOS 包未签名、未公证。各平台原生构建、模拟器与实际设备验证的范围分别记录，不将未实机的平台称为已全面验证。
