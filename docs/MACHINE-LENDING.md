# 机器借用

## 0.8.19 入口与使用

在左侧连接上右键，选择“分享机器…”，会在“我的账号”工作区打开借用表单并预选真实设备，不自动创建邀请。未登录时先登录并解锁账号，随后继续。也可以直接从“我的账号 → 机器借用”批量选择设备。

只有已在当前账号登记的 CAgent 设备可出借。普通 SSH/RDP 保存记录不是账号设备；界面会提示在目标 CAgent 登录同一账号并开放服务，不上传这类连接的密码来假装分享。

选择指定邮箱或分享码、有效期（预设天数或自定义日期时间，服务端限制一年以内），分享码还可设置可兑换人数。邮箱接收方在自己的“我的账号 → 机器借用”看到“待接受邀请”，点击“加入连接”；分享码接收方在同一页面粘贴并加入。接受后使用短期委派凭据，界面不会显示原机器密码。

“撤销”需要二次确认；到期、撤销、会员失效由服务端拒绝后续连接，不依赖前端隐藏按钮。当前提供分享码，未提供二维码。Android 借用认证需与 Android 新账号受控中继单独联调，不能用桌面测试代替。

## 原有实现与验证（2026-11-01）

账号页支持选择自己已注册的 CAgent 机器，按邮箱邀请或生成分享码，指定到期时间（最长一年）和分享码最多兑换人数（1–100）。一次可选择多台机器。邮箱邀请只允许该邮箱账号接受；同账号重复兑换不重复计数。分享码只在创建响应中返回，服务仅保存摘要。当前界面提供分享码复制，不宣称已提供二维码生成。

借用机器使用云端中继和控制端证书绑定的短期委派令牌连接，不下发设备密码，也不将借用控制端保存为永久配对。被控端继续执行自己的终端、HTTP、桌面等权限。借用连接不能调用读取/修改身份、账号与授权的配置接口。

新连接令牌有效 5 分钟；已建立连接每次请求复核有效借用授权，长连接每 2 秒复核，撤销/到期/出借人会员失效即拒绝后续请求并关闭连接（流式连接最多约 2 秒加网络响应时间）。已建立连接最多保持 24 小时，之后重新连接。网络校验失败关闭，不回退密码或直连。机器从出借账号移除后授权失效。

服务接口：
- GET /v1/lending：我的借出、借入和邮箱邀请及可出借设备。
- POST /v1/lending/create、redeem、revoke。
- POST /v1/devices/delegate：为实际控制端证书签发一次连接引导凭据。
- POST /v1/devices/delegation/verify：仅设备所有者账号可验证目标身份。
- GET /v1/admin/lending、POST /v1/admin/lending/revoke：管理员可查看授权元数据和带原因撤销（审计记录），不能获取分享码或设备密码。

验收：Python 服务测试包含限次、跨账号、邮箱、过期、撤销、管理员撤销、短期凭据及证书绑定；真实本机 TLS 测试覆盖免密码借用终端、拒绝配置读取、无永久配对与撤销断连。真实跨账号公网中继已完成下述隔离验收；实际用户长期运行与人工UI体验仍另行验收。

### 公网全链路验收补充

本机创建仅127.0.0.1监听的临时真实ClientServer，使用正式香港中继公网入口反向注册；另外的隔离借用账号通过真实ClientProvider完成中继证书核对、目标TLS、短期委派认证及实际本机hostname管理查询。没有永久配对或分享目标密码。错误中继证书被拒绝；停止反向注册后重新启动可恢复管理请求；撤销借用后3.5秒请求被拒绝。结束后临时三账号、设备、租借、会话及本机临时目录全部移除。此验收覆盖单设备公网路径，不等同长时间或高并发压测。

admin静态资源已部署到 `/opt/cshell-web-stage/admin`，原文件备份 `/opt/cshell-pro-admin/backups/unified-20261101`。app.js/styles.css摘要与本地一致；未登录公网请求401，内部管理接口新凭据200。部署诊断时内部代理凭据曾出现在工具输出，随即轮换并核验旧凭据403、新凭据200；用户账号及admin登录配置未变。没有人工管理员登录验收。

### 三控制端持续公网验收（2026-11-01）

使用三份独立控制端证书和隔离账号，通过正式香港反向中继访问仅监听本机回环地址的临时 CAgent Server。连续 181.375 秒并发完成 81 次真实 TLS 管理查询，0 次失败；每次均核验真实目标 hostname。完整操作耗时（包含租约/委派 API 与新建 TLS 通道，不是画面延迟）：P50 3963ms、P95 6403ms、最大 9075ms。

随后停止并重新建立出站注册，三个控制端均恢复成功；撤销借用后等待 3.5 秒，三个控制端均被拒绝。单独的无会员设备所有者没有获得中继配置，申请租约返回 403；错误中继证书同样拒绝。所有测试账号、设备、租借、会话与本机临时目录已清理，未改真实用户设备。日志为 `.local/public-relay-soak.log`。

这是单目标、三个控制端、约三分钟的连续实测，不代表无限并发、长期 SLA、桌面视频或任意网络环境性能保证。
