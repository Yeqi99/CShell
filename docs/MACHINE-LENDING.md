# 机器借用（2026-11-01）

账号页支持选择自己已注册的 CAgent 机器，按邮箱邀请或生成分享码，指定到期时间（最长一年）和分享码最多兑换人数（1–100）。一次可选择多台机器。邮箱邀请只允许该邮箱账号接受；同账号重复兑换不重复计数。分享码只在创建响应中返回，服务仅保存摘要。当前界面提供分享码复制，不宣称已提供二维码生成。

借用机器使用云端中继和控制端证书绑定的短期委派令牌连接，不下发设备密码，也不将借用控制端保存为永久配对。被控端继续执行自己的终端、HTTP、桌面等权限。借用连接不能调用读取/修改身份、账号与授权的配置接口。

新连接令牌有效 5 分钟；已建立连接每次请求复核有效借用授权，长连接每 2 秒复核，撤销/到期/出借人会员失效即拒绝后续请求并关闭连接（流式连接最多约 2 秒加网络响应时间）。已建立连接最多保持 24 小时，之后重新连接。网络校验失败关闭，不回退密码或直连。机器从出借账号移除后授权失效。

服务接口：
- GET /v1/lending：我的借出、借入和邮箱邀请及可出借设备。
- POST /v1/lending/create、redeem、revoke。
- POST /v1/devices/delegate：为实际控制端证书签发一次连接引导凭据。
- POST /v1/devices/delegation/verify：仅设备所有者账号可验证目标身份。
- GET /v1/admin/lending、POST /v1/admin/lending/revoke：管理员可查看授权元数据和带原因撤销（审计记录），不能获取分享码或设备密码。

验收：Python 服务测试包含限次、跨账号、邮箱、过期、撤销、管理员撤销、短期凭据及证书绑定；真实本机 TLS 测试覆盖免密码借用终端、拒绝配置读取、无永久配对与撤销断连。尚需部署云端与客户端后验证真实跨账号公网中继/UI体验。
