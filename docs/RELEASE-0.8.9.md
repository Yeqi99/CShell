# 0.8.9：文件连接、统一能力与工作台

状态：正在完成验证，尚未公开发布。正式渠道与本机版本仍为 0.8.8；旧标签和附件不移动。下列内容描述本轮实现，最终包、提交和渠道验收在发布后补记。

## 连接与界面

- 新建连接支持独立 SFTP、FTP 和显式 TLS 的 FTPS，直接打开文件工作区。SFTP 不创建 Shell / PTY，FTP 与 FTPS 不冒充 SSH。地址与凭据分别保存，FTPS 校验证书和主机名，不降级到明文。
- 文件列表、路径、多选、普通文件上传下载、重命名、建目录、删除与当前会话传输队列相互配合。FTP 不显示未实现的编辑、递归传输和跨连接复制；SFTP 编辑保留冲突检查，远端缺少原子替换能力时保留原文件并说明原因。
- CSV 与多条明确连接文本支持文件协议，密码不在预览回显。确认保存后才写入加密凭据，不自动连接。
- 默认双击 SSH 使用原生终端、RDP 使用远程桌面；全局可选可视化，单台连接右键可勾选默认可视化，Pro 随账号同步。旧版未标记为主动选择的可视化默认迁移为原生，已有单台覆盖保留。
- 可视化 SSH 的「文件与机器信息」默认折叠，共用真实 PTY。隐藏或断开后停止后台采集与自动保存，保留路径和编辑草稿。
- 侧栏空白处右键的字号调整收纳进「外观设置」。默认界面 14 px、分组 14 px、服务器和地址 12 px；已有自定义值保留，侧栏与终端下限 8 px、界面下限 9 px。
- 扩展分类根据当前面板宽度调整，避免多功能区并列时竖排挤压；RDP-only 安装入口提供实际 Windows 下载与安装指南，不要求选择 SSH。

## MCP、CLI 与工作台

- 浏览器工具复用所选机器的本机渲染浏览器、独立 Cookie 分区与真实网络出口，支持标签、导航、元素快照、截图、交互与有限同源抓取。支持明确 frame 的跨源 iframe 和开放 Shadow DOM，页面变化后旧引用失效。身份验证仍遵守网站的验证码、多因素认证和系统确认。
- 支持原生远控的 CAgent 提供真实画面截图及鼠标键盘输入；从 H264 帧解码取得有界 JPEG，不把最后一帧或桌面入口冒充实时远控。查看和控制分别授权，断开或撤权后停止。
- 新浏览器读取/操作、远控观看/输入权限分别控制，默认关闭。输入敏感值不写入操作审计或模型工具记录；网页和截图不改变权限。
- MCP 返回标准图片块，HTTP 返回有界图像数据；模型多模态能力按已知契约判断，图片单独加密保存。无图片能力时明确提示，不重放工具。
- 命令台、外部 CLI、可视化能力表单、HTTP 与 MCP 共用授权目录。帮助、搜索、参数契约、连接、范围切换、调用和文件结果保存完整说明见 [CLI](CLI.md)。CLI 不连接本机 Shell，不解释管道或命令替换。
- 工作台提供概览、命令行、可视化三种视图；支持独立命令台标签、输入草稿、历史结果与取消等待。切换目标后旧参数不能直接执行，关闭视图清理自己创建的 API 连接。

## 自定义扩展

- 独立 .cshellext 包可导入或拖入。snippets 贡献命令候选，process 贡献结构化独立进程工具。安装、启用和运行授权分开；工具进入智能体、MCP 与 CLI 的同一目录。
- 清单、协议、文件摘要、系统/架构、输入与输出 Schema、时限和并发均校验。撤权、停用或换包取消现有调用，更新字节后重新授权，不自动重放。
- 扩展运行在实际安装它的宿主。远端需另行安装与授权，选中远程机器不会搬动本机代码。私有运行时不改系统依赖或全局 PATH，独立进程不等于操作系统安全沙箱。
- 微信继续作为独立自定义包，不捆绑、不在公开市场展示。

## CAgent 兼容与更新

- 读取实际方法契约后再调用硬件与市场功能，旧端不再直接收到不认识的枚举值。已有执行权限的 SSH 目标可用只读兼容采集，不安装系统运行时。单个开发应用不兼容不会让整个市场失效。
- 支持新更新协议的 CAgent 在真实活动归零后等待空闲窗口，验证附件、版本和设备身份后才确认切换。新任务与更新入场相互约束，保留身份、数据与权限。
- Windows 准备阶段不替换活跃服务；Unix 原子切换，失败可回滚。结果未知不盲目终止/重放。同一失败版本自动冷却 6 小时，可显式重试，新版本不受旧冷却阻塞。
- 不支持安全握手的旧版本显示一次更新指引，不承诺无中断静默升级。

## OpenCode

- 模型选择器动态显示「OpenCode → 账号 / 模型」二级菜单，打开与重新聚焦时刷新目录，不要求逐个填入基座。只有明确选中时才创建对应引用，已有会话固定模型和输入草稿。
- 同步账号、目录下架和真实调用拒绝即时反映到基座设置，区分失效与临时网络错误；不清除密钥，不随机换模型，不自动选择付费模型。
- 官方客户端桥已通过真实 1.19.4 归档安装与本地会话 API 集成验证。真实官方 1.19.4 对 beam-free / Go、mimo-v2.6-flash-free / Zen、big-pickle / Zen 均返回服务端拒绝；纯官方命令也复现。不能把「已接入官方客户端」写成「所有免费模型可调用」，不伪造客户端标识绕过限制。运行时固定摘要、私有安装、按配置出口请求；结构化工具意图交回 CShell 权限链。官方协议元数据通过同一出口更新，检测必须明确选择模型。

## 验证记录

- FTP / FTPS 使用真实回环控制和数据通道验证，包含 TLS 验证、不降级、被动地址检查、读写、取消、连接丢失不重放。MCP / REST 检查文件授权、客户端隔离与目标身份变化。
- SFTP 在真实 SSH fixture 和真实 Electron 窗口验证：0 Shell、0 PTY；读取、建目录、安全原子保存、无扩展时拒绝保存；断线保留草稿，重连使用新会话，不改变旧编辑目标。
- 图像、多模态、浏览器实际页面与跨 frame 交互、H264 解码、更新握手与回滚均有定向验证。Windows 真实进程与 Linux 只读远端采集已验证；跨平台实机限制仍单列。
- 本地完整回归：开源 489 项中 484 通过、3 平台跳过，2 项进程启动时序测试修正后单文件 8/8 通过；Pro 主回归 511 项中 507 通过、3 平台跳过，唯一 Windows ACL 设置超时经同权限 .NET SetAccessControl 修复，管理与存储 12/12 复测通过，独立进程扩展 8/8 通过。MCP 输入 Schema 和 Agent 状态契约问题已修复。后续 CLI 真实管道取消测试两版 5/5，OpenCode 核心 5/5、Pro 14/14，类型检查通过。最终跨平台构建、源码 SHA 和附件验收另记。

## SSH 交互性能

- 可视化与原生视图复用同一个本地 xterm 与真实 SSH PTY。隐藏终端保留输出历史，停止非必要语义着色，提示符与链接装饰按变化更新。
- xterm 6 的不可见字符测量节点移到独立屏外宿主，避免隐藏工作区零宽测量引起反复同步布局。输入节点、缓冲区和终端不移动。窗口拖动、缩放和 fit 按帧合并，结束后持久化。
- 2026-10-25，在 Windows 本机隔离的 SSH fixture 上验证含字体测量修复的 Pro 0.8.9 review 包：另一 SSH 会话持续输出提示符和 URL 日志（名义 1,000 行/秒），前台原始/可视化终端各采集 60 个有效字符。keydown 事件处理到更新后下一动画帧的 p95 分别为 **48.8 ms / 53.7 ms**；两阶段均未观测到超过 50 ms 的 Long Task。测试保持语义配色开启，不接触用户连接、密钥或配置。这是本地渲染/回显压力结果，不是 WAN 网络延迟或物理屏幕呈现时延，不表示其他机器也具有相同数值。
- 原始 → 可视化 → 原始的真实包回归确认同一 SSH PTY、同一 xterm 输入节点；`view-history-marker` 输出仍保留，连接请求数不增加，默认打开方式持久化。以上数值来自 Pro review 包；开源版共享修复代码，最终发行附件仍需独立验收。
- 可复跑的人工基准归档为 `scripts/ssh-render-latency-smoke.ts`（`pnpm exec tsx scripts/ssh-render-latency-smoke.ts`），通过 `APP_PATH`（或 `CSHELL_EXECUTABLE`）指定实际包；未指定时从 `package.json` 版本查找唯一匹配的 Windows 包。结果保存在 `test-results/ssh-render-latency-<APP_LABEL>/`。不自动加入每次 CI，不在并行构建时用不同轮次计算提升百分比。

## 平台与边界

文件独立协议、工作台命令/可视化与官方客户端桥属于桌面端。Android 继续提供其已实现的 SSH / CAgent 文件能力；云同步保留但不消费其他协议和新增可选字段，不宣称手机与桌面功能完全一致。

发行只使用最终提交成功构建并核验的附件，开源 / Pro / CAgent / 架构分开。Windows 签名、macOS 公证与实机验证限制如实保留；Android 和系统安装器的必要确认不会绕过。官网与香港渠道在包验收后统一更新，不使用本轮早期构建替代最终源码。
