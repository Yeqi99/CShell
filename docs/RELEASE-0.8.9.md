# 0.8.9：OpenCode 目录一致性与 SSH 交互性能

状态：正在验证，尚未公开发布。旧 0.8.8 标签和附件保持不变。

## OpenCode 基座

- 目录刷新、恢复云账号或模型调用被拒绝后，基座列表、编辑页和新会话选择器使用同一运行时状态。
- 区分模型已下架、协议未适配、服务端拒绝与暂时无法读取目录。认证凭据和云端模型引用保留；暂时网络故障不伪装成下架。
- 新会话不能隐式回退到失效默认模型；使用者明确选择其他模型。纯账号验证不改默认基座，不自动选择付费模型，现有会话保持原模型。
- 扩展目录不再把“被列出”说成“已验证可调用”。服务端 403/404 的固定说明不泄漏上游响应中的秘密；允许显式重测并在成功后恢复状态。
- 官方 OpenCode 客户端集成仍不是已交付能力。本版修复当前实际调用路径的状态反馈，不绕过服务商限制。

## SSH 终端

- 可视化和原始视图仍复用一个本地 xterm 与同一个 SSH PTY，不使用截图或本地假回显。
- 隐藏的终端继续解析、确认并保留输出历史；停止非必要语义着色。可见提示符和链接装饰按变化更新，保留远端 ANSI 色和全屏程序行为。
- xterm 6.0 DOM 字符宽度缓存的测量节点移至独立屏外宿主；仅移动 aria-hidden 的测量节点，避免隐藏工作区的零宽测量反复触发同步布局。输入、缓冲区和实际终端留在原处。此兼容层针对锁定的依赖版本，有真实浏览器回归保护。
- 文件窗口最小化、关闭、切出前台或断开后暂停监控。窗口拖动/缩放按帧更新，结束后持久化；终端 fit 同样按帧合并，并保留浮窗返回时的真实 PTY 尺寸恢复。

## 验证记录

- 两边 TypeScript 与 OpenCode/云导入测试通过；覆盖目录下架、临时故障、服务端拒绝、显式恢复、默认模型保留、云恢复后重新核验。
- 真实浏览器覆盖 390 px 窄屏、400/550/700 px 智能体面板；无失效模型隐式发送、无刷新通知循环。
- 15 项 SSH/终端定向测试通过；文件/终端保持同一挂载与草稿，拖动期间不写存储，结束后一次保存。
- 2026-10-25，在 Windows 本机隔离的 SSH fixture 上验证含字体测量修复的 Pro 0.8.9 review 包：另一 SSH 会话持续输出提示符和 URL 日志（名义 1,000 行/秒），前台原始/可视化终端各采集 60 个有效字符。keydown 事件处理到更新后下一动画帧的 p95 分别为 **48.8 ms / 53.7 ms**；两阶段均未观测到超过 50 ms 的 Long Task。测试保持语义配色开启，不接触用户连接、密钥或配置。这是本地渲染/回显压力结果，不是 WAN 网络延迟或物理屏幕呈现时延，不表示其他机器也具有相同数值。
- 原始 → 可视化 → 原始的真实包回归确认同一 SSH PTY、同一 xterm 输入节点；`view-history-marker` 输出仍保留，连接请求数不增加，默认打开方式持久化。以上数值来自 Pro review 包；开源版共享修复代码，最终发行附件仍需独立验收。
- 可复跑的人工基准归档为 `scripts/ssh-render-latency-smoke.ts`（`pnpm exec tsx scripts/ssh-render-latency-smoke.ts`），通过 `APP_PATH`（或 `CSHELL_EXECUTABLE`）指定实际包；未指定时从 `package.json` 版本查找唯一匹配的 Windows 包。结果保存在 `test-results/ssh-render-latency-<APP_LABEL>/`。不自动加入每次 CI，不在并行构建时用不同轮次计算提升百分比。

Windows 签名、macOS 公证和实机验证限制沿用既有发行规则；只公开成功构建且摘要核验通过的附件。
