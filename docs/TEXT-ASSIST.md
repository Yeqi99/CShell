# 文字助手与连接体验

## 使用

- 选中文字后右键 **AI 分析**：打开现有智能体会话，没有会话时创建；保留已有草稿，追加原文和当前界面语言的提问引导，光标移到下一行。不会自动发送。
- 选中文字后右键 **AI 翻译**。终端还提供 **翻译终端内容**，可开启自动翻译增量，原文/译文随时切换。对话中自动模式读取当前对话内容。翻译层不修改终端输出。
- 普通输入框和已识别的 Shell 输入位置右键 **我想……**，输入意图生成候选；可继续补充。点击候选只填入原来的选区/光标位置，不发送消息、不执行命令。输入位置已变化时拒绝覆盖；密码字段不提供此入口。
- 智能体设置 → 模型基座，分别选择翻译与输入助手默认基座；与聊天和连接凭证解析模型独立。

翻译使用当前窗口的分块缓存与后端有界内存缓存，按模型、目标语言和原文区分；不将翻译文本额外写入磁盘。自动翻译由用户开启，关闭面板停止后续采集。切换原文时暂停翻译，返回译文后复用缓存并处理新增内容。已发出的模型请求可能继续完成，但关闭后的结果不会写入输入位置。

## 连接和 WSL

新建连接先列出已有机器；添加连接记录进入可编辑表单，返回选择页不丢草稿。启用 WSL 插件后，实际安装的发行版自动出现在左侧本机环境和连接选择页。

WSL 发行版安装在当前 Windows 用户下进行。组件引导由 Windows 请求管理员授权；安装不自动重启。WinINet 无法取得目录时，支持 `--from-file` 的 WSL 会尝试通过应用的系统代理获取 Microsoft 官方目录、下载 Ubuntu 官方镜像并验证 SHA-256，然后注册发行版。未绕过摘要校验，不修改全局代理或 `.wslconfig`，不注销/覆盖已有发行版。

首次以 root 为默认用户的发行版在工作区初始化表单创建普通 Linux 用户；密码仅经子进程 stdin 提交，不放入命令参数、不保存。已有用户不会被覆盖。支持默认用户管理的新版本 WSL 才执行初始化；进入会话时显式运行 Shell，避免每次进入发行版启动器的初始引导。

参考：[Microsoft WSL 命令说明](https://learn.microsoft.com/en-us/windows/wsl/basic-commands)、[Microsoft 发行版目录](https://github.com/microsoft/WSL/blob/master/distributions/DistributionInfo.json)。网络不可达、系统授权或必要重启仍需在当前安装界面处理。

## 智能体连接工具

`connect_machine` 通过保存的目标 ID 建立真实 SSH 会话，凭据只由后端读取；在工作台创建对应终端页签，后续工具调用绑定新目标。必须同时授权 CShell 建立连接能力和目标机器范围，命令能力仍单独授权。审核中修改目标或撤权会拒绝连接。缺少保存凭据时引导用户在工作台补齐，不让模型索取密码。

工具记录分别标注目标、输入和返回，空参数对象不展示。中文加粗兼容修复不改变代码块、行内代码或转义星号。

## 连接提取与基座可用性补充

连接表单标题和辅助操作统一对齐。点击“从文本填写”或粘贴图标后，在原位选择读取方式；手动字段始终保留。默认本地规则识别 SSH 命令、SSH URI、主机地址及中英文标签（主机、端口、用户名、密码、名称、分组）。未提供的字段不覆盖，冲突目标或无效端口拒绝填写。规则解析不调用网络，不执行命令。已配置基座时才显示 AI 方式，可独立选择解析模型。

没有配置基座时，隐藏文字/终端右键 AI 操作、模型默认选项和对话发送区，保留基座配置与已有历史入口。添加或删除基座后由 IPC 通知界面刷新，不需要重启。配置存在不等同于服务当前联网可用；临时网络故障不删除配置或历史。

基座编辑表单提供“测试连通性”：使用正在填写的 URL、模型和 Key 发起独立的简短完成请求，不携带会话、机器或工具信息，不自动保存草稿。显示请求耗时、流式响应支持或具体 HTTP 错误；20 秒超时。修改 URL 时不会复用旧地址的密钥。

智能体的 SSE 内容经主进程合并为约 40ms 的界面更新，流式增长时保持滚动跟随；用户向上滚动后不抢回视图。保留停止操作和中断校验，未完成的工具参数不执行。接口返回普通 JSON 时兼容完整回复。

本次验证：58 项单元/协议测试、构建、连接提取 Electron 回归、智能体界面回归通过。`scripts/ai-stream-smoke.ts` 用保持打开的本机 SSE 响应确认结束前即可看到增量文字，并验证停止和无基座隐藏行为。`scripts/extraction-smoke.ts` 验证无 AI 本地规则、冲突保护和显式 AI 填写。模型测试使用受控本机接口，不代表外部服务实时健康。
