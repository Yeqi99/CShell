# 使用统计

使用人数仅在 GitHub 动态徽章展示，客户端不显示人数。设置 → 关于与更新只保留匿名计数的本机自愿开关。账号来自服务端现有认证请求，不能判断是否有人正在操作。账号与设备可能重叠，不应相加。匿名统计默认关闭，随机标识仅存在本机独立文件，不随账号或外观同步；主动开启后每分钟心跳。关闭停止心跳并请求删除，离线删除下次联网重试。匿名数据仅保留最近 30 天记录。

公开 JSON：`https://shell.canp.ai/api/v1/public/usage`。GitHub SVG：`https://shell.canp.ai/api/v1/public/usage-badge`，返回 no-cache，GitHub Camo 仍可能缓存。完整口径页：`https://shell.canp.ai/usage.html`。

公开响应只含汇总数字和时间，不含邮箱、账号 ID、设备名称、IP、随机标识或操作内容。匿名设备请求未经账号认证，不能作为审计、计费或精确人数依据。当前匿名客户端集成范围为桌面开源版及 Pro；不宣称所有平台都已发送匿名心跳。
