# 开源版收口与 CShell Pro 前置评估（0.6.33）

日期：2026-10-19。范围：当前 Windows x64 CShell 与 CAgent。本轮检查不等于所有系统、驱动、网络与真实第三方服务全部验收。

## 本轮修复

- 远程桌面全屏请求被主窗口的全拒绝浏览器权限策略挡住。仅允许 CShell 自己的主文档申请全屏；其他页面、子框架及摄像头、剪贴板等权限不因此开放。真实 Electron 检查窗口全屏状态、视图尺寸、重复进入退出、Esc 返回原工作区状态。
- Esc 在工具栏持有焦点时也明确退出远控全屏，不向被控端发送该次按键。窗口内铺满与系统全屏保持独立。
- 应用市场初始化/操作失败在折叠区域之外显示，加载状态可见。
- 机器智能体显示中文执行状态，解释待本机确认状态，保留错误和回答的独立显示，提供可展开的真实工具记录；停止后立即刷新任务，网络恢复后清除旧读取错误。
- 对外名称统一为 CAgent：CShell 连接入口、插件与应用界面、Windows 原生窗口、浏览器后备界面和说明。旧协议 ID、命令、路径及设备身份保持兼容。
- 更新 CAgent 文档的现状摘要，移除“关闭即退出”“Windows 仍只有目录包”“微信尚未集成”等已过时的当前状态描述，保留按日期的历史证据。

## 实际验证

- 全量自动化：287 项通过，0 失败（`test-results/open-source-closeout-tests.log`）。后续权限策略、CAgent 智能体与微信路由针对回归 7 项通过，其中新增全屏权限隔离测试（`closeout-final-targeted.log`）。
- 真实 Electron：全屏/退出/Esc/恢复尺寸；设置分类、草稿保留、保存与取消、窄窗口和明暗主题；SSH 建连取消/关闭/断线恢复且保留滚动历史；RDP 保存、加密密码、重载、双击路由；机器工作区多终端、页面切换、重新认证与旧目标失效。
- 文件：隔离 CAgent 真正上传、下载、重命名、删除、拖放 200000 字节文件与 Windows 文件剪贴板传输。使用临时测试目录，不在真实远端做删除测试。
- 界面：插件搜索、安装条件与计划展示、WSL 网络配置保存不重启；AI 配置、模拟基座回复、会话输入草稿；事件规则草稿、故障和来源不可用；桌面解码恢复与生命周期夹具。
- `pnpm audit --prod --json` 本次返回 0 条已知漏洞（252 项依赖记录），不等于完成安全审计，也不覆盖 Python、原生代码或第三方应用漏洞。
- 两个旧验收脚本已更新：RDP 从临时打开改为保存配置 ID；文件夹具不再假定 TEMP 与用户目录在同一磁盘。失败与修正日志保留，未把过时脚本失败当成产品已通过。

主要证据：`desktop-fullscreen-0.6.33.json`、`closeout-window-permissions.log`、`closeout-feedback.json`、`closeout-settings.log`、`closeout-connection-layout.log`、`closeout-navigation.log`、`closeout-rdp-saved.log`、`closeout-lifecycle.log`、`closeout-files.log`、`closeout-ai.log`、`closeout-events.log`、`closeout-desktop-races.log`、`closeout-dependency-audit.json`（均位于 test-results）。

## 商业化前仍有重大问题

| 项目 | 已有能力与明确缺口 | 对 Pro 的影响 |
| --- | --- | --- |
| 无人值守远控 | Windows 用户进程采集；没有登录前服务、虚拟显示驱动或可靠的锁屏/RDP 会话覆盖。Windows 拒绝采集时恢复机制不能创造可访问桌面。 | 不能承诺通用无人值守远控。需独立验收会话切换、锁屏、UAC、显示器移除与重启。 |
| 性能与恢复保证 | 已修复丢失帧确认和采集无进展导致的冻结；已有短时公网 TCP/UDP 及故障注入记录。缺多小时视频/拖动、弱网、泄漏和真实公网中继部署矩阵。 | 不应以当前结果承诺稳定帧率或商业 SLA。 |
| 跨平台对齐 | Windows x64 为实测主线；macOS/Linux 原生精简界面、桌面采集/控制、Windows ARM 和手机尚未对齐。 | 明确首发支持系统；不能把 CI 构建目标当成已经交付与验收的平台。 |
| 微信稳定性与范围 | 仅精确核验的 Windows Weixin 4.1.15.50；历史分片和朋友圈缓存有范围限制，点赞评论等未交付，远端订阅尚未接入 CShell 规则触发来源。 | 继续标注实验能力，不宜作为不受版本限制的付费保证。 |
| 发行可信度 | Windows 配置明确未签名；更新目前通过 GitHub 和 SHA256 校验。尚缺正式签名身份、macOS 公证与全平台安装/升级/回退证据。 | 上线前完成签名和发布链路，不能把摘要校验等同发行者签名。 |
| 最终边界验收 | 旧 API/MCP 长时并发、泄漏与真实受控撤权综合验收仍有未完成项；单元测试和隔离测试不替代这部分。 | 对外承诺远程管理/多客户端服务前补齐；保持现有授权边界。 |

## 结论与建议边界

可以开始 CShell Pro 的产品设计与独立功能开发，但当前不能判定为“没有重大待解决问题”或直接商业上线。建议把 Windows x64 的终端、文件、连接与智能体工作流作为已有基线；远控、微信和跨平台按各自实际成熟度声明。Pro 开发与上述稳定性/发行工作分开列清单，不再用新增功能覆盖缺口。

本轮未新增收费、账号、许可证服务器或云端依赖，未改变用户指定的宽松默认权限，也未因界面命名变更重置已有权限。GitHub 发布与本机安装分别记录，不将构建成功表述为已发布。
