# CShell 0.6.5 Windows

- 微信工具包 0.1.2 支持持续监听，通过本地管道推送事件与游标，并将消息写入有界持久队列。
- 新增 wechat_subscribe、wechat_subscriptions、wechat_events、wechat_unsubscribe。支持精确会话或已授权的 *，可分页、等待新事件、停止及删除本地队列。
- 原生回调过滤绑定账号；权限撤销、父进程退出、租期到期会停止监听。设置页可停止监听。
- 默认持续 1 小时，最多 24 小时；每队列最多 10000 条/7 天，最多 8 个队列。缺口明确报告，不自动补历史、不自动恢复绑定、不自动唤醒模型回复。

验证结果单独保存在 test-results；手机发送的文件传输助手 123 已实时接收、推送、落盘，并在监听退出后按游标续读成功。最近会话读取在无需人工打开页面的情况下验证。

新增 wechat_recent_conversations：本地会话库分页读取会话 ID、未读数、最近活动时间等元数据，不含正文，不标记已读。独立 readSessions 授权默认关闭；按客户端排序字段和 ID 稳定翻页，实时变动可能重排，客户端应刷新首屏并去重。
