# CShell 0.8.12：输入、传输与草稿可靠性

本轮发布 CShell、CShell Pro 与 CAgent 0.8.12。开源版与 Pro 保持独立更新渠道，安装保留既有配置。

## 三项独立改进

- Android 远控：连续手势串行执行，失败或结果超时后丢弃依赖输入；鼠标松开不再清掉仍按住的 Shift/Ctrl/Alt。文本光标未确认时停止后续按键，避免输入到错误位置。
- 文件传输：跨机器复制同时关联源、目标会话；取消后即使目录信息刚返回，也不会继续创建目录。网络意外断开会取消关联传输。
- 智能体草稿：保存恢复成功后，解除对应会话的失败提示；其他会话的成功不会掩盖未保存草稿，旧请求晚到不会覆盖最新状态。恢复读取失败仍独立提示。

## 官网

首页、按架构选择下载和文档阅读器已先行更新；文档搜索结果支持方向键、Home/End 和 Esc。网页部署与客户端发行分开核验，不改已发布附件。

## 已完成的开发验证

两版文件相关 20 项测试、连接生命周期与取消 10 项测试、两项加密草稿测试及类型检查通过。真实 React hook 浏览器回归覆盖失败恢复、多会话和乱序完成。Android 光标修复在两版 API 29/35 模拟器通过；Pro 8 组连续点击验收通过。以上为开发提交验证，候选发行提交的完整构建与安装验收另行记录。

## 已知限制与未关闭问题

早期 Pro Android 10 模拟器曾出现一次连续点击计数不足，后续带诊断与 8 组测试通过，但根因尚未查明，不能宣称该偶发问题已解决。保留触摸诊断，不自动重放操作。模拟器不代替 Android 真机验收。

Windows 安装包签名与 macOS 公证条件、Mac/Linux 实机验证范围，按本轮实际构建结果记录；未成功构建与校验的附件不标记发布。本机 CAgent 旧运行时切换仍需核验。教学环境独立任务及既有机房 0.8.11 安装包不自动改标为 0.8.12。
