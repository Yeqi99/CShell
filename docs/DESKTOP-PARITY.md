# 桌面交互统一（2026-10-26）

工作台可视化模式与连接桌面复用同一桌面组件。工作台只提供全局入口，不绑定或伪造机器连接，不发起机器能力探测。

- 图标单击选择、Ctrl 多选、空白处拖动框选；双击或 Enter 打开。应用名称不参与文本选取，应用内容中的文字和输入框仍可正常选择。
- 图标按当前桌面高度从上向下排列并自动换列。空间不足可滚动，窗口尺寸恢复后重新排列；不会裁掉末尾应用。
- 两处使用相同窗口拖动、缩放、最大化、最小化、任务栏和显示桌面操作。切换工作台模式、最小化和恢复保留已挂载应用及草稿。
- 工作台的桌面外观使用独立的 `cshell-workbench` 外观记录，沿用现有外观存储与账号同步；不会改变其他机器外观。窗口位置仍仅在本机保存。
- 偏好设置、扩展及智能体仍打开原有真实入口。桌面外观不混入机器权限和连接状态。

验证：`scripts/desktop-parity-smoke.ts` 在独立 Electron 窗口覆盖工作台与 SSH 桌面：单击不打开、双击/Enter、真实鼠标框选、文字不误选、最小化恢复、终端草稿保留，以及 1000×700、500×330、280×290 和恢复大窗口后的应用可达性。该测试使用隔离数据与模拟内容，不连接用户服务器。

本次为本机构建修正，未冒充新的全平台正式发布。
