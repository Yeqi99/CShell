# 0.8.5 发布记录

发布于北京时间 2026-10-24。开源与 Pro 同步发布，不覆盖 0.8.4 标签或附件。

## 三项实际改进

1. 智能体运行或等待授权时，即使没有远程连接，关闭 CShell 也会提示。取消保留任务，确认后停止并保存。
2. CAgent Windows 产品版本与文件版本写入真实发行版本；本轮为 0.8.5 / 0.8.5.0。
3. CAgent 静默升级刷新当前安装已有快捷方式的图标与工作目录，不重建用户删除的入口，不接管其他安装，不改变自启动选择。

## 发布与验证

- 开源标签 `v0.8.5`，源码 `20e3fefa4f0ec48f1093a6669bdcc5937f1b9e5a`，GitHub release 422009654。
- Pro 标签 `pro-v0.8.5`，源码 `d7dd873cc18e91039b5fdcc7e04cf52a62cbdacd`，GitHub release 421995649。产品构建自 3091c57；之后到标签仅增加验证记录。
- 开源 15 个包、Pro 13 个包及各自 SHA256SUMS，共 30 项均通过 GitHub 服务端摘要与本地 SHA-256 对照。
- 香港正式目录 `/downloads/{opensource,pro}/v0.8.5/` 的 30 项文件完整哈希一致，公开 HTTPS HEAD 均为 200 且长度正确。
- 两个 releases.json 最新项为 v0.8.5，渠道及架构分离；官网首页、下载页、版本文档已同步 0.8.5。开源下载仍指向 GitHub，Pro / CAgent 使用香港源。
- 官网保留个性化工作台视觉、真实产品界面；下载页用新包真实摘要和大小。20 页链接结构、1440 / 390 宽度交互与无横向溢出检查通过。
- 核心 409 / Pro 438 项完整测试通过；七项跨平台 CI 成功。两版 Windows 实际包的原生加密存储、隔离、SSH 输入和文件操作通过。
- 两版实际包更新 IPC、渠道选择、流式校验下载、错误反馈与篡改阻止通过。该自动化使用网络夹具；已安装实例另行在线检查并显示当前最新版本。
- 两版 CAgent 实际发行安装器隔离安装成功，读取实际 EXE 元数据一致。正式本机 CShell、Pro、CAgent 均已安装并打开 0.8.5；Pro 登录和六条连接保留，CAgent 设备身份与证书指纹不变，既有快捷方式已指向新版。

## 限制与后续审查

Windows 安装器未做发行者代码签名；macOS 未做 Apple 公证。Android 签名与原证书一致，CI / lint 验证通过，手机安装保留系统确认。macOS/Linux 尚未覆盖所有实体设备与发行版。不声称所有远端设备已静默升级。

开源包首次功能测试通过但清理退出超时，原包复测正常，失败日志保留。升级时旧 0.8.4 CAgent 在无远程连接下接受 shutdown 后仍有进程残留，已核对路径后关闭并升级；下一轮需要隔离复现其退出流程，不能宣称 0.8.5 已解决。后续继续向稳定的 1.0 推进，不为版本号凑改动。
