# 走向 1.0：按真实问题推进

## 交付约束

开源内核先完成实现和验证，再合并 Pro；共享功能不得只在一个版本修复。每个递增小版本至少解决三个独立、可复现的问题或有明确用途的小功能，不拆分一个改动凑数量。若真实使用、故障恢复和发布流程已足够健壮，可在 1.0 前停止继续加版本；停止前必须完成证据审计。

每版更新日志记录触发场景、变化、验证、平台限制。版本、标签、附件摘要、官网链接、香港镜像和更新渠道须一致。下载文件先就绪，再切换清单；不能将草稿或构建成功当成发布成功。升级保留用户数据与身份。

## 当前基线：0.8.13 已发布（2026-10-27）

开源与 Pro 的不可变标签、30 个渠道附件、香港更新清单及官网五个发布文件已核验。三项独立改进是浏览器上传取消、取消退出后的自动更新保留、延迟文件重读时保护新草稿，详见 [0.8.13 发布记录](RELEASE-0.8.13.md)。本机升级被用户 Esc 中止，最近确认仍为 0.8.12；线上发布不等于本机安装完成。

冻结后已完成三项独立改进：CAgent 宿主已结束时的窗口退出恢复；更新偏好并发写入和失败保存保护；机房代理与课程环境同时下发时的变量丢失修复。两版均已有针对性回归，尚未进入新发行包。机房变更详见 [并发保存保护](CLASSROOM-ENVIRONMENT-SAVE.md)，还需完整回归和成品验收。继续审查实际故障及完整需求覆盖，不为凑版本拆分修复。

## 历史基线：0.8.12 已发布（2026-10-27）

开源、Pro 与 CAgent 的发行标签、30 个渠道附件、香港更新清单和官网版本链接已核验。三项独立问题域为 Android 输入队列、跨机器传输取消、智能体草稿保存警告恢复，详见 [0.8.12 发布记录](RELEASE-0.8.12.md)。本机开源、Pro 和 CAgent 已安装并打开 0.8.12，实际运行版本、原连接和 CAgent 身份摘要已核验；旧 CAgent 退出失败仍是待修复缺口。

该阶段的 0.8.13 发行验收已完成，本机升级仍待完成。继续审计账号/扩展跨端恢复与网络故障处理。官网首页、架构下载、文档阅读器、机房页和开发者入口已分别改版；整站完成仍需整体审计，不能用局部验收替代。

## 历史基线：0.8.11 已发布（2026-10-27）

开源与 Pro 的标签、附件、香港更新渠道和包含机房入口的官网已核验。详见 [0.8.11 发布记录](RELEASE-0.8.11.md)。本机三份正式包已安装；设备身份摘要保持不变，CAgent 运行时切换及重开后的界面验收仍待完成。

0.8.11 覆盖独立问题：工作台/机器桌面交互不一致、图标不随尺寸布局及文本误选、局域网发现启动失败后的恢复、屏幕标识失效与共享名称不明确、机房单文件安装交付。后续版本继续按真实问题立项，不拆分测试修正凑版本数量。

下一阶段先审计：本机最终包与数据保留、远控首次手势失败诊断、跨端账号及扩展数据恢复、官网真实交互和移动端设计质量。只有复现并验证三个独立产品改进后才递增下一版；测试夹具修正单独记录。官网“个性化设计已完成”的结论仍需页面实查与交互验收，现有上线和摘要一致性不足以证明设计目标达成。

## 历史记录：0.8.4 发布前状态（不代表当前）

已实现并验证的改进包括同机浏览器占用恢复、SSH 桌面终端历史保留、账号显式导入与隔离、权限云恢复与批量选择。当前 GitHub v0.8.4 / pro-v0.8.4 仍为草稿；完成附件上传、香港核验、渠道切换及本机安装前，不开始宣称下一版交付。

最终本地开源 16 组桌面回归已通过；其中 release-desktop-smoke 功能断言通过后，退出夹具进程停滞，经确认仅结束隔离测试进程后其余检查完成。新增有界夹具清理，需单独重跑证明无人工清理依赖。Pro Windows CI 已通过。Mac/Linux 实机与 macOS 公证限制仍需准确标注。

## 后续版本立项依据

优先审查实际问题：多连接/断线重试及退出释放；账号切换和失败回滚；应用代理故障不直连；多端数据兼容；更新失败恢复与渠道隔离。每项先形成复现证据再选入下一版，不预先承诺空洞版本号或堆功能。

## 官网独立设计要求

完整重新设计，不只替换颜色和营销标题。围绕 CShell 自身的机器工作台展开：真实产品界面、连接路径、窗口任务与操作结果。首页、设备下载、开源/Pro 权益、文档导航和发布记录形成统一视觉与交互；桌面与手机均需实测。不得用假监控数字、不可用功能或演示按钮冒充产品能力。

验收包含键盘焦点、窄屏阅读、下载平台/架构选择、真实附件摘要、开源 GitHub 入口、Pro 香港入口、文档内部链接和现有服务不受影响。设计实现纳入 Pro 官网源代码，并在开源文档保留一致功能口径。

## 完成审计

逐项检查代码、真实回归、包内容、在线发布、下载源、本机运行版本、文档与官网。缺少证据视为未完成；不能凭版本号、绿灯或意图认定目标达成。维护独立的发布记录，不覆盖旧标签。
