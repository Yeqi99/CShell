# 机房屏幕共享

在同一局域网里，老师主动共享一个屏幕，学生从共享列表选择并在独立标签页观看。它是 CShell 的可选扩展 `cshell.classroom`，不需要先创建 SSH 或 CAgent 连接。

本功能需要包含机房共享扩展的新构建；已发布的旧 0.8.10 不包含它。目前仅 Windows 支持，其他平台不会显示为可用。本功能只传输屏幕画面，没有音频、鼠标或键盘控制，也不会自动启动共享。

## 老师：选择屏幕并开始

1. 在扩展的插件市场中启用“机房屏幕共享”，打开它的专属页面。
2. 选择“共享我的屏幕”，填写易辨认的共享名称（最多 60 个字符），选择实际存在的屏幕。
3. 先关闭不希望展示的窗口，再点击“开始共享”。仅选择屏幕或启用扩展不会开始广播。
4. 共享过程中，应用顶部与扩展页显示共享状态。点击“停止共享”结束广播；切换标签不会自动停止老师的共享。

共享的是所选整个屏幕，通知、登录窗口和其他出现在屏幕上的内容也可能被看见。它是**非加密的局域网只读广播，不是私密会议**：同网段用户可以发现并观看，没有学生身份审批或点名授权。只在可信的机房网络使用，不要共享密码、个人聊天或其他秘密信息。

## 学生：发现并观看

1. 启用同一个扩展后，应用自动发现局域网中的共享；扩展页显示真实列表并自动刷新。
2. 选择老师的共享，打开独立“观看”标签。再次选择同一个共享会回到已有标签，不重复建立观看页。
3. 观看页明确标注“只读 · 无音频”。点击画面、输入文字不会向老师机器发送控制操作。
4. 切换到其他标签会暂停该观看页的画面拉取，返回后继续；关闭观看标签结束该页观看，不停止老师的广播，也不关闭其他标签。

“停止发现”只关闭列表发现，不代表停止老师的共享。再次点击“查找共享”可恢复；下次重新启用扩展或重启应用也会自动开启发现。停用扩展会结束本机共享、发现和观看；退出应用也会清理共享服务。

老师停止共享、断网或连接失效后，观看页清除旧画面并显示断开状态，不把最后一帧伪装成直播。点击“重新连接”重试；老师重新开始共享可能产生新的共享条目，应返回列表选择。

## 没有发现共享，或画面打不开

- 确认双方使用支持此扩展的新 Windows 构建，并已启用扩展；老师还需要明确点击“开始共享”。
- 确认双方在同一 IPv4 局域网网段。访客 Wi-Fi、无线客户端隔离、不同 VLAN、VPN 或组播过滤可能阻止发现；本功能不经互联网中继。
- 发现使用 UDP 组播 `239.255.72.83:47883`；画面服务使用共享启动时分配的本机 TCP 端口。请由管理员检查可信网络下的 CShell 防火墙规则。程序不会自动开放防火墙、修改路由或提升权限。
- 如果系统阻止屏幕采集，或原屏幕已拔出，停止共享、检查系统权限和显示器后重新选择。系统禁止采集的内容不能保证显示。
- 共享停止后，其他设备的列表可能需要数秒才能移除过期条目；观看请求不会因此继续获得旧广播内容。

当前画面为 JPEG 采样，服务端最多约 5 帧/秒，并缓存同一次采集结果供观看端复用；不是高帧率视频或低延迟远程桌面。清晰度、刷新与可连接人数仍受屏幕尺寸、机器负载和局域网带宽影响，不能以单机验证承诺整间机房并发性能。

## 批量部署

管理员可在新安装初始配置中启用 `cshell.classroom`。这只设置扩展开关，不自动开始共享，也不授予 CAgent 远控权限。已有用户配置不会被覆盖。安装脚本、示例配置及安全边界见 [批量安装与初始配置](DEPLOYMENT.md)。
