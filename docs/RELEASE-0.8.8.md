# 0.8.8 发布验收

本版包含 0.8.7 尚未公开的 Enter 发送、一键更新和独立自定义扩展变更（详见 RELEASE-0.8.7.md），并加入以下设置。

- 设置 → 工作区 → 默认连接视图：默认可视化；原始方式直接打开 SSH 终端或系统 RDP。CAgent、HTTP 使用自身工作区。
- SSH 会话标签栏提供可视化/终端切换；连接右键菜单提供单独的可视化入口。修改默认值不改变已有会话。
- 默认服务器名称 13 px、分组 15 px。保留已有个性设置；右键侧边栏空白处可调整名称、分组、地址字号及间距，恢复默认。Shift+F10 可在侧边栏焦点打开。
- Pro 账号云配置携带这些偏好；旧配置缺字段默认可视化。同步冲突沿用已有显式恢复流程。

验证：两分支 TypeScript 检查；旧配置默认/非法值验证；Pro 实际 Store 云导出、导入、重载保留视图与字号；浏览器组件测试覆盖原始 SSH 认证界面、右键空白菜单、字号保存、恢复默认、Escape 和独立可视化入口，截图已检查。
