# Terra 基座与系统代理

在智能体的“模型基座”添加 OpenAI API Key，模型填写 `gpt-6.1-terra`，地址填写 `https://api.openai.com/v1`。密钥加密保存，不写进外观方案。新会话选择此基座；旧会话保留原模型，切换标签不会改变运行中的任务。

## 网络出口

设置 → 网络与代理 → 跟随系统。新的本地配置默认使用系统代理/PAC；无系统代理时遵循系统直连规则。已有明确选择的直连、手动代理和机器出口不会被升级重置。手动或机器代理失败不切换到直连。机器工作区浏览器仍使用所选机器出口，其 Cookie 与缓存按机器隔离。

## 网站交互

智能体可以读取页面快照、截图、操作输入框/按钮/选择框、切换页面、读取子框架，以及在已登录的同源页面内限量抓取内容。操作遵守所选机器与浏览器读写权限。网页登录状态由该机器浏览器分区保存；截图与网页文字作为待分析数据，不作为新的操作授权。

Terra 通过 Responses API 接收截图、工具调用和工具结果。仅完整完成的模型响应可以交付工具调用；连接中断不能自动重放操作。真实网站的验证码、扫码、账号授权需要用户参与。发布、付款等操作必须遵循用户明确授权；不要把准备草稿误报为已发布。

## 本次验证边界

2026-10-29：真实 Electron 系统代理成功访问官方 Terra；模型依据真实截图与页面快照，通过 CShell MachineBrowser 的 11 次操作完成受控站点登录、跨页读取表格、保存并确认草稿。该测试不是小红书真实账号登录或发布验收，也不证明所有网站或文件上传流程都已支持。正式安装包另做加密基座读取和实际连通性测试。
