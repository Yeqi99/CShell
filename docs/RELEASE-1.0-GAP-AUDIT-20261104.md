# 1.0 需求反向审计（2026-11-04）

范围：按用户的同步、中继、MCP 长连接、可配置额度、机器网络出口与文件互传、微信统一应用、反馈、canp.site、Android 和 UI 要求反查代码。此清单区分未实现与未验收，不把历史文档中的失败当作当前状态，也不把单元测试当作生产验收。

## 已找到并修复的实质缺口

- 管理后台扩容请求原来每次提交生成新 UUID。响应丢失后重试会重复扩容。`services/admin/traffic.js` 现在将请求内容、编号与草稿保存在当前浏览器会话中，发送前持久化；相同参数跨刷新重试复用编号，变更参数才换编号。容量变更不清空草稿，刷新列表失败不会误报提交失败。
- 同步存储扩容原来只有 `/v1/admin/storage-grant` 后端接口，没有管理页面。现在“流量与成本”增加独立同步容量区，MiB、截止时间、账号和审计原因齐全，并复用幂等机制。总容量仍受后端 256 MiB 能力限制，不扩大既有权益、不写死价格。
- `node services/admin/traffic.test.mjs`：真实浏览器请求层模拟响应丢失，验证流量/同步扩容重试与刷新不重复、草稿恢复、参数改变换编号、单位/时间编码、1200/760/390 宽度无横向溢出。此处是 UI/HTTP 请求回归，不冒充生产扩容测试。

## 有实现但仍缺最终验收或部署

1. **云同步/中继/MCP**：新云数据库迁移已在复制库验证，容量协商与分块本地 HTTP/旧客户端回归有证据；最终生产 cloud-sync→relay→MCP 顺序部署、外网 HTTPS SDK 长连接、撤销/到期/跨月/中断恢复及并发负载尚需同一冻结版本验收。64 MiB 以上桌面已有真实加密 HTTP 测试，但不是低内存 Android 的最大 256 MiB 实机成功证明。
2. **Android VPN**：native 四 ABI、Java 构建、真实 JVM socket TCP/DNS/断流/租约测试通过。隔离模拟器的探针启动两次被自动审批 `blocked by policy` 拒绝；未执行系统授权/跨 UID TCP 出口/断路不直连验收。不得继续等效绕过，不把 fixture 安装当作 VPN 测试通过。具体动作见 `ANDROID-MACHINE-VPN.md`。
3. **Android 文件/远控/UI**：旧版手机画面、输入验收不能替代 1.0 新文件/代理/同步偏好最终包验证；需明确 USB 设备是否可用并记录已授予的 SAF 目录范围，不能把 Android 系统保护目录显示成全盘可访问。
4. **canp.site**：接口与受控 DNS mock/UI 测试存在；`CF_CANP_SITE_TOKEN` 未配置的证据下，没有真实受限 DNS 写入/解析验证。子域名分配与 HTTPS 网站部署是两件事，后者不应被 DNS 测试替代。
5. **微信市场**：`docs/release-evidence/wechat-1.0-candidates.json` 仍 `published:false`；0.1.3 两包已核验，不代表用户当前市场能够下载。需发布固定附件/摘要/香港来源，使用最终 CAgent 市场完成单入口→版本检测→安装→工具可见→事件生命周期验收，勿额外向联系人发消息。
6. **反馈**：桌面/原生 UI 与服务测试有证据，后端尚需实际部署；Android 构建不等于手机表单实测。匿名提交→管理员读取→重复请求只一条的生产链路需验证。
7. **Cloudflare 扩展**：旧 `CLOUDFLARE-MOBILE-FOLLOWUP.md` 仅有入口 UI，尚未记录通过 CShell 自己的 OAuth 到真实部署验收；Codex 的 CF MCP 授权不能替代应用插件授权测试。
8. **双版本发布与升级**：最终源码冻结、开源/Pro 对照移植、各平台真实附件、香港/CF 更新清单、旧客户端实际升级尚未形成一份统一最终证据。仅发布构建成功的架构，保留签名/公证及实机限制。德威云真实中继与桌面恢复以 `DEWEI-CAGENT-RECOVERY-20261104.md` 为准；安装正确 Pro 1.0 后恢复临时暂停的 autoUpdate，不能留下永久关闭。
