# CShell Pro 0.8.19

本次更新补齐账号设备发现与机器分享入口，并修复侧栏网络检测菜单。

- 左侧连接右键提供“分享机器…”，在账号工作区预选目标；支持邮箱邀请、限次分享码和自定义到期时间。借用者不获得机器密码，撤销和到期由服务端验证。
- 同账号设备可自动加入侧栏，保留用户调整的分组、名称、收藏及顺序。离线设备保留状态标记；身份或连接信息不完整时显示等待状态。
- 自动发现偏好独立随账号同步，不随外观方案导入。新同步格式写入后，旧客户端需要升级才能继续同步，避免覆盖新增字段。
- Android CAgent 增加账号登记和受控端中继、借用连接认证与撤销检查。屏幕共享、无障碍、短信和电话仍受 Android 系统权限约束。
- 全部延迟检测使用紧凑图标；自动检测菜单适配窗口边缘与缩放，打开时不再被工具提示遮挡。
- 扩展恢复先验证可携带配置，再执行安装，拒绝未声明字段时不产生安装副作用。设备权限、监听端口及微信本机账号绑定不作为普通偏好迁移。

保留已有连接、身份和凭据，普通版与 Pro 使用各自更新渠道。Windows 包未签名；macOS 包未签名、未公证，原生构建通过不等于所有实体设备验证。Android 的运营商短信、电话及指定联想设备的中继实机验证仍有既有覆盖限制，不作为本次已通过项目。
