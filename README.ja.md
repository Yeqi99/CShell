# CShell

**コンピューターとサーバーを、一つのワークスペースから管理。**

[简体中文](README.md) · [English](README.en.md) · 日本語

CShell は、端末、ファイル、リモートデスクトップ、AI との会話をマシンごとのワークスペースにまとめます。日常的なサーバー作業にも、複数のマシンを並べて監視する作業にも使えます。ビューの配置を保存し、次回も同じ構成で作業を続けられます。

[ダウンロード](https://github.com/Yeqi99/CShell/releases) · [プラットフォーム別機能](docs/PLATFORMS.md) · [不具合報告](https://github.com/Yeqi99/CShell/issues) · [MIT License](LICENSE)

## CShell と cagent の違い

| 製品 | インストール先 | 用途 |
| --- | --- | --- |
| **CShell** | 操作する側の PC またはスマートフォン | マシンへの接続、端末やファイルの操作、リモート画面の表示、AI の利用 |
| **cagent** | 管理される側のマシン | 認証済みの接続先に端末、ファイル、利用可能な機能を提供。単独で AI エージェントを実行することも可能 |

**SSH 接続には cagent は不要です。** cagent のマシン管理や対応するリモートデスクトップ機能が必要な場合に、対象マシンへインストールします。単独版 cagent は CShell、Electron、同梱ブラウザーに依存しません。Android では CShell 内の cagent 拡張を利用します。

基本的な接続に CShell アカウントは必要ありません。AI は利用者が設定したモデルサービスを使用し、推論の実行場所と料金はそのサービスに従います。

## 主な機能

- **マシンのデスクトップ**：インストール済みアプリを開き、PC ではウィンドウとタスクバー、Android ではタッチ向けの画面で操作します。アプリの管理は右クリックまたは長押しから行います。
- **マシン専用ブラウザー**：選択したマシンのネットワークで接続し、ページは操作側で描画します。タブ、履歴、ブックマーク、ログイン情報をマシンごとに分離し、切断時にローカル回線へ切り替えません。
- **開発アプリ**：アプリマーケットで Codex、Claude Code、コードエディターをインストールし、そのまま起動できます。プロジェクトとコマンドは対象マシンで実行します。公式ログインや独自モデル接続の対応はクライアントとサービスに依存します。
- **接続と端末**：SSH と cagent の接続をグループ、お気に入り、検索で管理。デスクトップ版ではタブやコンパクトウィンドウを使い、画面を切り替えてもセッションを保持します。
- **ファイル**：閲覧、転送、プレビュー。デスクトップ版では SSH 上のテキストを編集し、手動保存またはリアルタイム同期を選択できます。競合や切断時には下書きを保持します。
- **リモートデスクトップ**：対応する cagent の画面表示、キーボードとマウス操作、画質変更、ファイル転送。操作側と被操作側では対応機能が異なります。
- **保存できるビュー**：端末、リモート画面、AI 会話をタイル、主画面と副画面、プレビュー形式で配置。デスクトップ版は複数モニター、個別領域の終了、配置の復元に対応します。
- **AI による作業支援**：指定したマシンと権限の範囲でコマンド、ファイル、ツールを操作。実行記録の確認、承認、停止、イベントによる起動が可能です。
- **拡張機能**：Python 補完、Docker、HTTP、OpenCode、Tavily などを必要に応じて追加。アプリケーションカタログは選択したマシンを対象にインストールと設定を行います。

モデルの認証情報、マシンへの権限、外観設定は別々に管理します。会話や許可されたツールの結果は、選択したモデルサービスへ送信される場合があります。

## はじめに

1. [Releases](https://github.com/Yeqi99/CShell/releases) から OS とアーキテクチャに合ったパッケージを入手します。
2. SSH 接続を作成します。または対象マシンに cagent をインストールし、アドレス、ポート、パスワードを設定して、CShell から接続先の識別情報を確認します。
3. マシンのワークスペースから端末、ファイル、対応するリモートデスクトップを開きます。Android のファイル画面は端末内とリモートを切り替えられます。
4. 複数マシンを使う場合はデスクトップのビューを作成します。AI を使う前にモデルサービスとアクセス範囲を設定してください。

## 対応プラットフォーム

| プラットフォーム | CShell | cagent |
| --- | --- | --- |
| Windows x64 | デスクトップ版、`.exe` | ネイティブウィンドウ、端末、ファイル、Windows デスクトップ機能 |
| macOS Apple Silicon / Intel | デスクトップ版、`.dmg` / `.zip` | 単独ランタイムとブラウザー UI、端末、ファイル、管理 |
| Linux x64 / ARM64 | デスクトップ版、`.AppImage` / `.deb` | 単独ランタイムとブラウザー UI、端末、ファイル、管理 |
| Android | `.apk`、SSH、ファイル、cagent 接続、リモート操作 | 内蔵拡張、システムの許可による画面共有と制限付き入力 |

**すべての OS で機能が同一という意味ではありません。** Android はデスクトップ版の全マルチウィンドウ機能を提供しません。macOS / Linux cagent には、Windows と同等のネイティブ画面配信機能がまだありません。Android のロック中の画面共有、Windows のロック画面やモニターのない環境にも制約があります。[機能表](docs/PLATFORMS.md) と [Android cagent](docs/ANDROID-CAGENT.md) を参照してください。

公開済みパッケージは Releases の添付ファイルで確認してください。リリースごとの説明、`SHA256SUMS.txt`、署名・公証・実機検証の状況も確認できます。

## アプリの対応範囲

cagent と開発アプリは専用ディレクトリへインストールし、システムの Node/Python、ソフトウェア配布元、グローバル PATH を変更しません。通常のシステムパッケージは別途インストール計画を表示します。

コードエディターは code-server を利用し、Linux/macOS x64・ARM64 の独立パッケージに対応します。Windows ネイティブの自動インストールは提供せず、必要に応じて実際の WSL 環境へ接続します。Microsoft 公式 VS Code クライアントではありません。Android は遠隔操作側であり、スマートフォン自体に開発 CLI をインストールしません。

Android ブラウザーにはプロキシと独立 Profile に対応した System WebView が必要です。Web ダウンロードは未対応のため、転送にはファイルアプリを使用します。モバイルの WebRTC と Service Worker の通信には制限があります。埋め込みブラウザーのログイン可否はサービス側が判断します。iOS 版は未公開で、任意の Linux GUI アプリの動作も保証しません。

## 開発とメンテナンス

Node.js 24 と `package.json` で指定した pnpm を使用します。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm start
pnpm test
```

デスクトップのパッケージは `pnpm run dist`、単独版 cagent は `node scripts/agent-build.mjs` でビルドします。ネイティブ部品は対応する OS とアーキテクチャが必要です。Android には JDK、Gradle、Android SDK も必要です。
