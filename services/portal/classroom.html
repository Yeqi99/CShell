也适合小规模内网运维

对已经配对的机器统一更新模型配置、设置 CAgent 私有环境变量或运行维护脚本。先看计划，再确认执行；某台机器失败不自动重试，未确定的操作显示“结果未知”。

教师端内置 CPU 版 Python 教学环境模板：先预检，再确认安装 Anaconda、VS Code 与 PyTorch。每台机器至少需要 20 GiB 可用空间，环境放在独立目录。代理可随需要设置或清除，仅影响 CAgent 后续启动且支持代理环境变量的程序；也可只为一次安装指定临时代理。

安装前，了解范围与网络要求

初始密码仅用于部署。新安装默认密码为 123456，请在投入日常使用前修改。只在可信机房网络部署，不将 CAgent 端口暴露到公网。已有安装仍使用原来的端口、密码、身份和权限。

屏幕共享是局域网只读广播。老师需要明确点击开始；仅传画面，无音频、鼠标或键盘控制。它不是加密私密会议，请先关闭秘密内容。启用扩展或安装套件不会自动开始共享。

网络与系统权限仍然有效。双方需要可互通的局域网；无线隔离、不同网段和防火墙可能影响发现与连接。不会自动开放防火墙、绕过 UAC 或替安装器补上不存在的静默参数。

验收范围。机房专用套件保留 0.8.11；常规客户端最新版本请查看下载中心，两者分别验证和发布。Python 教学环境已通过模板、预检和界面检查，但尚未完成真实机器上的完整安装验真。已做的隔离测试不能替代真实机房、多学生并发及各校网络环境验收；部署前请先选少量机器验证。
