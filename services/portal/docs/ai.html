智能体、模型与记忆

安装 CAgent 后直接提问

打开 Windows 版 CAgent，在输入框写下任务即可使用体验基座，无需登录或填写 API Key。输入框下方显示「体验基座」，切换到自配基座后显示所选名称。可以先问「这台电脑有多少可用磁盘空间」，再让它把结果保存到你指定的文件。会话中的问题及完成任务所需的工具结果会发送给在线模型服务。

所有安装共享每天 1,000 万 Token，每台电脑每天最多使用其中 100 万，按北京时间零点重置。输入和输出都计入额度。额度不足时，会话会提示到「模型与权限」配置自己的大模型基座。已配置的自有基座沿用原设置。

用机器知识库备课

打开课程实验机的 CAgent 应用市场，安装「机器知识库」并保存读取权限。需要智能体整理新材料时，再授予写入权限。读取授权覆盖整台机器上的所有库。学生可以访问的机器只放可向学生公开的材料。

  1. 添加实验记录。库名填「课程」，分类填「MySQL」，标题填「比较索引前后的执行计划」。将查询语句和两次 EXPLAIN 的结果存为文本，来源填讲义章节。
  2. 打开绑定这台机器的智能体会话，让它在「课程 / MySQL」检索「执行计划」，读回原文并引用讲义中的观察结果。
  3. 把核对过的操作保存为步骤记录。Linux、Python 和 Java 可各设一个分类。

智能体用 knowledge_search 查找片段，再用返回的库名、分类和 ID 调用 knowledge_get 读全文。写入工具 knowledge_put 接受文本、JSON 字符串和包含 steps、outcome 的步骤记录。单条正文上限为 64,000 个 UTF-16 代码单元。PDF、课件和图片需要先提取正文。

配置基座

自定义服务可在模型配置中填写地址、模型名称和密钥。OpenCode 则只需在扩展中添加一次账号，随后从输入区的「AI 基座与模型 → OpenCode」二级菜单直接选择模型，不必逐个建立基座。密钥独立加密保存，不进入外观方案。发送前核对当前会话模型与实际目标。

OpenCode 模型与实时状态

模型菜单打开、应用回到前台或云端恢复账号后刷新目录。目录下架和实际调用拒绝会反映到基座设置；临时断网显示未知状态，保留账号和历史。不会因排序变化或失败自动换模型，也不会自动选择付费模型。

桌面端通过私有官方 OpenCode 运行时调用；工具仍由 CShell 按原权限和审核执行。现有账号实测的三个免费模型仍返回服务端 403，原生官方命令行也复现；账号认证成功不代表这些模型可生成。详见拒绝原因与排查。

授权与执行

按应用能力和机器范围授权。审核策略只决定已授权操作是否逐次询问，不会自动扩大机器范围。安装扩展或应用也不代表授予智能体调用权限。查看工具执行记录，可在当前任务中停止执行。

账号习惯记忆

Pro 账号习惯记忆保存长期偏好，并随账号同步。进入账号记忆查看、编辑或删除条目；智能体在授权范围内可以读取和修改。适合保存回复语言、常用工作习惯等，不应保存密码、令牌或私钥。记忆中的指令不能替代权限配置，也不能扩大设备访问范围。

会员模型：本周还可以用多少？

在对话框点额度图标，可看本周剩余百分比和下次刷新时间。Pro 的 100% 对应 5 元模型调用成本；每周一北京时间 00:00 刷新。同一账号在不同会员模型上的调用合计扣减，不会因供应商充值或会员人数变化而重新分配余额。个人密钥调用不占这份额度。

例如本周已消耗 1 元，剩余 80%。模型旁的低、中、高是相对消耗提示；两次请求即使使用同一模型，也可能因为输入、输出和缓存用量不同而产生不同成本。需要提前补满时，可使用 588 点将本周额度恢复为 100%。

官方模型

Pro 提供自建 Qwen3 8B 与 Qwen3.5 4B 视觉服务，通过账号网关调用，客户端不保存服务端原始密钥。登录后在模型入口选择实际可用模型，额度以账号状态为准。小模型的推理和工具选择能力有限，重要结果应对照工具记录确认。

长对话什么时候会压缩？

桌面智能体和 CAgent 根据当前模型的上下文窗口决定可保留多少历史。输入还要为工具、图片和下一次回复留出空间。切换到较小的模型时，长对话可能提前压缩。会员额度按实际调用结算，上下文估算仅用于准备请求。

会话并行与恢复

新建会话不会停止原会话任务。历史列表可找回会话，切换时保留各自输入草稿；重启恢复已有记录，不自动重放状态不明的操作。停止按钮只停止当前对应任务。

模型与真实操作

官方模型查询机器信息时使用真实工具结果。模型仍可能判断错误，工具权限与目标范围由程序核验。查询失败会报告实际原因，不把未知权限节点当作真实授权。

第一次让智能体操作机器

  1. 打开智能体面板，为自定义服务配置地址、模型 ID 和 Key，或从 OpenCode 账号下直接选择模型；需要检测时明确选择模型再发起测试。
  2. 选择当前会话实际使用的模型。一个会话的模型和运行目标不会因你切到其他标签而改变。
  3. 进入访问权限，选择需要使用的应用能力与机器范围，保存。
  4. 先试一个可核对的只读任务，如“查看开发机磁盘剩余空间”。
  5. 展开工具记录，检查目标、操作和结果。出现授权请求时看清参数，再允许或拒绝。

对话回复不等于已经执行。没有工具成功记录时，不应认为文件已经修改、软件已经安装或连接已经建立。

全部勾选与三种审核策略

全新安装默认选择当前已实现的应用能力、全部机器与机器操作。升级保留已有选择；旧配置缺失或损坏不扩大权限。目标端认证、权限和未安装能力仍分别核验。MCP 服务默认关闭，审核策略独立设置。

访问权限支持全部选择、全部清除及分区选择。它们先修改草稿，保存后生效。应用能力、允许的机器和单机覆盖共同决定工具可执行范围。

  • 全提示：已授权操作仍按策略请求审核。
  • 限制执行：按限制策略审查操作。
  • 全放行：不逐次审核已授权操作，但不扩大机器或工具权限。

远端 CAgent 还会执行自己的设备授权；CShell 勾选全部不覆盖目标机器明确关闭的权限。Pro 同步策略时保留范围和覆盖，发生冲突需要选择，不自动取最大权限。

新建、切换、找回与停止会话

  1. 用新建入口开一个独立会话，原会话正在执行的任务继续运行。
  2. 从历史入口找回旧会话；每个会话保留自己的消息与输入草稿。
  3. 发送前核对该会话模型和实际操作目标，不依据当前左侧高亮机器猜测。
  4. 停止按钮作用于当前会话真实任务。停止后查看已完成工具记录，部分已执行操作不能自动撤销。

应用重新打开可恢复历史，但状态不明的工具操作不会自动重放，避免重复写文件或安装。退出应用与仅切换会话不同，有运行任务时先查看退出提示。

让小模型更容易完成任务

一次给出一个可验证目标，说明机器、路径和禁止修改的内容。例如：“在测试机读取 /var/log 下最近的错误摘要，只读，不删除文件。”先让模型获取实际信息，再决定后续动作，比要求“帮我优化整台服务器”更可靠。

如果模型连续调用不存在的权限节点或重复失败，停止当前任务，检查工具记录与配置，再把任务缩小。提示词不能替代正确的工具实现、模型能力或实际权限。

发送与换行

输入后按 Enter 发送，Shift+Enter 换行；Ctrl+Enter 也可发送。中文输入法选字时不会误发送。此规则覆盖主智能体、机器智能体、编程应用和 CAgent；终端快捷键仍按终端设置处理。

0.8.10：模型菜单的键盘操作

模型菜单补齐键盘焦点、没有搜索结果时的提示，以及窄面板中的定位。选择模型仍以当前账号和目录为准，不因异步刷新自动选择其他模型。OpenCode 扩展中的默认值按钮明确命名为「设为默认模型」，与实际检测模型是否能调用分开。

新会话使用所选模型，运行中的会话不因菜单刷新或默认值变化而更换模型。服务端拒绝的模型不会因按钮改名恢复可用，也不会自动改用付费模型。

验证 DeepSeek 等模型是否真正可用

0.8.16 候选补充模型协议兼容处理。配置服务地址、模型名称与 Key 后，先核对本次会话实际使用的模型和网络出口，再发送一个短请求。目录列出模型或 Key 校验通过，不代表实际生成、工具调用和多轮续聊都成功。

遇到拒绝时保留服务端错误，分别排查模型名称、额度、服务区域和工具协议。不会为完成请求而自动换成付费模型、扩大工具权限或悄悄从选定代理退回直连。正式包的兼容范围以对应版本验收记录为准。

换电脑后模型无法连接

先在设置的“网络与代理”确认这台电脑实际使用的出口。新设备默认跟随系统代理；如果已明确选择直连或某个机器出口，云同步不会覆盖该选择。系统代理地址属于当前设备环境，不应从另一台电脑照搬。

选择当前会话真实模型，发送简短请求核验。密钥有效与实际生成成功是两件事；失败时查看统一诊断中的连接或服务端错误，不要反复导入覆盖密钥。
