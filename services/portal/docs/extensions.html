使用扩展与应用市场

这两个市场解决不同问题：扩展增加工作台能力；应用安装到你选定的真实机器上。

扩展

从扩展市场搜索、安装和启用需要的插件。Vim、Nano、Shell 联想、Docker、Conda、Python 等按各自支持范围工作。插件的专属设置和视图从已启用插件条目进入。停用插件不应关闭已有普通终端；卸载插件不会卸载服务器的软件。

第三方声明式命令包只提供候选命令，选中后仍需审阅并执行。不要把插件发布者的文字名称当作身份认证。

导入自定义扩展

打开扩展页面，点击“导入扩展”，或把一个 .cshellext 文件拖入页面。先查看名称、版本、来源与权限，再确认导入。包会出现在“自定义扩展”筛选中，默认停用，由你单独启用。

私有扩展不出现在公开市场。导入不会自动执行命令或授予机器访问权限。更新之前先停用；首次加载带独立运行时的签名包，需要重新打开应用。取消预览不会安装。

普通自定义包支持声明式命令，不接受任意脚本运行。制作方法见 本地扩展文件格式。

应用

  1. 先选择要安装的目标机器。
  2. 检查真实包管理器、系统与已有依赖。
  3. 阅读安装计划、目录和权限影响。
  4. 确认后执行，在所属工作区查看进度和失败原因。

安装任务使用独立通道，不向当前终端注入命令。不自动提权或添加软件源；停止任务不保证已经安装的文件被回滚。

CAgent 能力包

能力包将已安装的软件包装成可授权的工具。系统安装、配置、版本核验和工具授权分别检查，只有全部满足才显示可用。

准备接入自己的功能？先阅读开发者接入路线。

常用扩展怎么选

扩展适用任务使用前检查
Vim / Nano终端编辑器紧凑操作面板当前确为编辑器，手动回退识别不会向普通 Shell 盲发按键
Shell 联想补全常用命令只补全不执行，密码与全屏场景不提供普通候选
Docker当前机器的容器管理真实 Socket 与授权，删除和端口重建需确认
Python / Conda解释器与环境工作流选择真实环境，缺依赖时查看安装计划
WSLWindows 上的 Linux 发行版只列实际检测到的发行版，网络变更不自动重启全部任务
HTTP请求集合与多发送方先启用扩展，再选择真实支持的发送环境
OpenCode账号模型目录与智能体基座模型可列出不代表账号可以推理，见专门排查页

安装不等于可用，停用不等于卸载系统软件

插件安装、启用、配置和授权是不同状态。CAgent 应用还需要配套软件、版本核验与工具注册。界面显示未配置或不可用时，按详情补齐条件，不仅重复点击安装。

应用安装绑定目标机器，通过独立通道执行，不占用正在编辑或运行任务的终端。不隐式替换系统依赖。取消只能停止后续工作，已发生的安装变化应按实际日志处理。
