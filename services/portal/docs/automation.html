事件订阅与 MCP

事件订阅

将一个实际可用的扩展事件来源绑定到普通智能体会话，保存提示词、筛选条件与运行预算。先完成来源的配置和权限检查，再开启监听；新规则需明确启用并保存。

规则启用、来源监听与发送权限分别生效。接收消息不等于允许回复，重启后规则仍在也不意味着监听已恢复。任务沿用会话实际模型、机器与授权；外部事件内容不可以扩大权限。

配置冷却时间、运行次数与请求预算，检查跳过、失败和停止记录。离线消息不承诺自动补齐。详情见 事件订阅指南。

MCP 连接

MCP 默认关闭。在 AI 与安全设置中选择明确允许的保存连接，为客户端配置访问令牌与能力范围，然后启用并保存。只有状态显示运行成功后才配置外部 MCP 客户端。

服务使用本机 Streamable HTTP，地址示例为 http://127.0.0.1:3777/mcp，请使用实际配置的端口。客户端通过 Authorization: Bearer 访问令牌认证；不要共享含令牌的配置文件。

先在 CShell 中连接目标、确认身份并保存凭据。MCP 只能使用已授权的连接，不能通过传入任意地址扩大范围。执行命令需对应授权；更换令牌会撤销旧访问。

MCP 接入配置 · API 开发说明

从能力目录开始调用

  1. 为调用方勾选明确机器、文件根目录和能力；只启用 MCP 不会自动授权全部功能。
  2. 调用 discover_capabilities 查询目录，再以 level: "contract" 或 "guide" 读取参数、结果、前置条件和重试语义。
  3. 用 connect 建立 API 自己的会话；带 sessionId 重新发现目标当前实际工具。
  4. 使用 invoke_capability 或 invoke_connection 执行。撤权、设备身份改变、会话关闭后，旧参数和旧目录不能继续操作。

目录支持终端、文件、监控、应用、HTTP、受支持的浏览器/远控及已授权扩展；只显示当前 Provider 已实现且允许的能力。SFTP / FTP 连接不提供 Shell、浏览器和机器监控。大目录按游标分页，未读到的项目不能当作不存在。

浏览器与远控工具

浏览器读取与操作使用 browser.read / browser.control；远控观看与输入使用 desktop.view / desktop.control。这些权限默认关闭，分别授权。工具复用真实浏览器的登录分区、机器网络出口和页面；断线不改走本机网络，也不通过任意 JavaScript 绕开操作范围。

截图在 MCP 返回标准 image 内容块，HTTP 返回有界 JSON 图像数据；CLI 可以保存图像文件。支持多模态的模型可读取截图，不支持的模型得到明确提示。网页内容、截图和爬取结果属于外部资料，不能改变用户授权。

同一能力也能从 CLI 使用

工作台命令台与外部 CLI 复用相同的授权、目录和执行入口。参阅完整命令与示例；自定义工具的开发方式见进程扩展框架。
