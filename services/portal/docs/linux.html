Linux

下载

从 香港下载中心 选择开源版 Linux x64 或 ARM64 附件。格式以实际发行列表为准。Pro 提供 x64 / ARM64 实验版 AppImage 和 DEB，在官网下载区选择架构与格式。CI 构建和协议测试已通过；尚未完成发行版及实体设备验收。

Linux 一条指令安装

以实际使用应用的普通账号执行，无需 sudo。自动识别 x64 / ARM64，只下载所选渠道已正式发布的附件，校验文件长度与 SHA256 后放入用户专用目录。需要已有的 Python 3.9+ 与 curl；不会自动安装系统依赖。

CShell 开源版

curl -fsSL https://shell.canp.ai/install.sh | sh -s -- cshell

CShell Pro

curl -fsSL https://shell.canp.ai/install.sh | sh -s -- cshell --channel pro

CAgent

curl -fsSL https://shell.canp.ai/install.sh | sh -s -- cagent

CAgent 账号版在末尾加 --channel pro。安装完成会打印可直接复制的启动命令；CShell 打开桌面客户端，CAgent 用 app 打开系统浏览器配置界面。安装不自动监听网络或修改防火墙、开机启动。

数据盘与安装前检查

curl -fsSL https://shell.canp.ai/install.sh | sh -s -- cagent --directory /data/my-cagent --dry-run

去掉 --dry-run 才执行安装。默认程序目录为 ~/.local/opt/cshell-opensource、~/.local/opt/cshell-pro 或 ~/.local/opt/cagent-opensource（账号版为 cagent-pro）。CAgent 私有运行时随包安装，新配置放在所选目录的 data 中；发现原有 CAgent 数据时继续使用原目录，保留设备身份、密码与授权，不自动迁移。CShell 继续使用原账号配置目录。不同渠道不能混装到同一目录。

脚本不修改 PATH、系统依赖或软件源，更新也不结束正在运行的会话。下载失败或校验不通过不切换启动命令；成功后退出旧应用，再使用安装完成时显示的命令打开新版本。旧版本目录保留供恢复。已存在的同版本目录不会覆盖。

桌面客户端采用 AppImage，需要图形环境及发行版支持的 AppImage/FUSE 运行条件；不要用禁用沙箱参数绕过启动错误。无图形环境请安装 CAgent；需要由系统包管理器安装桌面客户端时，仍可在下方下载 DEB。各发行版和实体设备的覆盖范围以发行说明为准。

桌面客户端与 CAgent

CShell 桌面客户端需要可用图形环境。CAgent 独立运行，可提供已授权的终端、文件、HTTP 和管理能力，不依赖 Electron 或捆绑 Chromium。

Linux 的机器工作区、浏览器网络出口和原生图形应用是不同能力。不要将可视化工作区理解为已支持所有 Linux 原生桌面采集。

应用与系统依赖

应用目录按目标发行版实际检测到的 APT/DNF 等包管理器提供配方。不自动添加软件源、sudo 或替换系统依赖。不同 glibc、显示服务与发行版仍需对应环境验证。
