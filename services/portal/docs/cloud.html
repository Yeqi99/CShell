账号、云同步与会员

注册与登录

在主页右上角进入账号页。邮箱验证码用于注册，也可使用固定密码登录。登录后自动同步，无需手动启动同步。

第一次登录：选择要载入的配置

检测到开源版配置或 Pro 未登录数据时，会分别显示来源与条目概况。查看后确认才载入；不会自动上传旧数据。重复连接和模型由你选择保留当前内容或使用来源内容。旧工作区的访问授权不随本机导入迁移。

设置 → 账号与云同步 → 本机配置，可以再次载入来源，或清除未登录缓存。清除前会列明范围并要求确认；账号云端数据、开源版原文件和设备身份不会删除。切换账号分别使用独立工作区。

自动同步的内容

连接与加密凭据、模型基座、OpenCode 账号、扩展设置、视图和偏好、支持的浏览器历史与收藏、习惯记忆，以及 CShell 智能体访问策略随账号同步。权限保留机器范围与单机覆盖；多端同时更改策略会要求处理冲突，不自动合并为更大授权。

CAgent 自身远程访问授权、设备身份、运行中进程、终端输出、远端文件和浏览器 Cookie 不作为通用配置恢复。Android 保留暂不使用的加密云字段，避免手机保存覆盖桌面扩展配置。

同账号设备（0.8.19）

  1. 在目标机器的 CAgent 登录同一账号并启用服务；Android 还需开启 CAgent 的账号设备发现。
  2. 在电脑的“我的账号 → 同账号设备”打开“自动发现设备”。
  3. 新设备会加入左侧默认分组，显示账号设备标记；可以拖动到任意分组，之后刷新不会移回。

自动发现选择随账号同步。离线设备保留并标记离线；等待加密连接信息时会说明状态，不冒充连接成功。会员可以使用中继连接，无需公网 IP，仍验证目标身份与权限。

手机需要启动 CAgent 服务。观看与控制手机还分别需要系统录屏和无障碍授权；登录账号不会代替这两项授权。

应用网络出口

设置 → 网络与代理，可选直连、手动 HTTP/HTTPS/SOCKS5 代理，或会员账号中的机器作为出口。例如选择美国机器后，受支持的模型 API 请求通过该机器访问。出口不可用时请求失败，不回退本机网络。

CAgent 机器内也可选择另一台同账号机器作为受支持应用的出口。新终端中的程序需支持 ALL_PROXY；已有终端不会自动改环境。此功能不接管全机流量、UDP 或第三方应用的独立网络实现。

0.8.10：排序与扩展账号同步

本节对应已发布的 0.8.10 补丁。补丁修复按 ID 合并配置时顺序丢失的问题，保留连接等有序列表的排列；Android 保存账号配置时保留手机暂不支持的 FTP / SFTP 连接位置与未知字段，不将它们转换成 SSH。

Tavily 账号及 Key 纳入加密云同步和确认后的本机导入。是否允许按量付费、扩展安装状态和运行授权仍由本机管理，不随账号复制。没有配置过 Tavily 时不增加空字段；明确删除最后一个账号后记录空列表，避免其他设备把已删账号恢复。旧云数据缺少该字段时保留本机内容，失败回滚恢复原状态。

新增同步内容与旧客户端

0.8.10 新增可选的 Tavily 与机器桌面外观加密段。账号写入新段后，应使用支持它的新版桌面客户端；0.8.9 会安全拒绝不认识的段，不会为兼容而清空云端。没有新段的账号继续按已有格式同步。

机器桌面的背景、主题、命名方案与对应图片纳入加密同步；窗口位置、临时运行状态和原生桌面会话不会作为外观恢复。最终范围见本页和版本验收记录，不把同步外观当作复制设备权限。

分享或借用机器（0.8.19）

  1. 在左侧机器上右键，选择“分享机器…”。当前机器会预选，也可在“我的账号 → 机器借用”批量选择。
  2. 选择“指定邮箱”或“分享码”，设置有效期；分享码还可限制兑换人数。有效期可选择常用时长或自定义日期时间。
  3. 接收方打开自己的“我的账号 → 机器借用”，接受邮箱邀请，或粘贴分享码加入连接。

只可分享自己账号登记的 CAgent 机器。普通 SSH / RDP 连接需先在目标机器安装并登录 CAgent；不会直接把保存的密码交给别人。

到期后不能兑换或继续连接。撤销后已有委派连接也会失效，对方不能重新分享或更改所有权。实际连接需要机器在线、出借账号具有有效中继权益，以及目标机器开放所需操作。

CAgent 使用同账号模型

CAgent 登录相同账号后恢复云端模型与 OpenCode 账号，并在模型菜单选择。模型凭据按目标设备的存储上下文重新加密；同步模型不会重置该机器主动关闭的远程权限。服务端拒绝、额度不足和地区限制会显示实际原因，不把目录中的模型当作已经调用成功。

内置插件的启用选择与可同步偏好跟随账号；外部插件二进制、系统代理开关、设备身份和本机服务端口仍属于当前设备。新配置格式要求旧客户端升级后再同步，避免覆盖新增字段。

换电脑后恢复扩展与设置

账号保存内置插件选择、外部扩展的来源与版本及既有命令配置。CAgent 能力包恢复选择、精确版本和清单摘要，不复制任意配置。CAgent 的账号外观修改也会回写云端；不同账号各自保留设置。

可信目录中存在匹配能力包时，CAgent 下载并核验安装；本机缺少匹配外部扩展时，插件市场显示「待恢复」。展开可查看名称、版本和原因，通过选择安装包进入预览。已安装同名旧版本不等于恢复完成，运行授权仍单独管理。

卸载或停用的选择会记住，不因旧恢复记录重新出现。令牌、设备身份、监听端口、本机路径和运行进程不作为通用扩展配置复制。新同步内容写入后，不认识该格式的旧客户端会提示升级并保留云数据。

能力包设置的同步范围

CAgent 能力包当前恢复安装选择、精确版本与清单摘要。portableConfiguration 是适配器可选的非敏感配置白名单契约，目前生产适配器尚未声明，不能称全部扩展配置已同步。既有 CShell 命令配置按原有字段恢复；微信本机监听、进程与账号绑定、联系人收发范围和操作授权不迁移。
