CShell Pro 1.1.1 使用说明

账号与奖励

在账号点数区打开「邀请好友与礼品卡」可以生成个人二维码海报。新用户扫码后使用邮箱验证码和密码注册，邀请关系随注册写入，同一用户只有一个邀请人。平台确认充值订单后按实充点数的 5% 奖励邀请人，零散不足一个点的部分跨订单累计。后台手工调账、礼品卡和邀请奖励本身均不触发分成。

后台「点数与礼品卡」可以登记已经支付的充值订单，查看包含来源编号的最近 500 条点数流水。支付系统可在受保护的服务端向 POST /v1/admin/settled-recharges 提交 account、order 和整数 points。订单号全局唯一，重复提交通知只入账一次。点击流水的「溯源」可按先进先出查看该次支出使用的每一笔入账及点数，邀请奖励可回查原充值订单。对账时以支付平台的已结算订单为准。

管理员按点数、会员套餐天数或一次周额度重置生成礼品卡，点击「查看并保存礼品卡图片」下载 PNG。收件人可扫码后登录或注册，也可以在账号输入兑换码。每张卡只有一个领取账号。会员卡在同一套餐原到期日上顺延。重置卡在会员已有周消耗且请求结算完毕时使用。

后台「账号与会员」设置套餐权益，「点数与礼品卡」设置天数和点数售价。管理员上架后，用户在网页账号中购买。管理员应核对新增套餐的权益和售价。

域名与端口

在会员域名中先认领主域名，再增购或续费其他二级域名。每个额外域名每 30 天收费 1,000 点，到期未续会清除该额外域名的解析。新租机器含 3 个业务端口，CAgent 连接端口单列。已有 10 端口订单保留原配置。增加一个业务端口按每 30 天 200 点随剩余租期折算，支付前显示本次报价。

智能体、数据库与移动端

Windows Pro 在新建 CAgent 连接的安装入口提供随包安装器。在已启用的 CAgent 扩展中打开本机 CAgent。智能体绑定本机终端后，可按已有权限查询桌面状态、截图和输入，实际操作通过本机 CAgent 执行。受控端保留已有身份与授权。Linux CAgent 的 MySQL、Redis、Milvus 使用专用目录原生安装，应用市场允许配置端口。安卓 CAgent 在用户启用管理连接期间持有后台 CPU 唤醒锁，系统重新创建服务时只恢复管理连接。正在授权的投屏可供再次连接，投屏授权已终止时需在手机确认新会话。手机长消息 Markdown 在独立打包的 Worker 里解析。

在管理后台「会员模型号池 → 明杰 AIOPEN」保存 API Key 并查看供应商额度。Key 不限额时，实际可用金额取决于上游账号余额。
