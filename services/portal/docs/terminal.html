终端、复制粘贴与文件

打开正确环境的终端

默认双击 SSH 连接进入原生终端；也可从连接右键打开可视化，或为这台机器记住可视化打开方式。可视化中的终端和文件仍使用当前真实连接。本机 Windows 可选 CMD / PowerShell；WSL 从已启用扩展选择真实安装的发行版。连接断开时，保留的输出是历史，不代表命令仍可执行。

切换工作区保留终端与滚动历史；关闭终端和切换标签不同，关闭前确认前台任务是否仍在运行。极简视图和独立小窗复用会话，可从还原入口回到工作台。

可视化与原始 SSH 使用同一终端

SSH 桌面里的终端由本机 xterm 渲染，通过原来的 SSH PTY 收发输入与输出。切回原始连接视图时复用同一会话、终端历史和输入状态，不启动第二条 SSH 连接，也不以远端截图传输普通终端。

从 0.8.9 起，隐藏终端保留输出历史，但停止额外的提示符与链接着色工作；文件窗口关闭、最小化或不在前台时暂停监控。拖动和缩放窗口按显示帧合并调整，结束后保存位置，减少多会话下的界面负载。

SSH 输入仍由远端真实回显，不用本地假回显掩盖连接延迟。若只有某台机器输入迟缓，可在网络延迟测试中检查本机到该机器的往返时间。

Ctrl+C 复制、Ctrl+V 粘贴，同时保留 Linux 按键

默认剪贴板模式下，选中文字后按 Ctrl+C 复制，Ctrl+V 粘贴；未选择文字的 Ctrl+C 不发送中断。Ctrl+Shift+C / Ctrl+Shift+V 仍可用于复制粘贴。

  1. 需要停止运行中的命令时，展开终端快捷键栏，点击「中断 · Ctrl+C」。
  2. 栏中也有挂起 Ctrl+Z、结束输入 Ctrl+D、原生 Ctrl+V 和 Esc，操作只发送给当前有效终端。
  3. 需要完全遵循 Shell / Vim 按键时勾选「原生按键」；要长期采用原生行为，在终端偏好中关闭剪贴板快捷键。

粘贴多行命令可能由远端 Shell 按换行处理。先检查文本再粘贴，尤其不要把解释性文字或密码粘入正在运行的程序。

字号、配色、链接与命令候选

在外观设置调整终端字体、字号和明暗配色，和界面字体分开设置。终端也支持 Ctrl+Shift+= 放大、Ctrl+Shift+- 缩小、Ctrl+Shift+0 还原。

终端保留远端 ANSI 颜色，并提供受支持内容的视觉强调。程序本身的全屏绘制与颜色仍由程序决定，不会把所有输出重新解释成语法代码。链接打开前应确认地址。

启用 Shell 联想扩展后，候选仅补全输入，不自动回车。密码输入和全屏程序不应出现普通 Shell 候选。Vim / Nano 操作面板依赖有效编辑器状态，不能仅凭日志里出现编辑器名称就执行操作。

上传、下载与编辑文件

  1. 在目标机器桌面打开「文件」，核对当前目录与机器名称。
  2. 选择文件后使用带悬浮说明的上传、下载、复制、粘贴等工具。目标目录必须在当前账号可访问的范围内。
  3. 遇到同名文件先处理覆盖冲突；查看所属操作的进度与错误，不把开始传输视为完成。
  4. 编辑内容保存前核对目标路径。断开、权限不足或文件变化时，先保留草稿再处理错误。

CShell Pro 云同步保存配置，不会把远端文件作为网盘上传。删除、安装和传输的目标都是当前机器；把文件拖回原目录不应产生一次新的移动。

终端不响应或显示异常

  • 有历史输出但无法输入：检查连接状态和是否处于仅观察模式。
  • Ctrl+C 没有停命令：检查剪贴板模式，使用快捷键栏的中断按钮。
  • 中文错位：选择支持中文的等宽字体，检查字号和远端编码。
  • 安装日志提到 Vim 却未打开工具条：这是正常的，工具条只应服务实际编辑器。
  • 文件操作被拒绝：检查目标路径和远端权限，不以切换界面绕过授权。

0.8.10：SSH 文件区与智能体共存

补丁修复打开智能体后 SSH 右侧文件与机器信息被强制隐藏的问题。关闭或收起文件区后可从所属终端恢复；窄工作区中保留可发现入口，不必关闭智能体才能找回文件。原生与可视化继续使用同一 SSH PTY，切换保留终端历史与文件草稿。

SSH 通过实际 SSH 连接传输，不绕行 CAgent。界面回显与远端网络往返是不同环节；本轮本地渲染基准不能证明某台用户机器的网络延迟已消除。遇到远端回显慢，可先查看网络出口与延迟测试。

0.8.10：SSH 输入响应

原生终端与可视化终端继续使用直连 SSH PTY。连接建立后禁用 TCP Nagle 小包合并等待，让键盘输入及时发送；不会转为 CAgent 中转。

真实 Pro 0.8.10 安装包的本地 DOM 测量：原生 SSH p95 为 20.7 ms，可视化为 19.7 ms；切换保留同一 PTY，观测没有长任务。这不是网络往返或物理屏幕端到端时延，不能据此认定用户网络延迟已经解决。

文件大小、传输进度与速率

0.8.16 将文件大小统一为 KiB、MiB、GiB。例如 140,000,000 字节显示为 133.5 MiB，不再使用“亿 B”。SSH / SFTP 文件区、FTP 文件连接和 CAgent 文件应用采用相同单位。

  1. 在目标文件区选择上传、下载或复制；SSH 有新任务时自动展开所属传输队列。
  2. 查看“已传 / 总量 · 百分比 · 平均速度”。速度来自实际传输字节与操作开始后的时间，不是 Ping，也不包含排队时间。
  3. 目录或批量总量尚未确定时只显示已传字节。数据发送完后还要等待文件提交成功，完成之前不会显示 100%。
  4. 需要中止时点击该任务的取消入口；取消、失败和完成后不继续显示运行中的速率。检查错误后再重试，不把开始传输当成成功。

CAgent 下载使用后台分块写入事件，上传按远端确认位置更新进度。FTP 仅提供已实现的文件操作，不承诺递归目录上传或下载。云同步不传输这些文件。SSH / SFTP 已通过实际 16 MiB 上传、下载摘要一致与断连取消验证；高延迟线路下载吞吐仍可能有限，不保证固定速度。

在文件区修改 Linux 权限

  1. 连接 SSH 或 SFTP，在文件列表选中一个文件或目录，右键选择“文件权限”。
  2. 查看当前模式、UID 和 GID，按所有者、组、其他用户调整读、写、执行位。
  3. 保存后等待服务器读回结果。只修改当前所选项，不递归影响子目录；保留原特殊权限位。

服务器必须允许读取句柄及修改权限。遇到权限不足、服务器不支持或读取后权限已变化，面板会报错，不自动 sudo、放大权限或改用不安全的备用操作。符号链接不提供此操作。FTP / FTPS、CAgent 与 Windows ACL 暂无等价编辑入口；这与 MCP 的能力授权是两回事。
