机器信息与磁盘诊断

查看当前机器，而不是本机

在已连接的 CAgent 机器桌面打开「机器信息」。顶部显示目标主机名、系统、架构和系统版本，先核对目标再解读数据。仅 SSH 的机器需使用其支持的监控功能，不能把 CAgent 专属字段当成已提供。

面板活动时约每 4 秒继续采样；刷新按钮发起新读取。断开后明确显示最后采集数据，采集失败会显示原因。首次采样尚不能计算 CPU 差值或网络速度，等待下一次采样即可。

处理器与历史曲线

概览显示逻辑核心数、型号、总负载与内存已用 / 总量。处理器页进一步提供每核占用、频率，以及系统能提供的用户态、内核态、IO 等待、1 / 5 / 15 分钟负载均值和温度。

CPU 百分比由连续计数差值计算。曲线保留最近采样，不是开机以来完整记录。负载均值不等于百分比；温度、IO 等待等未提供时不会伪造为 0。

内存、交换区与进程

内存页显示可用、空闲、缓存、缓冲及交换区总量和空闲量，并列出系统提供的进程内存排行。缓存可被系统回收，可用内存与完全空闲内存不是一个概念。

进程细节受系统工具和当前权限影响；查看信息不会自动授权结束进程。不要只因缓存占用高就判断内存不足。

磁盘容量与大文件扫描

磁盘页提供文件系统容量和连续采样得到的磁盘吞吐。使用「大文件扫描」时指定实际目标路径、大小阈值和结果范围，明确发起后才扫描。

扫描有时间、数量和路径边界，不等于无限深度遍历整台机器。结果不完整或取消时，应结合返回状态理解覆盖范围。扫描只寻找文件，不自动删除；删除前仍需确认用途和权限。

网卡、速率与监听端口

网络页按网卡展示地址、累计收发量和连续采样的上下行速度；监听端口来自目标机器的系统信息。累计流量和即时速率单位不同，不应相互比较。

看到监听端口不代表互联网能访问它，也不代表 CShell 已替你开放防火墙。可结合连接延迟测试从实际来源检测目标端口。

显卡与系统差异

显卡页呈现当前系统能提供的显卡和驱动信息。没有驱动、传感器或权限时可显示未提供或诊断原因；没有温度或利用率不是采集为零。Windows、Linux、macOS 的字段可能不同，不将某平台特有字段作为所有设备的保证。
