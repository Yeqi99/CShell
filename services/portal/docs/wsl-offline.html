WSL 离线安装

下载 WSL 运行时和 Linux 镜像，复制到目标电脑安装。运行时与发行版是两个独立文件；普通 Ubuntu ISO 不能直接导入 WSL。

1 · 选择下载来源

内容来源选择
WSL 运行时 MSI微软官方发布按 x64 / ARM64 选择 MSI；检查微软数字签名
当前发行版 .wsl微软官方镜像清单按架构选择 Url，并保存对应 Sha256
Ubuntu 22.04 rootfs · 国外Ubuntu 官方存档amd64 / arm64 的 rootfs.tar.gz 与 SHA256SUMS
Ubuntu 22.04 rootfs · 国内清华 TUNA · 中国科大 · 南京大学旧版发行版存档，适合手动 import；不是最新 .wsl

2026-11-01 已检查三个国内目录可访问且列有 amd64 / arm64 镜像和校验文件；镜像站同步状态会变化。未下载整份镜像，不把目录可访问当作安装验收。WSL MSI 暂无经过核验的国内官方镜像，可在能访问微软 GitHub 的机器下载后用 U 盘传递。

2 · 检查文件

Get-AuthenticodeSignature .\wsl.x64.msi
Get-FileHash .\ubuntu-jammy-wsl-amd64-ubuntu22.04lts.rootfs.tar.gz -Algorithm SHA256

MSI 签名应为有效的微软签名。Linux 镜像摘要与官方对应版本的 SHA256SUMS 或微软清单对照；不匹配就停止，不能忽略校验。

3 · 在目标 Windows 安装

先运行 MSI。以管理员身份启用虚拟机平台，系统要求时保存工作并重启；CShell 不会绕过管理员权限或自动重启。

dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

当前 .wsl 镜像用：

wsl --install --from-file D:\Downloads\Ubuntu.wsl

国内下载的旧版 rootfs 用独立名称导入，目标目录必须为空：

wsl --import Ubuntu-Class D:\WSL\Ubuntu-Class D:\Downloads\ubuntu-jammy-wsl-amd64-ubuntu22.04lts.rootfs.tar.gz --version 2
wsl -d Ubuntu-Class
wsl --list --verbose

ARM64 Windows 换用 arm64 文件。导入的 rootfs 初次默认可能是 root，按课程/组织要求建立普通用户；不要覆盖已有发行版。回到 CShell 的 WSL 插件点击刷新，选择实际检测到的发行版。
