机器桌面与浏览器

CAgent 连接面向整台机器。进入机器工作区后，按需打开终端、浏览器、文件、应用和智能体，而不是必须先选择一个 Shell。

浏览器的网络归属

CShell 在本机渲染浏览器，通过所选机器的网络出口请求网页。它不是远端浏览器截图。缓存和 Cookie 按机器隔离保存在本机；网络断开时不悄悄退回本机出口。

历史、收藏和标签与网站 Cookie 不同。Pro 同步支持的浏览器记录；Cookie 和网站登录状态保留在本机，不随通用配置同步。手机与桌面显示方式也不同，见Android 说明。

远程控制

远程桌面依赖目标系统实际提供的采集、输入和权限。Windows、Android 被控能力不等同于 macOS/Linux。Android 需要系统录屏授权；锁屏、后台限制及厂商系统可能终止投影。

原生应用

应用文件夹只应列出目标机器已适配的可启动应用。Linux 原生图形应用使用独立兼容入口，不把普通浏览器冒充完整 Linux 桌面。QQ、微信等能力须逐项满足版本、依赖和权限条件。

更多：Linux 可视化工作区、桌面边界。

统一机器桌面

SSH 连接提供终端、文件与安装 CAgent 入口；CAgent 显示真实已安装的能力。RDP 默认直接打开远程桌面，也可单独选择可视化。只有 RDP 凭据时，安装 CAgent 入口提供 Windows 安装指南和已发布的下载包；在远程桌面中安装并核对身份后，再添加 CAgent 连接，不要求选择一条不存在的 SSH 通道。

机器信息

CAgent 桌面的“机器信息”提供概览、CPU、内存、磁盘、GPU 和网络。图表来自当前机器的采样；系统不提供温度或显存等信息时明确显示未提供。大文件扫描需要选择路径并显式开始，设有扫描上限并可取消。

窗口、任务栏与离线状态

默认双击 SSH / RDP 使用原始连接方式；从连接菜单打开可视化，或设置该机器默认以可视化打开。可视化桌面离线也可打开。右下角显示真实连接状态，点击可重试。桌面可打开不代表终端、文件或远控已连接；能力就绪后才可使用。

应用窗口可最小化并从机器任务栏恢复。切换工作区保留已打开任务和草稿。关闭浏览器、关闭远控窗口与关闭整台机器工作区是不同操作，操作前核对所属窗口。

用目标机器浏览网页

  1. 进入目标机器桌面，打开「浏览器」，确认地址栏附近显示正确机器。
  2. 输入网址，按需新建标签；使用后退、前进、刷新、缩放、历史和收藏入口。
  3. 网络错误时查看当前机器连接状态和诊断，不自动改用本机网络。
  4. 同一机器已有浏览器窗口时优先恢复已有窗口；遇到不存在的占用见占用排查。

普通网页由本地客户端渲染；这里不是远端系统完整桌面。网站登录状态按机器隔离，切换机器不共享 Cookie。

观看与控制远程桌面

在机器桌面打开远程控制应用。先确认画面来自目标机器，再选择可用的画质与缩放。观看和输入控制分别受权限约束，能看到画面不代表能发送键鼠。

最小化后可从任务栏恢复。延迟同时受采集、编码、网络与显示影响，TCP 延迟不能直接代表操作延迟。断线后确认重新连接状态，不能把最后一帧当作当前画面。Android 录屏和系统控制必须保留系统授权流程。

让智能体操作网页和远程画面

在智能体权限或 MCP 客户端范围中，分别开启浏览器读取、浏览器操作、远控观看和远控输入。查看不自动包含点击和键盘权限，权限只作用于明确选择的机器。

浏览器工具可列标签、打开网址、读取元素、截图、点击、输入、选择、滚动和有限同源抓取。使用机器自己的本地浏览器分区，已有 Cookie 可继续登录；网页跨源 iframe 要以返回的 frame 目标操作，页面跳转后需重新读取元素。网站要求验证码、多因素认证或系统确认时，仍需完成其正常流程。

远控工具读取目标实际画面，并向同一会话发送鼠标与键盘操作。画面关闭、断开或权限撤销后，旧引用不能继续输入。截图按实际 Provider 能力开放；桌面截图不会替代普通浏览器渲染。
