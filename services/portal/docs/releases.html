版本与验证状态

Pro 当前下载

官网目前提供 0.8.2 测试版 Windows x64 安装程序与签名 Android APK。下载包包含基础账号与云同步体验；不能将正在开发的新权益视为当前包已经交付。

macOS、Linux 的 Pro 安装包尚未发布。开源版各平台通过 GitHub Releases 获取实际已上传附件。构建通过、附件上传、签名/公证和真机验证是不同状态。

新版开发中

扩展设置与浏览器数据同步、共享基座、账号习惯记忆、同账号机器中继接入、应用网络代理与官方模型正在开发或联调。官网发布说明会随实际验证结果更新。

校验下载

官网下载的 Pro 包可使用 SHA-256 清单 核验。Windows 可运行 Get-FileHash；Linux 使用 sha256sum；macOS 使用 shasum -a 256。摘要确认文件一致性，不等同于发行者数字签名。

反馈问题

在 GitHub Issues 附上版本、系统、CPU 架构与最小复现步骤。日志需移除邮箱验证码、账号令牌、连接密码和模型密钥。
