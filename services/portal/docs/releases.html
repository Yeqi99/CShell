版本与验证状态

0.8.13 · 取消操作与编辑保护

0.8.13 已发布。开源版、Pro 与 CAgent 的各平台附件已核验，官网香港下载源与应用更新渠道同步更新。

  • 浏览器上传取消后停止后续分块，关闭后的读取结果不再写入旧连接；已在途请求不自动重放。
  • 取消退出后，自动更新继续按原设置检查；取消安装不会启动安装器，真正退出时才清理计划。
  • 远端文件重新读取期间继续输入，新草稿不会被晚到的响应覆盖。保留原版本校验并暂停实时同步；再次确认重新读取后仍可正常加载。

Windows Pro 实际成品已验证加密存储、SSH、SFTP、桌面交互及延迟读取时的草稿保护。Android 构建与模拟器不替代真机；Windows 未做发行者签名，macOS 未公证。机房独立安装包继续使用原版本。

0.8.12 · 输入、传输与草稿可靠性

0.8.12 已发布。开源版、Pro 与 CAgent 同步更新，保留 0.8.11 的统一桌面：图标随尺寸换列，支持框选、多选与窗口恢复，应用名称不会被误选成文字。

  • Android 远控连续手势按顺序执行；失败或光标结果未确认时停止依赖输入，不自动重放。鼠标松开不再清除仍按住的修饰键。
  • 跨机器文件复制同时关联源与目标连接；任一连接断开会取消传输，取消后返回的目录查询不再继续创建目录。
  • 智能体草稿保存恢复后清除对应失败提示；其他会话保存成功不会掩盖未保存内容，过期请求不覆盖最新状态。

Windows 成品已验证终端、文件及桌面交互，Android API 29/35 模拟器通过；模拟器不替代真机。早期 Android 10 连续点击曾有一次计数不足，后续压力回归通过，但根因未明确。Windows 未做发行者签名，macOS 未公证；Mac/Linux 实机范围仍有限。既有机房独立安装包保留 0.8.11，不改标版本。

0.8.11 · 统一桌面与机房部署

0.8.11 已发布。工作台和连接桌面使用同一套窗口与任务栏。图标按桌面高度自动换列，空间不足可滚动；支持单击选择、Ctrl 多选、空白处框选，双击或 Enter 打开，应用名称不会被误选为文字。

  • 窗口支持拖动、缩放、最大化、最小化恢复；保留已打开应用及输入草稿。工作台的桌面外观单独保存，Pro 登录后沿用已有外观同步。
  • 机房发现启动失败后自动重试。共享屏幕使用稳定显示器标识，失效时重新选择；默认名称含机器名，便于区分多个共享。
  • 教师端与学生端可预置扩展。教学环境通过独立脚本下发，不写死在客户端；既有配置与身份保留。

学校网络的组播隔离、防火墙及完整教学环境安装仍需目标机器验证；不能把本机测试等同于所有学生机都可用。Windows 未签名，macOS 未公证，Android 保留系统安装确认。机房部署与下载 · 各平台安装包与校验

0.8.10 · 同步与多面板体验

0.8.10 已发布。开源版、Pro 与 CAgent 的最终安装包已核验，官网与香港更新渠道同步提供。升级保留已有账号、连接与密钥；各平台验收范围和限制见对应发行记录。

  • Pro 保留按 ID 合并的列表排序；Android 保存未使用的 FTP / SFTP 连接位置与未知云字段。
  • Tavily 账号和 Key 纳入加密同步与确认导入，付费许可和扩展授权留在本机；空字段、明确删除与失败回滚分别处理。
  • 补齐机器桌面背景、主题、命名方案和图片的同步，排除运行窗口与原生临时状态。新增可选段要求新版桌面，旧版不认识时拒绝恢复并保留云数据。
  • SSH 文件与信息面板可与智能体共存；模型菜单补齐键盘与窄宽定位，命令台异步结果不抢焦点，OpenCode 默认值按钮改为「设为默认模型」。

具体范围见同步说明、SSH 面板和模型菜单。安装包与渠道已核验；本地渲染基准不代表用户网络延迟已经解决。

SSH 连接建立后禁用客户端 Nagle 小包合并等待。真实 Pro 0.8.10 包本地 DOM p95：原生 20.7 ms、可视化 19.7 ms；保留同一 PTY，观测没有长任务。网络 RTT 仍存在，查看测试范围。

0.8.9 · 文件连接与统一工作台

0.8.9 已发布。开源版、Pro 与 CAgent 的最终安装包已核验，官网与香港更新渠道同步提供。升级保留已有账号、连接与密钥；各平台验收范围和限制见对应发行记录。

  • FTP / FTPS / SFTP：桌面端新增独立文件连接，支持浏览、上传、下载、重命名、建目录与传输队列；文件连接不启动 Shell。FTP 不提供未实现的递归传输或文本编辑。查看协议与操作范围。
  • 原生连接与可视化：SSH 默认打开原生终端，单台连接右键可记住可视化选择。可视化终端中可折叠展开文件与机器信息，切换保留同一 PTY 和历史。设置打开方式。
  • 工作台与 CLI：概览、命令台、可视化三种视图共用能力目录，支持独立命令台标签、草稿、契约查询和真实调用。命令台不是 CMD 或 PowerShell。查看完整命令。
  • 智能体与 MCP：补齐真实浏览器读取、交互、截图与有限抓取，以及受支持的远控画面、鼠标和键盘操作。读取、控制分别授权，保留网站正常鉴权流程。了解工具与权限。
  • 自定义扩展：独立 process 工具包可接入智能体、CLI 和 MCP；安装、启用与运行授权分开。制作工具扩展。
  • 模型选择：OpenCode 账号下动态列出模型，不必逐个填入基座；失效状态同步到设置，已有会话保持原选择。接入官方运行时不等于服务端允许所有模型。查看接入与实际拒绝状态。
  • 界面与兼容：侧栏字号收进右键折叠设置，默认字号更紧凑；窄面板分类不再竖排挤压。硬件与市场按机器实际能力读取，RDP-only 安装入口改为 Windows 安装指南。支持新协议的 CAgent 空闲时核验更新并保留身份与权限。查看更新条件。

独立文件协议、三种工作台视图与官方 OpenCode 运行时属于桌面端功能。Android 保留已有 SSH / CAgent 功能，并保留不消费的云配置字段；不把桌面能力标成手机已实现。

0.8.8 · 应用内更新与智能体输入

开源版与 Pro 使用香港源，在应用内连续下载、校验并安装。各平台的系统确认仍保留；CAgent 也提供原位更新。智能体统一 Enter 发送、Shift+Enter 换行，兼容中文输入法和已有会话。

0.8.6 · 文档与可靠性

使用手册按任务整理，支持正文搜索、章节直达、移动目录与示例复制；官网重新设计。CAgent 改善退出清理和启动期间关闭的处理。OpenCode 入口自动刷新模型目录，保留已有会话的选择；服务商拒绝的免费模型仍不能保证可用。Pro 修复旧配置导入时读取 OpenCode 扩展凭据的位置。

0.8.5 · 升级与退出

开源版与 Pro 同步修复三项问题：智能体任务运行时退出会提示，取消退出保留任务；CAgent 的 Windows 文件版本与发行版本一致；静默升级刷新已有快捷方式的图标，不重建已删除入口，也不修改其他安装的快捷方式。

0.8.4 · 统一机器工作区

开源版与 Pro 同步提供离线可打开的机器桌面、批量连接导入、机器信息、延迟测试、字体与侧栏定制、分组内拖动、终端快捷键和辅助配色。智能体会话独立运行，切换保留草稿，历史可恢复。

Pro 账号与网络

登录后自动同步账号配置；开源版和未登录数据先预览，再由你选择载入。新增权限配置恢复、未登录缓存清理、共享基座与习惯记忆。同账号 CAgent 自动发现，会员可使用免公网 IP 连接和应用机器出口。受控端权限仍由目标机器授权。

浏览器与终端修复

同一机器的多个工作区复用本机浏览器标签，失效占用自动释放；手机和电脑的本地浏览器互不占用。断线不回退本机网络，浏览器可重试；终端断线历史和独立小窗会话保留。

0.8.8 正式包的平台验证

Windows x64 已完成实际安装包启动、SSH、终端与文件流程验证；Android 提供签名 APK，并完成 Android 29/35 模拟器原生测试。macOS 与 Linux 提供已构建的 ARM64 / x64 包；实体设备和不同发行版仍需验证。macOS 未做 Apple 公证，Windows 安装器未做发行者代码签名。

下载与校验

在 下载中心 选择产品、系统与架构。使用 Pro 摘要清单 或 开源版摘要清单 校验安装包。移动端安装仍需系统确认；不支持新更新源的旧客户端需首次手动升级。

反馈问题

向 GitHub Issues 提供版本、系统、CPU 架构和复现步骤，请勿附带密码、令牌或模型密钥。

一键更新

CShell 0.8.8 起，在「设置 → 关于与更新」点击立即更新，应用会下载当前产品和架构对应的安装包、校验后继续安装。全过程使用香港更新源，不需要打开 GitHub。自动下载完成时，点击「安装并重新打开」即可。

  • Windows：保存当前任务后安装到原目录并重新打开。有运行中会话时会先确认；取消退出也会取消本次安装。
  • Android：下载后直接进入系统安装确认。首次需要允许 CShell 安装应用，返回后继续安装；不会绕过系统确认。签名或包身份不一致时停止，不要求卸载或清空数据。
  • macOS：验证 DMG 内的应用身份与版本，在有写权限的原应用目录替换并保留备份。仍受系统安全检查与未公证限制。
  • Linux：AppImage 可原位更新并保留旧程序。DEB 安装仍通过系统包管理器处理，不能把非 AppImage 安装方式当作可直接替换。
  • CAgent：原生窗口或「设置与权限 → 应用更新」提供检查与更新。Windows 使用安装程序；Linux/macOS 独立私有运行包原位更新并用原数据目录重新启动。程序内嵌数据目录、系统 Node 启动或不可写目录会停止自动替换，防止损坏数据与环境。

0.8.2 等旧版本怎么升级？

旧客户端若仍显示「打开 GitHub 下载页」或找不到安装包，其更新源和匹配规则已写在旧程序内，服务器不能直接改掉。请从香港下载中心下载对应产品，覆盖安装一次；不要卸载或删除配置。之后使用应用内更新。开源版与 Pro 必须选择各自渠道，不能互相覆盖。

安装、升级与保留数据

  1. 在下载页选择开源版、Pro 或 CAgent，再选系统和处理器架构。会员与免费 Pro 使用同一客户端。
  2. 开源版、Pro 和 CAgent 均可使用香港下载源，无需跳转 GitHub。核对包名、版本和 SHA-256 摘要。
  3. 升级前处理正在运行的任务，按对应安装程序执行。保留原安装路径与数据，不用另一版本覆盖当前渠道。
  4. 重新打开后核对关于页版本、账号、连接与模型。没有更新不等于安装失败，也可能是当前已为该渠道最新版。

Windows 包未签名，macOS 包未签名 / 公证；macOS 与 Linux 仍有实机验证限制。Android 需要系统安装确认，不能声称所有设备已静默升级。

卸载与重装

卸载客户端程序与删除用户数据是两件事。若希望重装后保留连接和身份，先确认安装器的数据选项并备份；不要手工删除 CAgent 身份目录或跨设备复制私钥来“恢复”。

清除 Pro 未登录缓存使用账号页专用入口，不把卸载程序作为清理云账号的方法。云端数据、远端文件和服务器上已安装的软件不会因卸载本机客户端自动消失。
