Android

安装与升级

从官网下载获取 Pro 签名 APK；开源版从香港下载中心下载。最低系统为 Android 10。允许本次下载来源安装后按系统提示完成；升级使用相同签名的同一产品安装包。Pro 与开源版的数据独立。

手机工作区

支持连接机器、终端、远端文件与按目标能力提供的桌面控制。触摸、拖动、滚轮和文本输入采用手机交互。桌面多显示器视图和完整桌面插件运行时不直接复制到手机。

手机作为被控端

Android CAgent 能力在 CShell 扩展中按需启用，需要系统录屏授权；输入控制依赖单独的无障碍授权。不能绕过锁屏或受保护画面。系统结束投影后需在手机重新授权。

需要每次开启屏幕共享吗？

关闭电脑上的观看窗口或网络断开后，只要手机当前投影仍有效，重新连接即可继续，不需要再次确认录屏。0.8.18 Pro 已在 Android 16 实机验证此过程。

手机重启、覆盖安装、进程结束，或用户及系统停止投影后，需要在手机重新开始共享并确认。Android 的录屏授权只对本次投影有效，不能设置为永久开机共享；锁屏也可能结束投影。

本机文件与后台

本机目录通过系统选择器授权。厂商省电、Doze、锁屏或网络切换可能影响后台连接。模拟器检查不能覆盖全部手机；反馈时提供 Android 版本和机型。

Android 被控端说明

手机账号工作区

手机端将访客与各账号配置分开保存。注册不会自动上传访客连接，载入或清除访客数据需确认。切换账号前应结束当前连接与文件传输；浏览器数据按账号和机器隔离。桌面专属字段继续保存在加密云数据中。

安装更新保留 Android 系统确认。手机不具备所有桌面插件和安装能力，请以移动端实际入口为准。

应用内更新

更新入口、各平台安装方式与旧版升级说明见一键更新指南。更新使用香港源，保留当前产品渠道与账号数据；安装前先保存工作。

与桌面文件连接的区别

0.8.9 的独立 FTP / FTPS / SFTP 新建入口属于桌面客户端。Android 当前继续使用 SSH 或 CAgent 连接中的文件功能，不把其他协议自动转换为 SSH。Pro 云数据保留未在手机使用的连接、凭据和可选字段，手机端保存或同步不会删除这些桌面配置。

0.8.16 原生验证范围

最终 Core 492fe7a 的 Release 41080272258 首轮通过 API 29 / 35 模拟器验证，覆盖实际屏幕编码、加密传输、解码、旋转与点击输入；此前旧构建的一次 API 29 零帧失败在原源码严格重跑后通过，保留该间歇性记录；最终构建无需重跑，未降低帧数或点击断言。这不等于所有实体设备、系统定制或桌面扩展已验收。安装仍保留 Android 系统确认，0.8.16 已公开发布，选择对应渠道与架构，下载后仍需系统安装确认。

让智能体使用手机能力

先连接实际手机，再在手机端开启需要的能力。屏幕共享由 Android 系统确认；触摸与界面读取还需要开启辅助控制。锁屏、共享停止或权限撤销后，相关工具会停止可用，不会继续向旧画面输入。

短信与电话在手机设置中分别授权。只有硬件支持且系统确实授予权限时，智能体才能看到对应工具；没有 SIM 卡、未选择默认短信 SIM 或系统不允许时会给出具体提示。紧急电话请直接在手机上操作。

发送短信和拨号的“已提交”表示已交给系统，不等于已送达或接通。重复提交同一个操作编号不会再次发送或拨打；状态不确定的操作不会因断线重连自动重放。电脑上的机器授权和手机系统权限都需要满足。

手机的远程工作区（0.8.20）

连接手机后，从机器桌面打开远程控制、文件或应用。远控默认完整显示手机画面，窗口随实际横竖屏调整；不拉伸填满。视频采用有界缓冲减少等待确认造成的停顿，实际流畅度仍取决于网络和手机编码能力。

文件包含 CAgent 专用共享目录及手机文件页中通过系统选择器授权的目录。可传输文件、新建文件夹、重命名和删除，当前单文件上传上限 512 MiB；不会读取其他应用的私有目录。目录授权被撤销后需要在手机重新选择。

应用页支持搜索手机真实可启动的应用，点击请求打开，然后可切到远程控制查看。Android 可能限制后台启动；提交请求不等于应用已打开。应用与文件操作同时可供已授权智能体调用。上述入口需要匹配的 0.8.20 手机端；版本发布状态请看安装与版本页面。

通过 USB 测试安装

USB 调试授权与 USB 安装是两项独立设置。若 ADB 安装返回 INSTALL_FAILED_USER_RESTRICTED，请解锁手机，在开发者选项中允许 USB 安装，并处理手机上的安装确认。CShell 不会代替系统授权；也可以下载对应版本 APK 后在手机上手动安装。

同账号连接与画面比例

启用并保存 CAgent 后，重新进入 CShell 会恢复设备连接服务，无需先共享屏幕。同账号设备列表隐藏手机自身，并将该分组置顶。系统限制后台活动时，请检查通知与电池设置。

远程画面按手机真实宽高等比显示，横竖屏变化后重新适配。查看屏幕仍需要 Android 的录屏授权；设备在线不等于已授权录屏。
