02 / CAGENT PROTOCOL

一种连接，通向整台机器。

自研 CAgent 协议将身份认证、终端、文件、HTTP 和机器管理统一到同一设备上下文。支持的能力由目标机器实际提供，权限在后端执行。

CShell身份核对 · 加密通道CAgent

无需以 SSH 终端作为所有功能的前置入口。同账号免公网 IP 接入属于 Pro 会员新版联调能力。

03 / LINUX WORKSPACE

让 Linux，成为可视化工作环境。

从机器桌面打开文件、终端、浏览器和应用市场。窗口保留各自状态，切换任务也不必反复进入不同工具。

浏览器在 CShell 本地渲染，通过所选 Linux 机器访问网络；原生图形应用通过独立兼容入口使用。
